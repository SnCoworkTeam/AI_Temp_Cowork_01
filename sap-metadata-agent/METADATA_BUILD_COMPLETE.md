## 📊 构建流程

```
1. 检测总服务数
   ↓
2. 分批处理所有服务
   ├─ 发现数据资产
   ├─ 提取业务实体
   ├─ 分析业务流程
   └─ 同步到metadata-service
   ↓
3. 构建语义索引
   ↓
4. 验证同步状态
   ↓
5. 生成构建报告
```

## 🚀 使用方法

### Windows (PowerShell)
```powershell
cd sap-metadata-agent
.\build_all_metadata.ps1
```

### Linux/macOS/Windows (Python)
```bash
cd sap-metadata-agent
python build_all_metadata.py
```

## 📈 功能特性

1. **自动检测总服务数**
   - 无需手动配置
   - 自动从SAP系统获取服务总数
   - 如果检测失败，使用默认值348

2. **分批处理**
   - 每批处理10个服务（可配置）
   - 自动处理所有批次直到完成
   - 支持自定义批次大小

3. **进度保存**
   - 自动保存构建进度
   - 支持断点续传
   - 构建中断后可继续

4. **错误处理**
   - 自动重试失败的批次
   - 最多重试3次
   - 详细的错误信息

5. **语义索引构建**
   - 所有批次完成后自动构建
   - 将元数据索引到知识库
   - 支持语义搜索

6. **同步验证**
   - 验证数据资产同步
   - 验证业务实体同步
   - 提供同步统计

7. **详细报告**
   - 构建统计信息
   - 成功/失败批次数
   - 累计数据资产数
   - 累计业务实体数
   - 累计业务流程数
   - 总耗时

## 🔍 检查构建状态

### 使用API
```bash
curl http://localhost:8015/api/sap-metadata/build-status
```

### 使用脚本
脚本运行时会自动显示进度，每10个批次显示一次详细报告。

## ⚙️ 配置参数

可以在脚本中修改以下参数：

- `BATCH_SIZE`: 每批处理的服务数量（默认：10）
- `MAX_RETRIES`: 失败重试次数（默认：3）
- `RETRY_DELAY`: 重试延迟（秒，默认：5）
- `REQUEST_TIMEOUT`: 请求超时时间（秒，默认：600）

## 🔧 故障排查

如果遇到问题，请参考 `BUILD_ALL_METADATA.md` 中的故障排查章节。

常见问题：
1. **无法连接到API** - 检查sap-metadata-agent服务是否运行
2. **服务数为0** - 检查SAP MCP服务器连接
3. **同步失败** - 检查metadata-service和数据库连接
4. **构建中断** - 直接重新运行脚本，会自动继续
