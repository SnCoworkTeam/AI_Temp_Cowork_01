# 进入容器运行语义索引构建

如果 `docker` 命令不可用，可以进入容器后直接运行：

## 方法1: 进入容器后运行（推荐）

```bash
# 1. 进入容器
docker exec -it enterprise-ai-sap-metadata-agent bash

# 2. 在容器内运行（文件已通过热加载映射到 /app/scripts）
cd /app/scripts
python build_semantic_in_docker.py --batch-size 1 --no-resume

# 3. 如果测试成功，开始正式构建
python build_semantic_in_docker.py --batch-size 50
```

## 方法2: 使用 docker-compose exec

```bash
# 如果 docker 命令不可用，尝试 docker-compose
docker-compose exec sap-metadata-agent python /app/scripts/build_semantic_in_docker.py --batch-size 50
```

## 方法3: 使用 PowerShell 脚本

```powershell
cd sap-metadata-agent
.\run_semantic_build.ps1 --batch-size 50
```

脚本会自动尝试多种方式执行。

## 方法4: 直接在容器内创建启动脚本

如果经常需要运行，可以在容器内创建一个启动脚本：

```bash
# 进入容器
docker exec -it enterprise-ai-sap-metadata-agent bash

# 创建启动脚本
cat > /app/scripts/run_build.sh << 'EOF'
#!/bin/bash
cd /app/scripts
python build_semantic_in_docker.py "$@"
EOF

chmod +x /app/scripts/run_build.sh

# 以后可以直接运行
/app/scripts/run_build.sh --batch-size 50
```

## 检查容器状态

```bash
# 检查容器是否运行
docker-compose ps sap-metadata-agent

# 或
docker ps | grep sap-metadata-agent
```

## 如果容器未运行

```bash
# 启动容器
docker-compose up -d sap-metadata-agent

# 等待容器启动
docker-compose ps sap-metadata-agent
```
