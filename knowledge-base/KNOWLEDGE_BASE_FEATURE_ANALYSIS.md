# 知识库服务功能分析

## 📊 当前已有功能

### ✅ 已实现的基础功能
1. **文档管理**

   - ✅ 文档详情查询
   - ✅ 文档删除
   - ✅ 文档状态管理（uploading, processing, processed, failed）

2. **搜索功能**
   - ✅ 语义搜索（semantic search）
   - ✅ 关键词搜索（keyword search）
   - ✅ 混合搜索（hybrid search）
   - ✅ 搜索历史记录

3. **知识图谱**
   - ✅ 知识图谱节点管理
   - ✅ 知识图谱边管理
   - ✅ 知识图谱查询

4. **知识库管理（刚实现）**
   - ✅ 知识库列表（基于category分组）
   - ✅ 创建知识库（通过category）
   - ✅ 获取知识库详情
   - ✅ 删除知识库（删除该category下的所有文档）

5. **其他功能**
   - ✅ 文档分类（category字段）
   - ✅ 文档标签（tags）
   - ✅ 文档元数据管理
   - ✅ 健康检查
   - ✅ 维护功能

## ❌ 缺少的核心功能

### 1. **知识库作为独立实体**
**问题**：当前知识库只是通过文档的`category`字段进行分组，没有独立的数据库模型。

**需要实现**：
- [ ] 创建`KnowledgeBase`数据库模型
- [ ] 知识库与文档的一对多关系
- [ ] 知识库的独立ID和元数据
- [ ] 知识库的创建时间、更新时间等字段

**数据库模型设计**：
```python
class KnowledgeBase(BaseModel):
    id: UUID  # 知识库ID
    name: str  # 知识库名称
    description: str  # 描述
    embedding_model: str  # 嵌入模型
    chunk_strategy: str  # 分块策略
    chunk_size: int  # 分块大小
    chunk_overlap: int  # 分块重叠
    status: str  # 状态
    created_by: UUID  # 创建者
    created_at: datetime
    updated_at: datetime
    settings: JSONB  # 配置信息
```

### 2. **知识库配置管理**
**问题**：无法为每个知识库设置独立的配置。

**需要实现**：
- [ ] 嵌入模型配置（每个知识库可以使用不同的嵌入模型）
- [ ] 分块策略配置（chunk_size, chunk_overlap）
- [ ] 向量存储配置
- [ ] 索引配置
- [ ] 更新知识库配置（PUT/PATCH端点）

### 3. **知识库更新功能**
**问题**：当前只有创建和删除，没有更新功能。

**需要实现**：
- [ ] 更新知识库名称和描述
- [ ] 更新知识库配置
- [ ] 批量更新文档的category（迁移到其他知识库）

### 4. **文档与知识库的关联**
**问题**：文档通过category字段间接关联知识库，不够明确。

**需要实现**：
- [ ] 文档表添加`knowledge_base_id`外键
- [ ] 上传文档时指定知识库ID
- [ ] 文档迁移功能（从一个知识库迁移到另一个）
- [ ] 批量操作（批量添加/移除文档）

### 5. **知识库权限管理**
**问题**：没有权限控制机制。

**需要实现**：
- [ ] 知识库所有者（owner）
- [ ] 知识库共享（share）
- [ ] 角色权限（read, write, admin）
- [ ] 权限验证中间件

### 6. **知识库统计和分析**
**问题**：统计信息不够详细。

**需要实现**：
- [ ] 知识库使用统计（访问次数、搜索次数）

- [ ] 知识库健康度评估
- [ ] 存储空间统计
- [ ] 性能指标（索引时间、搜索延迟）

### 7. **知识库导入/导出**

**需要实现**：

### 8. **知识库版本管理**
