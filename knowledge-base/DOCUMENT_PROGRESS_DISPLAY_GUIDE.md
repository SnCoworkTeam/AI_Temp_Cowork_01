# 文档处理进度展示使用指南

## 🎯 功能概述

文档处理进度展示功能提供了详细的实时进度信息，包括：
- ✅ **处理过程**：显示所有处理阶段
- ✅ **当前阶段**：高亮显示正在进行的阶段
- ✅ **完成百分比**：显示总体进度和当前阶段进度
- ✅ **实时更新**：自动轮询更新进度信息

## 📊 进度展示位置

### 1. 文档列表页面

在知识库详情页面的文档列表中：

1. **状态列显示**：
   - 显示文档状态（处理中/已处理/失败）
   - **处理中的文档会显示进度百分比**（如：`45.5%`）
   - 处理中的文档旁边有展开/收起按钮（▼/▲）

2. **展开详细进度**：
   - 点击处理中文档旁边的展开按钮
   - 显示完整的处理进度详情

### 2. 进度详情展示

展开后会显示：

#### 总体进度条
- 显示总体完成百分比（0-100%）
- 显示当前步骤名称
- 显示预估剩余时间

#### 处理阶段列表
显示所有9个处理阶段：

1. **📤 上传** (5% 权重)
   - 文件上传到服务器

2. **📄 解析** (15% 权重)
   - 解析文档内容

3. **🧹 预处理** (包含在分块阶段)
   - 清洗文本、标准化格式

4. **⭐ 质量评估** (包含在分块阶段)
   - 评估文档质量

5. **✨ 元数据增强** (包含在分块阶段)
   - 生成摘要、提取关键词

6. **✂️ 分块** (10% 权重)
   - 将文档分割成块

7. **🔢 向量化** (60% 权重) ⭐
   - **最耗时的阶段**
   - 显示已完成块数/总块数
   - 显示向量化进度条

8. **💾 存储** (10% 权重)
   - 保存到数据库和向量存储

9. **✅ 完成**
   - 处理完成

## 🎨 视觉指示

### 阶段状态图标

- ✅ **已完成**：绿色对勾图标 + 绿色背景
- 🔄 **进行中**：蓝色旋转图标 + 蓝色背景 + 边框
- ⏳ **待处理**：灰色时钟图标 + 灰色背景
- ❌ **失败**：红色叉号图标 + 红色背景

### 进度条颜色

- **蓝色**：处理中
- **绿色**：已完成
- **红色**：失败

## 📈 进度百分比计算

### 总体进度

总体进度 = 各阶段进度 × 权重

**权重分配**：
- 上传：5%
- 解析：15%
- 分块：10%
- **向量化：60%**（最重要）
- 存储：10%

**示例**：
- 上传完成：5%
- 解析完成：5% + 15% = 20%
- 分块完成：20% + 10% = 30%
- 向量化 50% 完成：30% + (60% × 50%) = 60%
- 向量化 100% 完成：30% + 60% = 90%
- 存储完成：90% + 10% = 100%

### 当前阶段进度

对于向量化等有子步骤的阶段：
- 显示 `已完成块数 / 总块数`
- 显示阶段内进度条
- 例如：`45 / 100` 表示已完成45个块，共100个块

## 🔄 实时更新

### 自动轮询

- **轮询间隔**：每3秒自动更新一次
- **轮询条件**：仅对处理中的文档（`processing` 或 `uploading` 状态）
- **自动停止**：文档完成后自动停止轮询

### 手动刷新

- 点击展开按钮查看最新进度
- 刷新页面获取最新状态

## 💡 使用场景

### 场景 1: 查看文档是否已开始向量化

1. 在文档列表中，找到处理中的文档
2. 查看状态列：
   - 如果显示进度百分比，说明已开始处理
   - 点击展开按钮查看详细进度
3. 在详细进度中：
   - 如果看到 **🔢 向量化** 阶段是蓝色（进行中），说明正在向量化
   - 查看向量化进度：`已完成块数 / 总块数`

### 场景 2: 监控大文档处理进度

1. 上传大文档后，文档状态变为 `processing`
2. 状态列会显示进度百分比（如：`25.5%`）
3. 点击展开按钮查看详细进度：
   - 查看当前阶段（如：向量化）
   - 查看当前阶段进度（如：`50 / 200` 块）
   - 查看预估剩余时间

### 场景 3: 排查处理问题

1. 如果文档长时间停留在某个阶段：
   - 查看详细进度，确认当前阶段
   - 检查是否有错误信息（红色背景）
   - 查看后端日志了解具体问题

## 🎯 关键信息解读

### 向量化阶段

**如何判断是否已开始向量化？**

1. **查看阶段列表**：
   - 如果 **🔢 向量化** 阶段是蓝色（进行中）→ **正在向量化**
   - 如果 **🔢 向量化** 阶段是绿色（已完成）→ **向量化已完成**
   - 如果 **🔢 向量化** 阶段是灰色（待处理）→ **尚未开始向量化**

2. **查看进度百分比**：
   - 如果总体进度 > 30%，通常已开始向量化
   - 向量化阶段占60%权重，是进度的主要部分

3. **查看当前步骤**：
   - 如果 `current_step` = `"embedding"` → **正在向量化**
   - 如果显示 `已完成块数 / 总块数` → **正在向量化**

### 预估剩余时间

- 基于已用时间和当前进度计算
- 格式：`约 X 分 Y 秒` 或 `约 X 秒`
- 仅供参考，实际时间可能因文档大小和服务器负载而变化

## 🔧 技术实现

### 前端组件

- **DocumentProgress.tsx**：进度展示组件
- **知识库详情页面**：集成进度展示

### API 端点

- `GET /api/knowledge/documents/{document_id}/progress`
- 返回详细的进度信息

### 数据流

```
文档上传 → 后端开始处理 → 创建进度跟踪器
    ↓
前端轮询进度 API → 获取进度信息 → 更新UI
    ↓
处理完成 → 停止轮询 → 更新文档状态
```

## 📝 注意事项

1. **进度信息可能延迟**：
   - 轮询间隔为3秒，可能有最多3秒的延迟
   - 处理完成后，进度信息可能被清除

2. **网络问题**：
   - 如果无法获取进度，会显示错误提示
   - 文档仍会继续处理，只是无法显示进度

3. **已完成文档**：
   - 已完成的文档不会显示进度信息
   - 状态显示为"已处理"

4. **失败文档**：
   - 失败的文档会显示错误信息
   - 查看详细进度了解失败原因

## 🎉 总结

通过文档处理进度展示功能，您可以：

- ✅ **实时了解**文档处理进度
- ✅ **准确判断**是否已开始向量化
- ✅ **预估时间**了解剩余处理时间
- ✅ **排查问题**快速定位处理卡点

所有信息都会自动更新，无需手动刷新！
