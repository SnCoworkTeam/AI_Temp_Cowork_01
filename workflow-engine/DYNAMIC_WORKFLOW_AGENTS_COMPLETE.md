```
动态设计的智能体网络:
1. 元数据智能体 → 提供业务上下文（销售订单相关）

5. 内容生成智能体 → 生成分析报告
6. 格式优化智能体 → 优化报告格式
```


## 四、智能体协作模式

### 4.1 数据流

```
元数据智能体 (业务上下文)
    ↓
数据查询智能体 (数据获取)
    ↓
分析智能体 (数据分析)
    ↓
洞察生成智能体 (业务洞察)
    ↓
内容生成智能体 (报告生成)
    ↓
格式优化智能体 (格式优化)
    ↓
MCP工具智能体 (发送/交付)
```

### 4.2 并行执行

```
第1层（并行）:
  - 元数据智能体
  - 内容生成智能体（如果是简单问答）

第2层（并行）:
  - 数据查询智能体
  - 工作流智能体（如果需要）

第3层（并行）:
  - 分析智能体
  - 洞察生成智能体（如果数据已准备好）

第4层:
  - 内容生成智能体
  - 格式优化智能体
  - MCP工具智能体
```

## 五、使用示例

### 5.1 后端使用

```python
from agent_service.src.core.dynamic_execution_engine import DynamicExecutionEngine

engine = DynamicExecutionEngine()

# 执行动态工作流（流式）
async for chunk in engine.execute_dynamic_workflow(
    user_input="分析一下销售订单，形成分析报告，然后发送给刘玉斌",
    context={"user_id": "user_123"},
    stream=True
):
    print(chunk)
```
