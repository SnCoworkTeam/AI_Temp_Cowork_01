# 所有元数据类型列表展示更新

## 更新内容

### ✅ 统一列表展示
- **数据资产**: 表格列表展示（按分类分组）
- **工作流**: 表格列表展示
- **AI模型**: 表格列表展示
- **业务实体**: 表格列表展示
- **汇总视图**: 所有类型都使用表格列表展示

### ✅ 全量数据支持
- 所有元数据类型都支持获取全量数据
- 当limit > 1000时，自动使用分页获取所有数据
- 每次分页获取1000条，直到获取完所有数据

### ✅ 统一的表格列
所有元数据类型使用统一的表格列：
- **名称**: 元数据的唯一标识符
- **显示名称**: 元数据的显示名称
- **类型**: 元数据类型（type或asset_type）
- **状态**: 元数据状态（active、inactive等）
- **创建时间**: 元数据创建时间
- **操作**: 查看详情按钮

## 使用说明

1. **查看所有元数据**
   - 点击"全部"标签查看所有类型的汇总
   - 每个类型以表格形式展示

2. **查看特定类型**
   - 点击对应的标签（数据资产、工作流、AI模型、业务实体）
   - 查看该类型的所有元数据

3. **搜索和筛选**
   - 使用搜索框搜索元数据
   - 数据资产支持分类筛选

4. **查看详情**
   - 点击"查看详情"按钮查看完整元数据信息

## 注意事项

- 首次加载可能需要一些时间（取决于数据量）
- 大量数据时建议使用搜索功能缩小范围
- 表格支持横向滚动（如果列太多）
