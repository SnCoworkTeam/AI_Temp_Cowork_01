# AI助手思考过程显示功能说明

## 功能概述

已为AI助手对话框添加了完整的思考过程显示功能，包括：
- 💭 **思考过程**：AI分析请求、设计方案的过程
- ⚙️ **执行过程**：AI执行任务的详细步骤
- ✅ **最终结果**：完整的执行结果

## 主要特性

### 1. 完整流程显示
按照以下顺序完整展示AI的工作过程：
```
思考过程 → 执行过程 → 最终结果
```

### 2. 智能开关控制
- **执行中**：自动显示思考和执行过程，实时更新
- **完成后**：提供开关按钮，用户可以选择显示或隐藏详细过程
- **用户偏好**：选择会自动保存到浏览器本地存储（localStorage）

### 3. 折叠/展开功能
- 完成后的思考过程和执行过程可以折叠/展开
- 点击标题栏右侧的箭头图标即可切换
- 方便用户快速查看或隐藏详细信息

### 4. 状态指示
- **进行中**：显示动画脉冲效果（"进行中..."、"执行中..."）
- **已完成**：显示完整信息，可折叠

## 使用方式

### 查看思考过程

1. **执行过程中**：
   - 思考过程和执行过程会自动实时显示
   - 可以看到AI的分析、设计、执行步骤

2. **执行完成后**：
   - 在最终结果上方会显示控制按钮
   - 点击"👁 思考过程"按钮可显示/隐藏思考过程
   - 点击"👁 执行过程"按钮可显示/隐藏执行过程

### 折叠/展开详情

- 点击思考过程或执行过程标题栏右侧的 ⌄ 或 ⌃ 图标
- 折叠后只显示标题，展开后显示完整内容

## 技术实现

### 修改的文件
- `web-ui/src/components/DynamicWorkflowDisplay.tsx`

### 新增功能
1. **状态管理**：
   - `showThinking`：是否显示思考过程
   - `showExecution`：是否显示执行过程
   - `thinkingCollapsed`：思考过程是否折叠
   - `executionCollapsed`：执行过程是否折叠

2. **本地存储**：
   - `workflow_show_thinking`：保存思考过程显示偏好
   - `workflow_show_execution`：保存执行过程显示偏好

3. **UI组件**：
   - 使用 `lucide-react` 图标库的 `Eye`、`EyeOff`、`ChevronDown`、`ChevronUp` 图标
   - 响应式设计，支持深色模式

## 显示逻辑

### 思考过程
```typescript
// 执行中：自动显示，不可折叠
{thinkingProcess.length > 0 && showThinking && (
  <div className="thinking-process">
    <h3>思考过程 {!isComplete && "进行中..."}</h3>
    {!thinkingCollapsed && <内容>}
  </div>
)}
```

### 执行过程
```typescript
// 执行中：自动显示，不可折叠
{executionProcess.length > 0 && showExecution && (
  <div className="execution-process">
    <h3>执行过程 {!isComplete && "执行中..."}</h3>
    {!executionCollapsed && <内容>}
  </div>
)}
```

### 最终结果
```typescript
// 只在完成后显示
{isComplete && finalResult && (
  <div className="final-result">
    <h3>分析结果</h3>
    <内容>
  </div>
)}
```

## 样式设计

### 颜色方案
- **思考过程**：蓝色系（`bg-blue-50`、`text-blue-700`）
- **执行过程**：绿色系（`bg-green-50`、`text-green-700`）
- **最终结果**：渐变背景（`from-white via-blue-50/50 to-indigo-50/30`）

### 交互效果
- 按钮悬停：颜色加深
- 进行中状态：脉冲动画（`animate-pulse`）
- 过渡动画：平滑的颜色和状态切换（`transition-colors`）

## 适用场景

此功能主要用于**动态工作流**（`workflowType: 'dynamic'`）的消息：
- 复杂的数据分析任务
- 多步骤的智能体协作
- 需要展示AI推理过程的场景
