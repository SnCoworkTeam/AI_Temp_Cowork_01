# 项目管理功能手动测试指南

## 快速开始

### 1. 准备工作

1. **访问系统**
   - 打开浏览器（推荐 Chrome 或 Edge）
   - 访问：http://43.143.139.197:3000

2. **登录系统**
   - 使用管理员账号登录（用户名：admin）
   - 如果不知道密码，请联系系统管理员

3. **打开开发者工具**
   - 按 `F12` 打开浏览器开发者工具
   - 切换到 `Network`（网络）标签
   - 勾选 `Preserve log`（保留日志）

4. **准备测试报告**
   - 打开 `docs/项目管理功能测试报告模板.md`
   - 准备截图工具（Windows: Win+Shift+S）

- 如果发现问题，详细描述复现步骤

- 可以同时打开测试计划和测试报告

- 使用开发者工具查看网络请求

## 常见问题

### Q: 如何查看API请求？
**A:** 打开开发者工具（F12），切换到 Network 标签，刷新页面或执行操作，即可看到所有API请求。

### Q: 如何获取Token？
**A:** 在 Network 标签中找到任意API请求，查看请求头中的 `Authorization` 字段，即可看到Token。

### Q: 测试时发现bug怎么办？
**A:** 在测试报告的"问题记录"部分详细记录，包括：
- 问题描述
- 复现步骤
- 截图
- 浏览器控制台错误（如果有）
