# SAP MM物料管理模块概述

## 概述
SAP MM（Material Management，物料管理）是SAP ERP系统中的一个核心模块，用于管理企业的物料主数据、采购、库存等业务流程。

## 主要功能

### 1. 物料主数据管理
- 物料主数据：包含物料的基本信息，如物料号、描述、单位、分类等
- 物料类型：原材料、半成品、成品、贸易商品等
- 物料分类：根据物料特性进行分类管理

### 2. 采购管理
- 采购申请（PR）：内部需求申请
- 采购订单（PO）：向供应商采购物料的正式单据
- 框架协议：长期采购协议
- 货源确定：自动或手动确定采购来源

### 3. 库存管理
- 库存盘点：定期或循环盘点
- 库存转移：仓库间、工厂间转移
- 库存评估：按不同评估方法评估库存价值
- 预留：为特定用途预留库存

### 4. 供应商管理
- 供应商主数据：供应商基本信息
- 供应商评估：价格、质量、交货时间等
- 供应商关系管理：供应商选择和开发

## 关键业务流程

### 采购到付款流程
1. 创建采购申请
2. 创建采购订单
3. 发送给供应商
4. 收货（GR）
5. 发票校验（MIRO）
6. 付款

### 库存管理流程
1. 物料入库
2. 库存盘点
3. 库存转移
4. 物料出库
5. 库存评估

## 与其他模块的集成

- **SD（销售与分销）**: 销售订单触发采购需求
- **FI（财务会计）**: 采购发票过账到财务
- **CO（成本控制）**: 成本中心费用分配
- **PP（生产计划）**: 生产订单物料需求
