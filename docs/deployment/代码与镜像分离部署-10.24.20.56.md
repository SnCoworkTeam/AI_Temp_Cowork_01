# 10.24.20.56：代码与镜像分离部署

代码在 `/opt/enterprise-ai-platform`，镜像包在 `/opt/enterprise-ai-platform1` 时的部署方式，并保证**后期拉取代码后可以包含到容器里**。

---

## 一、目录约定

| 目录 | 内容 |
|------|------|
| `/opt/enterprise-ai-platform` | 代码（git clone）、docker-compose.yml、.env，**作为 compose 工作目录** |
| `/opt/enterprise-ai-platform1` | 仅镜像 .tar 及导出时的 docker-compose.yml、.env（可选） |

compose 从**代码目录**启动，容器内通过 **volume 挂载** 使用代码目录下的源码，因此 `git pull` 后重启服务即可让新代码生效。

---

## 二、首次部署（在 10.24.20.56 上执行）

### 方式一：用脚本（推荐）

```bash
# 去掉脚本可能的 Windows 换行符
sed -i 's/\r$//' /opt/enterprise-ai-platform/scripts/deploy-from-separate-image-dir.sh
chmod +x /opt/enterprise-ai-platform/scripts/deploy-from-separate-image-dir.sh
bash /opt/enterprise-ai-platform/scripts/deploy-from-separate-image-dir.sh
```

脚本会：从 `/opt/enterprise-ai-platform1` 加载所有 `.tar` → 确保代码目录有 `.env` → 在 `/opt/enterprise-ai-platform` 执行 `docker compose up -d --no-build`。

### 方式二：手动手动执行

```bash
# 1. 加载镜像（在镜像目录）
cd /opt/enterprise-ai-platform1
for f in *.tar; do [ -f "$f" ] && docker load -i "$f"; done

# 2. 确保代码目录有 .env（若没有则从导出目录复制或从 .env.example 生成）
cd /opt/enterprise-ai-platform
[ ! -f .env ] && cp /opt/enterprise-ai-platform1/.env .env 2>/dev/null || cp .env.example .env
sed -i 's/\r$//' .env
sed -i '1s/^\xEF\xBB\xBF//' .env

# 3. 在代码目录启动（不构建）
export COMPOSE_PROJECT_NAME=enterprise-ai-platform
docker compose up -d --no-build

# 4. 查看状态
docker compose ps
```

## 三、后期拉取代码后如何包含到容器里

compose 里各服务挂载了代码目录（如 `./registry-service/src:/app/src`），因此：

1. **在代码目录拉取代码**
   ```bash
   cd /opt/enterprise-ai-platform
   git pull origin zhgj
   ```

2. **让容器使用新代码**（二选一）
   - **重启相关服务**（推荐）：
     ```bash
     docker compose restart registry-service api-gateway config-center mcp-gateway workflow-engine web-ui auth-service knowledge-base metadata-service chat-service dag-orchestrator agent-service agent-orchestrator agent-registry memory-service
     ```
   - **或整体重启**：
     ```bash
     docker compose up -d --no-build
     ```

3. **若 docker-compose.yml 或依赖有变更**
   ```bash
   cd /opt/enterprise-ai-platform
   docker compose up -d --no-build
   ```

无需在服务器上重新构建镜像，代码通过挂载进入容器。

## 四、小结

| 操作 | 命令/位置 |
|------|------------|
| 首次部署 | `bash /opt/enterprise-ai-platform/scripts/deploy-from-separate-image-dir.sh` |
| 代码更新 | `cd /opt/enterprise-ai-platform && git pull`，再 `docker compose restart <服务名>` 或 `docker compose up -d --no-build` |
| 工作目录 | 始终在 `/opt/enterprise-ai-platform` 执行 `docker compose` |
