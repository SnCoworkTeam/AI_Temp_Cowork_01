## 🎯 平台概述

企业AI平台是一个面向企业业务流程自动化的综合性AI平台，集成了MCP工具网关、智能工作流引擎、知识库管理、统一认证授权和自动化调试等核心能力。平台采用微服务架构，支持高可用、可扩展的企业级部署。

### 核心价值

- **业务流程自动化**: 通过可视化工作流设计器，快速构建和部署业务流程自动化方案
- **AI能力集成**: 深度集成大语言模型（支持OpenAI和DeepSeek），提供智能决策和内容生成能力
- **工具生态**: 通过MCP协议统一管理各类工具，支持SAP、知识库、文档处理等企业工具集成
- **知识管理**: 企业级知识库系统，支持多格式文档管理、语义搜索和知识图谱
- **智能运维**: 自动化调试系统，智能分析错误、自动修复、持续监控

## 🚀 核心能力

### 1. MCP工具网关 (MCP Gateway)

**端口**: 8001  
**技术**: FastAPI + Python 3.11

#### 核心功能

- **工具统一管理**
  - 工具注册与发现机制
  - 工具元数据管理（名称、描述、参数、返回值）
  - 工具版本管理
  - 工具分类和标签系统

- **工具执行引擎**
  - 统一的工具调用接口
  - 参数验证和类型检查
  - 异步执行支持
  - 执行结果缓存

- **企业工具集成**
  - **SAP工具**: SAP数据查询、事务执行、报表生成
  - **知识库工具**: 文档搜索、知识图谱查询、文档管理
  - **文档处理工具**: 文档解析、格式转换、内容提取

- **监控与审计**
  - 工具执行日志记录
  - 性能指标监控（响应时间、成功率、错误率）
  - 使用统计和分析
  - 审计追踪

- **安全控制**
  - 访问权限控制
  - 速率限制（Rate Limiting）
  - 参数验证和清理
  - 执行超时控制

#### API端点

```
GET  /api/tools                    # 获取工具列表
GET  /api/tools/{tool_name}         # 获取工具详情
POST /api/tools/execute             # 执行工具
GET  /api/tools/monitoring/stats   # 工具使用统计
GET  /api/health                   # 健康检查
```

### 2. 工作流引擎 (Workflow Engine)

**端口**: 8002  
**技术**: LangGraph + LangChain + FastAPI

#### 核心功能

- **动态工作流构建**
  - 基于JSON配置的工作流定义
  - 可视化工作流设计器（前端）
  - 工作流版本管理
  - 工作流模板库

- **丰富的节点类型**
  - **LLM节点**: 调用大语言模型进行文本生成、分析、决策
  - **工具节点**: 调用MCP工具执行具体操作
  - **条件节点**: 基于条件的分支逻辑
  - **转换节点**: 数据格式转换和处理
  - **HTTP节点**: 调用外部API服务
  - **延迟节点**: 定时任务和延迟执行
  - **日志节点**: 工作流执行日志记录
  - **知识增强节点**: 从知识库获取上下文信息
  - **文档处理节点**: 文档解析和处理

- **工作流执行引擎**
  - 异步执行支持
  - 状态持久化和恢复
  - 并发执行控制
  - 超时和错误处理
  - 执行历史记录

- **智能编排能力**
  - 基于LangGraph的图执行引擎
  - 状态变量引用和传递
  - 条件分支和循环支持
  - 节点依赖管理

- **监控与分析**
  - 工作流执行性能监控
  - 节点执行时间统计
  - 错误率分析
  - 执行成功率追踪

#### 工作流示例场景

1. **SAP数据分析工作流**
   - 查询SAP数据 → LLM分析 → 生成报告 → 发送通知

2. **知识库增强问答**
   - 用户提问 → 知识库搜索 → LLM生成答案 → 返回结果

3. **文档处理流程**
   - 上传文档 → 解析内容 → 向量化存储 → 知识图谱更新

#### API端点

```
GET  /api/workflows                    # 获取工作流列表
GET  /api/workflows/{workflow_id}      # 获取工作流详情
POST /api/workflows                    # 创建工作流
PUT  /api/workflows/{workflow_id}      # 更新工作流
POST /api/workflows/{workflow_id}/execute  # 执行工作流
GET  /api/workflows/executions/{execution_id}  # 获取执行状态
GET  /api/workflows/metrics            # 工作流性能指标
```

## 🏗️ 系统架构

### 微服务架构

平台采用微服务架构，每个服务独立部署、独立扩展、独立维护。

```

│              Next.js + TypeScript + TailwindCSS             │
└───────────────────────┬─────────────────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
┌───────▼──────┐ ┌──────▼──────┐ ┌─────▼──────┐
│ Auth Service │ │MCP Gateway  │ │Workflow    │
│   (8003)     │ │   (8001)    │ │Engine(8002)│
└───────┬──────┘ └──────┬──────┘ └─────┬──────┘
        │               │               │
        └───────────────┼───────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
┌───────▼──────┐ ┌──────▼──────┐ ┌─────▼──────┐
│Knowledge Base│ │   Redis     │ │ PostgreSQL │
│   (8004)     │ │   (6379)    │ │   (5432)   │
└──────────────┘ └─────────────┘ └────────────┘
```

### 服务通信

- **RESTful API**: 服务间通过HTTP RESTful API通信
- **异步消息**: 支持异步任务队列（未来扩展）
- **服务发现**: 通过Docker网络进行服务发现

### 数据存储

- **PostgreSQL**: 业务数据持久化
  - 用户和权限数据
  - 工作流定义和执行历史
  - 知识库元数据
  - 系统配置和审计日志

- **Redis**: 缓存和会话管理
  - 用户会话缓存
  - Token缓存
  - 工作流执行状态缓存
  - 速率限制计数

- **ChromaDB**: 向量数据库
  - 文档向量索引
  - 语义搜索支持

## 🎯 应用场景

### 1. 企业业务流程自动化

**场景**: 自动化重复性业务流程，提高效率

**示例**:
- **订单处理流程**: 订单接收 → 库存检查 → 自动确认 → 发货通知
- **客户服务流程**: 客户咨询 → 知识库搜索 → AI生成回复 → 人工审核 → 发送回复
- **数据分析流程**: 数据提取 → 数据清洗 → AI分析 → 报告生成 → 邮件发送

### 2. SAP系统集成

**场景**: 通过MCP工具网关集成SAP系统，实现数据查询和事务执行

**示例**:
- **库存查询工作流**: 查询SAP库存数据 → LLM分析库存状况 → 生成预警报告
- **销售数据分析**: 提取SAP销售数据 → 数据转换 → AI生成分析报告 → 发送给管理层

### 3. 企业知识管理

**场景**: 构建企业知识库，支持智能搜索和问答

**示例**:
- **文档知识库**: 上传企业文档 → 自动解析和向量化 → 支持语义搜索
- **智能问答系统**: 用户提问 → 知识库搜索相关文档 → LLM生成答案 → 返回结果
- **知识图谱构建**: 从文档中提取实体和关系 → 构建知识图谱 → 可视化展示

### 4. 智能客服系统

**场景**: 基于知识库和AI的智能客服系统

**示例**:
- **自动问答**: 用户问题 → 知识库搜索 → AI生成回答 → 返回给用户
- **工单处理**: 用户提交工单 → 工作流分析 → 自动分类和路由 → 生成处理建议

### 5. 数据分析和报告生成

**场景**: 自动化数据分析和报告生成流程

**示例**:
- **日报生成**: 定时触发 → 数据提取 → AI分析 → 生成日报 → 自动发送
- **业务分析**: 多数据源整合 → 数据清洗 → AI分析 → 可视化报告生成
