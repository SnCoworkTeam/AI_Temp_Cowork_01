## 🔍 问题分析

### 1. 数据完整性分析

#### 1.1 实体数据检查

**检查项**:
- [ ] 实体总数是否足够

- [ ] 实体是否有related_entities字段
- [ ] 实体是否有sap_module信息

**潜在问题**:
- 如果实体数据不足，无法创建足够的关系
- 如果实体缺少关系字段，无法发现关系

#### 1.2 关系数据检查

**检查项**:
- [ ] 父子关系数量（基于parent_id）
- [ ] 关联关系数量（基于related_entities）
- [ ] 同模块关系数量（基于sap_module）

**潜在问题**:
- 如果实体缺少parent_id，无法创建父子关系
- 如果实体缺少related_entities，无法创建关联关系
- 如果实体缺少sap_module，无法创建同模块关系

---

### 2. 技术问题分析

#### 2.1 关系发现服务限制

**检查项**:
- [ ] 规则引擎是否有关系数量限制
- [ ] 同模块关系是否有限制（如最多5条）
- [ ] LLM增强是否正常工作

**潜在问题**:
- 如果规则引擎限制了关系数量，可能导致关系不足
- 如果LLM增强未启用或失败，可能缺少关系

#### 2.2 构建错误

**已知错误**:
- `target_node_id` 为 null 的错误
- 发生在创建 "mentions" 类型的边时

**影响**:
- 可能导致部分关系创建失败
- 可能导致构建过程中断

#### 2.3 关系创建逻辑

**检查项**:
- [ ] 节点查找逻辑是否正确
- [ ] 边创建验证是否过于严格
- [ ] 是否有关系去重逻辑导致关系丢失

**潜在问题**:
- 如果节点查找失败，无法创建边
- 如果验证过于严格，可能跳过有效关系
- 如果去重逻辑有问题，可能丢失关系
