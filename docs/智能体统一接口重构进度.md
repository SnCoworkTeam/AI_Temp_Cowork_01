## 📝 技术细节

### 统一接口设计

```python
class BaseAgent(ABC):
    @abstractmethod
    async def plan(
        self,
        task: str,
        context: Optional[Dict[str, Any]] = None
    ) -> Union[ExecutionPlan, AsyncIterator[str]]:
        """规划任务"""
        pass

    @abstractmethod
    async def execute(
        self,
        plan: ExecutionPlan,
        context: Optional[Dict[str, Any]] = None
    ) -> ExecutionResult:
        """执行计划"""
        pass

    async def reflect(
        self,
        result: ExecutionResult,
        context: Optional[Dict[str, Any]] = None
    ) -> Optional[Reflection]:
        """反思执行结果（可选）"""
        return None
```
