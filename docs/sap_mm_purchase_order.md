# SAP MM采购订单管理

## 概述
采购订单（Purchase Order，PO）是SAP MM模块中用于向供应商采购物料的主要单据。

## 采购订单类型

### 1. 标准采购订单
- 一次性采购
- 包含完整的采购信息
- 最常用的采购订单类型

### 2. 框架采购订单
- 长期采购协议
- 不包含具体数量和日期
- 通过后续的采购订单下达具体采购

### 3. 合同采购订单
- 长期采购合同
- 包含价格和条件
- 通过后续订单下达

### 4. 计划采购订单
- 计划性采购
- 可以转换为正式采购订单

## 采购订单结构

### 抬头信息
- 采购订单号
- 供应商
- 采购组织
- 采购组
- 订单日期
- 交货日期
- 货币
- 付款条件

### 行项目信息
- 物料号
- 物料描述
- 数量
- 单位
- 单价
- 总价
- 交货日期
- 账户分配

## 采购流程

1. **创建采购申请（PR）**
   - 内部需求申请
   - 可以手动创建或自动生成

2. **创建采购订单（PO）**
   - 基于采购申请创建
   - 或直接创建

3. **发送给供应商**
   - 打印或电子发送
   - 供应商确认

4. **收货（GR）**
   - 物料到达后收货
   - 更新库存

5. **发票校验（MIRO）**
   - 收到供应商发票
   - 与采购订单和收货单核对
   - 过账到财务

## 关键字段说明

- **采购订单号**: 系统自动生成或手动输入
- **供应商**: 必须维护供应商主数据
- **物料**: 必须维护物料主数据
- **价格**: 可以从信息记录、合同等获取
- **账户分配**: 成本中心、项目、订单等

## 相关单据

- 采购申请（PR）
- 收货单（GR）
- 发票（Invoice）
- 付款凭证（Payment）
