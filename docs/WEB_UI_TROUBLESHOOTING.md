# Web-UI 无法访问问题排查

## 当前状态

✅ **服务器端检查结果：**
- Web-UI 服务正常运行（healthy）
- 端口 3000 正在监听（0.0.0.0:3000）
- 本地连接测试成功（返回 200 OK）
- 服务日志正常，无错误

## 问题诊断

如果服务在服务器上正常运行，但外网无法访问，最可能的原因是：

### 1. 腾讯云安全组未开放 3000 端口 ⚠️

**这是最常见的原因！**

#### 解决步骤：

1. **登录腾讯云控制台**
   - 访问：https://console.cloud.tencent.com/
   - 进入：云服务器 → 实例

2. **找到你的服务器**
   - 服务器IP: `43.143.139.197`
   - 点击服务器名称进入详情

3. **配置安全组**
   - 在"安全组"标签页，点击安全组ID
   - 或直接进入：云服务器 → 安全组

4. **添加入站规则**
   - 点击"入站规则" → "添加规则"
   - 配置如下：
     ```
     类型: 自定义
     来源: 0.0.0.0/0  (或指定你的IP)
     协议端口: TCP:3000
     策略: 允许
     备注: Web UI前端
     ```

5. **保存并应用**
   - 点击"完成"
   - 规则立即生效

### 2. 检查访问URL

确保使用正确的URL：
- ✅ `http://43.143.139.197:3000`
- ✅ `http://43.143.139.197:3000/`
- ❌ `https://43.143.139.197:3000` (如果未配置SSL)

### 3. 测试外网连接

从你的本地电脑执行以下命令测试：

```bash
# 测试HTTP连接
curl http://43.143.139.197:3000

# 测试端口是否开放
telnet 43.143.139.197 3000

# 或使用PowerShell测试
Test-NetConnection -ComputerName 43.143.139.197 -Port 3000
```

**预期结果：**
- 如果安全组已配置：应该能连接并返回HTML内容
- 如果安全组未配置：连接超时或拒绝连接

### 4. 检查浏览器控制台

打开浏览器开发者工具（F12），查看：
- **Network标签**：检查请求状态码
- **Console标签**：查看是否有JavaScript错误

常见错误：
- `ERR_CONNECTION_TIMED_OUT` → 安全组未开放
- `ERR_CONNECTION_REFUSED` → 服务未运行或端口错误
- `ERR_NAME_NOT_RESOLVED` → DNS解析问题

## 快速检查清单

- [ ] 腾讯云安全组已开放 3000 端口
- [ ] 使用正确的URL: `http://43.143.139.197:3000`
- [ ] 服务器上服务正常运行（已确认 ✅）
- [ ] 本地防火墙未阻止连接
- [ ] 浏览器未使用代理或VPN

## 其他可能的问题

### 如果安全组已配置但仍无法访问：

1. **检查服务器公网IP是否正确**
   ```bash
   curl ifconfig.me
   # 应该返回: 43.143.139.197
   ```

2. **检查是否有其他防火墙**
   - 检查服务器上的 iptables 规则
   - 检查是否有云防火墙服务

3. **检查服务是否绑定到正确地址**
   ```bash
   netstat -tlnp | grep 3000
   # 应该显示: 0.0.0.0:3000
   ```
