## 附录：API接口列表

### 项目相关接口
- `GET /api/v1/projects` - 获取项目列表
- `GET /api/v1/projects/{project_id}` - 获取项目详情
- `POST /api/v1/projects` - 创建项目
- `PUT /api/v1/projects/{project_id}` - 更新项目
- `DELETE /api/v1/projects/{project_id}` - 删除项目
- `POST /api/v1/projects/import/excel` - 导入项目

### 项目群相关接口
- `GET /api/v1/programs` - 获取项目群列表
- `GET /api/v1/programs/{program_id}` - 获取项目群详情
- `POST /api/v1/programs` - 创建项目群
- `PUT /api/v1/programs/{program_id}` - 更新项目群
- `DELETE /api/v1/programs/{program_id}` - 删除项目群

### 任务相关接口
- `GET /api/v1/tasks` - 获取任务列表
- `POST /api/v1/tasks` - 创建任务
- `PUT /api/v1/tasks/{task_id}` - 更新任务
- `DELETE /api/v1/tasks/{task_id}` - 删除任务

### 周报相关接口
- `GET /api/v1/weekly-reports` - 获取周报列表
- `POST /api/v1/weekly-reports` - 创建周报
- `PUT /api/v1/weekly-reports/{report_id}` - 更新周报

### 项目计划相关接口
- `GET /api/v1/projects/{project_id}/plans` - 获取项目计划列表
- `POST /api/v1/projects/{project_id}/plans` - 创建项目计划
- `PUT /api/v1/project-plans/{plan_id}` - 更新项目计划
