# SSH智能体演示任务

## 推荐演示任务

### 任务1：查看服务器系统信息和项目状态（推荐）
```
请帮我查看服务器的系统信息，包括：
1. 系统版本和内核信息
2. 当前磁盘使用情况
3. /opt/enterprise-ai-platform 目录下的主要文件和目录
4. 检查 docker-compose 服务运行状态
```

### 任务2：查看项目日志（简单快速）
```
请查看 agent-service 服务的最新日志，显示最后20行
```

### 任务3：检查服务健康状态（实用）
```
请检查以下服务的运行状态：
1. agent-service 容器状态
2. web-ui 容器状态
3. 显示各服务占用的内存和CPU
```

### 任务4：查看项目结构（展示能力）
```
请列出 /opt/enterprise-ai-platform 目录下的主要子目录，
并显示每个目录的大小和文件数量
```

### 任务5：创建测试文件并验证（完整流程）
```
请在 /opt/enterprise-ai-platform 目录下创建一个测试文件 test_ssh_agent.txt，
内容为 "SSH智能体测试成功 - $(date)"，
然后读取文件内容确认创建成功
```

## 最佳演示任务（推荐使用）

**任务描述：**
```
请帮我执行以下操作：
1. 显示当前系统时间和服务器基本信息
2. 查看 /opt/enterprise-ai-platform 目录结构（只显示一级目录）
3. 检查 agent-service 和 web-ui 两个容器的运行状态
4. 显示这两个服务的最新日志各5行
```

**预期效果：**
- 可以看到系统信息
- 可以看到项目目录结构
- 可以看到服务状态
- 可以看到服务日志
- 展示SSH智能体的多步骤执行能力

## 使用说明

1. 在智能体详情页的"任务描述"输入框中输入上述任一任务
2. 点击"执行"按钮
3. 等待执行完成
4. 在"执行结果"区域查看输出

## 注意事项

- 所有操作都限制在 /opt/enterprise-ai-platform 目录下
- 不会执行危险命令（如 rm -rf /）
- 执行结果会显示命令输出和状态
