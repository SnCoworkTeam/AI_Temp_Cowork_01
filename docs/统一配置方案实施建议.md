## 实施步骤

### 第一步: 创建配置包（推荐立即实施）

#### 1.1 创建目录结构

```bash
mkdir -p config-standards/packages/{eslint-config,prettier-config,typescript-config,python-config}
mkdir -p config-standards/templates/{.husky,.vscode}
```

#### 1.2 创建ESLint配置包

```javascript
// config-standards/packages/eslint-config/package.json
{
  "name": "@enterprise-ai/eslint-config",
  "version": "1.0.0",
  "main": "index.js",
  "dependencies": {
    "@typescript-eslint/eslint-plugin": "^6.0.0",
    "@typescript-eslint/parser": "^6.0.0",
    "eslint-config-next": "^14.0.0",
    "eslint-config-prettier": "^9.0.0"
  }
}
```

```javascript
// config-standards/packages/eslint-config/index.js
module.exports = {
  extends: [
    'eslint:recommended',
    'plugin:@typescript-eslint/recommended',
    'next/core-web-vitals',
    'prettier'
  ],
  parser: '@typescript-eslint/parser',
  plugins: ['@typescript-eslint'],
  rules: {
    '@typescript-eslint/no-unused-vars': ['error', {
      argsIgnorePattern: '^_',
      varsIgnorePattern: '^_'
    }],
    '@typescript-eslint/no-explicit-any': 'warn',
    'react-hooks/exhaustive-deps': 'warn',
    'react/no-unescaped-entities': 'off',
    'no-console': ['warn', { allow: ['warn', 'error'] }],
    '@typescript-eslint/explicit-function-return-type': 'off',
    '@typescript-eslint/explicit-module-boundary-types': 'off',
  },
  ignorePatterns: ['dist', 'node_modules', '.next', 'out'],
};
```

#### 1.3 创建Prettier配置包

```javascript
// config-standards/packages/prettier-config/index.js
module.exports = {
  semi: true,
  trailingComma: 'es5',
  singleQuote: true,
  printWidth: 100,
  tabWidth: 2,
  useTabs: false,
  endOfLine: 'lf',
  arrowParens: 'always',
  bracketSpacing: true,
  jsxSingleQuote: false,
};
```

#### 1.4 创建Python配置包

```toml
# config-standards/packages/python-config/pyproject.toml
[tool.black]
line-length = 120
target-version = ['py310']
include = '\.pyi?$'

[tool.isort]
profile = "black"
line_length = 120
known_first_party = ["database", "project_management"]

[tool.ruff]
line-length = 120
target-version = "py310"

[tool.ruff.lint]
select = ["E", "F", "W", "I"]
ignore = ["E501", "W503", "E203"]

[tool.mypy]
python_version = "3.10"
ignore_missing_imports = true
show_error_codes = true
warn_return_any = true
disallow_untyped_defs = false
```

```ini
# config-standards/packages/python-config/mypy.ini
[mypy]
python_version = 3.10
ignore_missing_imports = True
follow_imports = normal
show_error_codes = True

[mypy-database.*]
ignore_missing_imports = True

[mypy-*.routes.*]
ignore_missing_imports = False
disallow_untyped_defs = False
```

### 第二步: 应用到现有服务

#### 2.1 更新前端服务 (web-ui)

**package.json**:
```json
{
  "devDependencies": {
    "@enterprise-ai/eslint-config": "workspace:*",
    "@enterprise-ai/prettier-config": "workspace:*",
    "prettier": "^3.0.0",
    "husky": "^9.0.0",
    "lint-staged": "^15.0.0"
  }
}
```

**.eslintrc.json**:
```json
{
  "extends": ["@enterprise-ai/eslint-config"]
}
```

**.prettierrc.js** (新建):
```javascript
module.exports = require('@enterprise-ai/prettier-config');
```

#### 2.2 更新后端服务 (project_management)

**复制Python配置**:
```bash
cp config-standards/packages/python-config/pyproject.toml project_management/
cp config-standards/packages/python-config/mypy.ini project_management/
```

### 第三步: 配置Git钩子

#### 3.1 安装Husky

```bash
cd web-ui
npm install --save-dev husky lint-staged
npx husky init
```

#### 3.2 配置lint-staged

```javascript
// web-ui/.lintstagedrc.js
module.exports = {
  '*.{js,jsx,ts,tsx}': [
    'prettier --write',
    'eslint --fix',
    'eslint',
  ],
  '*.{css,scss,less,md,json}': [
    'prettier --write',
  ],
};
```

#### 3.3 配置pre-commit钩子

```bash
# web-ui/.husky/pre-commit
#!/usr/bin/env sh
. "$(dirname "$0")/_/husky.sh"

npx lint-staged
```

## 风险评估与应对

### 风险1: 团队接受度

**风险**: 团队成员可能不适应新规范

**应对**:
- 提供详细文档
- 组织培训会议
- 设置过渡期
- 逐步启用严格规则

### 风险2: 现有代码冲突

**风险**: 现有代码可能不符合新规范

**应对**:
- 使用 `--fix` 自动修复
- 设置宽松的初始规则
- 逐步收紧规则
- 允许例外情况

### 风险3: 配置维护

**风险**: 配置包需要持续维护

**应对**:
- 指定维护负责人
- 建立更新流程
- 版本化管理
- 定期审查规则
