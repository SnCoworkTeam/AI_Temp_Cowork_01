# 项目计划表格组件分析报告

## 一、现有实现分析

### 当前使用的组件
- **Ant Design Table** + **@dnd-kit** (拖拽)
- 位置：`web-ui/src/components/ProjectPlans/PlanTreeTable.tsx`

### 现有功能
✅ 树形结构展示（expandable）
✅ 拖拽排序（@dnd-kit）
✅ 内联编辑（点击单元格进入编辑模式）
✅ 操作按钮（添加、编辑、删除）

### 现有问题
❌ **编辑体验不够Excel化**：
   - 需要点击单元格 → 显示编辑控件 → 编辑 → 保存
   - 不能像Excel那样直接输入就开始编辑
   - 不支持Tab键快速切换单元格

❌ **增删改查不够直观**：
   - 添加任务需要点击按钮跳转页面
   - 删除需要点击按钮确认
   - 不能直接在表格内快速操作

❌ **缺少Excel常用功能**：
   - 不支持复制粘贴
   - 不支持批量编辑
   - 不支持列排序/筛选
   - 不支持单元格公式

## 二、组件方案对比

### 方案1: react-data-grid (推荐⭐⭐⭐⭐⭐)

**优点**：
- ✅ 轻量级（~200KB）
- ✅ 完全开源免费
- ✅ 支持内联编辑（双击或直接输入）
- ✅ 支持树形结构
- ✅ 支持虚拟滚动（性能好）
- ✅ 支持列排序、筛选
- ✅ 支持复制粘贴
- ✅ 支持键盘导航（Tab、Enter、方向键）
- ✅ 与React 18完全兼容
- ✅ TypeScript支持良好

**缺点**：
- ❌ 需要自己实现拖拽功能（可配合@dnd-kit）
- ❌ 样式需要自定义（但支持CSS定制）

**安装**：
```bash
npm install react-data-grid
```

**示例代码**：
```tsx
import DataGrid from 'react-data-grid';

const columns = [
  { key: 'name', name: '名称', editable: true },
  { key: 'assignee', name: '负责人', editable: true },
  { key: 'progress', name: '进度', editable: true },
];

function PlanDataGrid({ rows, onRowsChange }) {
  return (
    <DataGrid
      columns={columns}
      rows={rows}
      onRowsChange={onRowsChange}
      defaultColumnOptions={{ resizable: true, sortable: true }}
      treeData={true} // 支持树形结构
    />
  );
}
```

## 四、代码示例

### 基础实现

```tsx
'use client';

import DataGrid, { Column, Row } from 'react-data-grid';
import { useMemo, useState } from 'react';

interface PlanRow {
  id: string;
  name: string;
  type: 'phase' | 'task';
  assignee?: string;
  progress: number;
  status: string;
  children?: PlanRow[];
}

const columns: Column<PlanRow>[] = [
  {
    key: 'name',
    name: '名称',
    editable: true,
    width: 300,
    renderCell: ({ row }) => (
      <div className="flex items-center gap-2">
        {row.type === 'phase' ? '📁' : '📄'}
        <span>{row.name}</span>
      </div>
    ),
  },
  {
    key: 'assignee',
    name: '负责人',
    editable: true,
    width: 120,
  },
  {
    key: 'progress',
    name: '进度',
    editable: true,
    width: 150,
    renderCell: ({ row }) => (
      <div className="flex items-center gap-2">
        <progress value={row.progress} max={100} />
        <span>{row.progress}%</span>
      </div>
    ),
  },
  {
    key: 'status',
    name: '状态',
    editable: true,
    width: 120,
  },
];

export default function PlanExcelTable({ tree, onUpdate }) {
  const [rows, setRows] = useState<PlanRow[]>(tree);

  // 将树形数据扁平化（react-data-grid会自动处理树形）
  const flatRows = useMemo(() => {
    const flatten = (nodes: PlanRow[], level = 0): PlanRow[] => {
      const result: PlanRow[] = [];
      for (const node of nodes) {
        result.push({ ...node, level });
        if (node.children) {
          result.push(...flatten(node.children, level + 1));
        }
      }
      return result;
    };
    return flatten(rows);
  }, [rows]);

  const handleRowsChange = (newRows: Row[]) => {
    setRows(newRows as PlanRow[]);
    onUpdate?.(newRows);
  };

  return (
    <DataGrid
      columns={columns}
      rows={flatRows}
      onRowsChange={handleRowsChange}
      defaultColumnOptions={{
        resizable: true,
        sortable: true,
      }}
      style={{ height: '100%', minHeight: 400 }}
    />
  );
}
```

### 增强功能实现

```tsx
// 支持树形结构
<DataGrid
  columns={columns}
  rows={rows}
  onRowsChange={handleRowsChange}
  treeData={true} // 启用树形结构
  defaultExpandedGroupIds={new Set(['phase-1', 'phase-2'])} // 默认展开
/>

// 支持复制粘贴
<DataGrid
  columns={columns}
  rows={rows}
  onRowsChange={handleRowsChange}
  enableCellCopyPaste={true} // 启用复制粘贴
/>

// 支持列筛选
<DataGrid
  columns={columns}
  rows={rows}
  onRowsChange={handleRowsChange}
  enableColumnFilters={true} // 启用列筛选
/>
```
