# 防火墙端口配置说明

## 端口开放策略

### ✅ 对外开放的端口（外网访问）

以下端口需要在**腾讯云安全组**中开放：

| 端口 | 服务 | 说明 |
|------|------|------|
| 3000 | web-ui | 前端Web界面 |
| 8001 | mcp-gateway | MCP API网关 |
| 8002 | workflow-engine | 工作流引擎 |
| 8003 | auth-service | 认证服务 |
| 8004 | knowledge-base | 知识库服务 |
| 8005 | metadata-service | 元数据服务 |

### 🔒 仅本地访问的端口（已配置）

以下端口已配置为仅绑定到 `127.0.0.1`，不对外开放：

| 端口 | 服务 | 说明 |
|------|------|------|
| 5432 | postgres | PostgreSQL数据库（仅内网访问） |
| 6379 | redis | Redis缓存（仅内网访问） |
| 8081 | redis-commander | Redis管理工具（仅内网访问） |

## 腾讯云安全组配置

### 入站规则配置

在腾讯云控制台 → 云服务器 → 安全组中，添加以下入站规则：

```
协议类型: TCP
端口范围: 3000
来源: 0.0.0.0/0
策略: 允许
备注: Web UI前端

协议类型: TCP
端口范围: 8001
来源: 0.0.0.0/0
策略: 允许
备注: MCP Gateway

协议类型: TCP
端口范围: 8002
来源: 0.0.0.0/0
策略: 允许
备注: Workflow Engine

协议类型: TCP
端口范围: 8003
来源: 0.0.0.0/0
策略: 允许
备注: Auth Service

协议类型: TCP
端口范围: 8004
来源: 0.0.0.0/0
策略: 允许
备注: Knowledge Base

协议类型: TCP
端口范围: 8005
来源: 0.0.0.0/0
策略: 允许
备注: Metadata Service
```

### 出站规则

建议保持默认的"允许所有"策略，以便服务可以正常访问外部API。

## 验证端口配置

### 检查端口绑定

```bash
# 检查应用端口（应该绑定到 0.0.0.0）
sudo netstat -tlnp | grep -E ':(3000|8001|8002|8003|8004|8005)'

# 检查数据库端口（应该只绑定到 127.0.0.1）
sudo netstat -tlnp | grep -E ':(5432|6379|8081)'
```

## 安全建议

1. **最小权限原则**：只开放必要的端口
2. **数据库安全**：数据库端口仅绑定到本地，不对外开放
3. **定期审查**：定期检查安全组规则，移除不必要的开放端口
4. **IP白名单**：如果可能，建议将API端口（8001-8005）限制为特定IP访问
5. **HTTPS**：生产环境建议使用HTTPS（443端口）并配置SSL证书
