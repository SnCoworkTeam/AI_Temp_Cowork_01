## 🎯 技术实现

### 集成策略

1. **可选集成**
   - 默认启用向量协调服务（如果可用）
   - 如果向量服务不可用，自动降级到常规搜索
   - 保证服务可用性

2. **结果融合**
   - 常规搜索结果 + 向量搜索结果
   - 基于entity_uri去重
   - 统一按相似度排序

3. **性能优化**
   - 向量搜索独立超时（1秒）
   - 不影响常规搜索性能
   - 并行执行
