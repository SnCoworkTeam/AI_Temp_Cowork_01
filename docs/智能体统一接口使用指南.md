# 智能体统一接口使用指南

## 📖 概述

所有智能体现在都使用统一的接口：`plan()`, `execute()`, `reflect()`。这提供了：
- ✅ 统一的接口，易于扩展
- ✅ 统一的数据格式（ExecutionPlan, ExecutionResult）
- ✅ 状态管理（AgentState）
- ✅ 向后兼容（旧接口仍然可用）

## 🚀 快速开始

### 使用统一接口

```python
from src.core.agents import ServerOperationAgent, AnalysisAgent

# 创建智能体
agent = ServerOperationAgent(ssh_config={...}, agent_config={...})

# 方式1：使用plan_and_execute（推荐）
result = await agent.plan_and_execute(
    task="查看服务器信息",
    context={"project_id": "123"},
    auto_execute=True
)

# 方式2：分步执行
plan = await agent.plan("查看服务器信息")
result = await agent.execute(plan, context={"project_id": "123"})
```

### 使用旧接口（向后兼容）

```python
# 旧接口仍然可用
result = await agent.process_request(
    user_request="查看服务器信息",
    project_id="123",
    context={...},
    auto_execute=True
)
```

## 📋 API参考

### BaseAgent基类

所有智能体都继承自`BaseAgent`，实现以下方法：

#### `plan(task, context) -> ExecutionPlan`

规划任务，生成执行计划。

**参数**:
- `task: str` - 任务描述
- `context: Optional[Dict[str, Any]]` - 上下文信息

**返回**:
- `ExecutionPlan` - 执行计划
- 或 `AsyncIterator[str]` - 流式输出（如果支持）

#### `execute(plan, context) -> ExecutionResult`

执行计划。

**参数**:
- `plan: ExecutionPlan` - 执行计划
- `context: Optional[Dict[str, Any]]` - 上下文信息

**返回**:
- `ExecutionResult` - 执行结果

#### `plan_and_execute(task, context, auto_execute, stream) -> Dict | AsyncIterator`

规划并执行任务（便捷方法）。

**参数**:
- `task: str` - 任务描述
- `context: Optional[Dict[str, Any]]` - 上下文信息
- `auto_execute: bool = True` - 是否自动执行
- `stream: bool = False` - 是否流式输出

**返回**:
- `Dict[str, Any]` - 包含plan和execution_result的字典
- 或 `AsyncIterator[str]` - 流式输出

### ExecutionPlan数据类

```python
@dataclass
class ExecutionPlan:
    plan_name: str
    description: str
    execution_mode: str  # single, sequence, dynamic
    commands: List[str] = []  # SSH命令（SSH智能体使用）
    steps: List[Dict[str, Any]] = []  # 通用步骤（其他智能体使用）
    expected_outcomes: List[str] = []
    rollback_commands: Optional[List[str]] = None
    dependencies: List[str] = []
    metadata: Dict[str, Any] = {}
```

### ExecutionResult数据类

```python
@dataclass
class ExecutionResult:
    plan_name: str
    success: bool
    commands_executed: int = 0  # SSH命令数量
    commands_succeeded: int = 0
    steps_executed: int = 0  # 通用步骤数量
    steps_succeeded: int = 0
    results: List[Dict[str, Any]] = []
    error: Optional[str] = None
    summary: Optional[str] = None
    execution_time: float = 0.0
    metadata: Dict[str, Any] = {}
```

### AgentState枚举

```python
class AgentState(str, Enum):
    IDLE = "idle"
    PLANNING = "planning"
    EXECUTING = "executing"
    REFLECTING = "reflecting"
    WAITING = "waiting"
    COMPLETED = "completed"
    FAILED = "failed"
```

## 💡 使用示例

### 示例1：SSH智能体

```python
from src.core.agents import ServerOperationAgent
import os

# 创建SSH智能体
ssh_config = {
    "host": "43.143.139.197",
    "username": "ubuntu",
    "private_key_path": "/path/to/key.pem",
    "base_workdir": "/opt/enterprise-ai-platform"
}

agent = ServerOperationAgent(
    ssh_config=ssh_config,
    agent_config={"llm_model": "deepseek-reasoner"}
)

# 执行任务
result = await agent.plan_and_execute(
    task="查看服务器系统信息",
    context={"project_id": "123"},
    auto_execute=True
)

print(f"执行成功: {result['execution_result']['success']}")
print(f"摘要: {result['execution_result']['summary']}")
```

### 示例2：数据分析智能体

```python
from src.core.agents import AnalysisAgent

agent = AnalysisAgent()

# 规划任务
plan = await agent.plan("分析销售数据趋势")

# 执行分析（需要提供数据）
result = await agent.execute(
    plan,
    context={
        "data": [
            {"month": "2024-01", "sales": 1000},
            {"month": "2024-02", "sales": 1200}
        ]
    }
)

print(f"分析成功: {result.success}")
print(f"结果: {result.results}")
```

### 示例3：流式输出

```python
# SSH智能体支持流式输出
async for chunk in agent.plan_and_execute(
    task="执行复杂任务",
    context={...},
    auto_execute=True,
    stream=True
):
    print(chunk, end='', flush=True)
```

### 示例4：使用适配器（旧智能体）

```python
from src.core.agents import AgentAdapter
from src.core.agents.workflow_agent import WorkflowAgent

# 创建旧智能体
legacy_agent = WorkflowAgent()

# 使用适配器
adapter = AgentAdapter(legacy_agent)

# 现在可以使用统一接口
result = await adapter.plan_and_execute("执行工作流", context={...})
```

## 🔄 迁移指南

### 从旧接口迁移到新接口

**旧代码**:
```python
result = await agent.execute(
    input_data={"task": "分析数据"},
    context={...}
)
```

**新代码**:
```python
# 方式1：使用plan_and_execute
result = await agent.plan_and_execute(
    task="分析数据",
    context={...}
)

# 方式2：分步执行
plan = await agent.plan("分析数据")
result = await agent.execute(plan, context={...})
```

### 兼容性说明

- ✅ 所有旧方法都保留，现有代码无需修改
- ✅ `AgentManager` 自动适配新旧接口
- ✅ 旧智能体可以通过`AgentAdapter`使用统一接口

## 🛠️ 实现新智能体

### 继承BaseAgent

```python
from src.core.agents.unified_base_agent import BaseAgent, ExecutionPlan, ExecutionResult, AgentState

class MyAgent(BaseAgent):
    def __init__(self):
        super().__init__(
            agent_id="my_agent",
            name="我的智能体",
            description="智能体描述",
            capabilities={"capability1": "能力1"}
        )

    async def plan(self, task: str, context: Optional[Dict] = None) -> ExecutionPlan:
        """规划任务"""
        self.set_state(AgentState.PLANNING)
        # ... 规划逻辑 ...
        plan = ExecutionPlan(
            plan_name="我的计划",
            description=task,
            execution_mode="sequence",
            steps=[...]
        )
        self.set_state(AgentState.IDLE)
        return plan

    async def execute(self, plan: ExecutionPlan, context: Optional[Dict] = None) -> ExecutionResult:
        """执行计划"""
        self.set_state(AgentState.EXECUTING)
        # ... 执行逻辑 ...
        result = ExecutionResult(
            plan_name=plan.plan_name,
            success=True,
            steps_executed=1,
            steps_succeeded=1,
            results=[...],
            summary="执行完成"
        )
        self.set_state(AgentState.COMPLETED)
        return result
```

## 📊 状态管理

### 获取状态

```python
state = agent.get_state()
print(f"当前状态: {state.value}")
```

### 状态转换

智能体会自动管理状态，但也可以手动设置：

```python
agent.set_state(AgentState.PLANNING)
# ... 执行规划 ...
agent.set_state(AgentState.EXECUTING)
# ... 执行任务 ...
agent.set_state(AgentState.COMPLETED)
```

## 🔍 调试和测试

### 检查智能体类型

```python
from src.core.agents.unified_base_agent import BaseAgent

if isinstance(agent, BaseAgent):
    print("支持统一接口")
    result = await agent.plan_and_execute(...)
else:
    print("使用旧接口或适配器")
```

### 测试统一接口

```python
# 测试plan方法
plan = await agent.plan("测试任务")
assert isinstance(plan, ExecutionPlan)

# 测试execute方法
result = await agent.execute(plan, {})
assert isinstance(result, ExecutionResult)

# 测试plan_and_execute
result_dict = await agent.plan_and_execute("测试任务", {})
assert "plan" in result_dict
assert "execution_result" in result_dict
```

## ⚠️ 注意事项

1. **向后兼容**: 所有旧方法都保留，现有代码无需修改
2. **状态管理**: 智能体会自动管理状态，但要注意异常情况
3. **错误处理**: 统一接口返回`ExecutionResult`，包含错误信息
4. **流式输出**: 只有部分智能体支持流式输出（如SSH智能体）
