## 📊 已实现的接口清单

### 项目计划CRUD（5个）

1. ✅ `GET /api/v1/projects/{project_id}/plans` - 获取计划列表
2. ✅ `GET /api/v1/projects/{project_id}/plans/{plan_id}` - 获取计划详情
3. ✅ `POST /api/v1/projects/{project_id}/plans` - 创建计划（支持模板）
4. ✅ `PUT /api/v1/projects/{project_id}/plans/{plan_id}` - 更新计划
5. ✅ `DELETE /api/v1/projects/{project_id}/plans/{plan_id}` - 删除计划

### 项目模板CRUD（5个）

1. ✅ `GET /api/v1/project-templates` - 获取模板列表
2. ✅ `GET /api/v1/project-templates/{id}` - 获取模板详情
3. ✅ `POST /api/v1/project-templates` - 创建模板
4. ✅ `PUT /api/v1/project-templates/{id}` - 更新模板
5. ✅ `DELETE /api/v1/project-templates/{id}` - 删除模板

### 计划任务操作（4个）

1. ✅ `POST /api/v1/projects/{project_id}/plans/{plan_id}/tasks` - 创建任务
2. ✅ `PUT /api/v1/projects/{project_id}/plans/{plan_id}/tasks/{task_id}` - 更新任务
3. ✅ `DELETE /api/v1/projects/{project_id}/plans/{plan_id}/tasks/{task_id}` - 删除任务
4. ✅ `PATCH /api/v1/projects/{project_id}/plans/{plan_id}/tasks/{task_id}/move` - 移动任务
