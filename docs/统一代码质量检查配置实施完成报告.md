## 🚀 下一步操作

### 1. 安装前端依赖

```bash
cd web-ui
npm install
```

这将安装新添加的依赖：
- prettier
- eslint-config-prettier
- husky
- lint-staged

### 2. 初始化Husky

```bash
cd web-ui
npx husky init
```

### 3. 配置pre-commit钩子

复制模板文件内容到 `.husky/pre-commit`:

```bash
# 方法1: 手动复制
cat config-standards/templates/.husky/pre-commit > web-ui/.husky/pre-commit

# 方法2: 在web-ui目录执行
cd web-ui
npx husky add .husky/pre-commit "npx lint-staged"
```

### 4. 测试配置

#### 前端测试

```bash
cd web-ui

# 检查ESLint
npm run lint

# 格式化代码
npx prettier --write "src/**/*.{ts,tsx,js,jsx}"

# 检查TypeScript
npx tsc --noEmit
```

#### 后端测试

```bash
cd project_management

# 格式化代码
black --check src/

# 排序导入
isort --check-only src/

# 静态分析
ruff check src/

# 类型检查
mypy src/ --config-file mypy.ini
```

### 5. 验证Git钩子

```bash
cd web-ui

# 创建一个测试提交
git add .
git commit -m "test: 测试代码质量检查"

# 应该会自动运行lint-staged
```
