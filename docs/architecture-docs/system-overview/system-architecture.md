# 系统架构概览

## 系统整体架构

企业AI平台采用微服务架构，包含以下核心组件：

```
┌─────────────────────────────────────────────────────────┐
│                    Web UI (Next.js)                      │
│                  Port: 3000                             │
└──────────────────────┬──────────────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
┌───────▼──────┐ ┌─────▼──────┐ ┌─────▼──────┐
│ MCP Gateway  │ │  Workflow  │ │    Auth    │
│   Port:8000  │ │   Engine   │ │  Service   │
│              │ │ Port:8001  │ │ Port:8002  │
└───────┬──────┘ └─────┬──────┘ └─────┬──────┘
        │               │               │
        └───────────────┼───────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
┌───────▼──────┐ ┌─────▼──────┐ ┌─────▼──────┐ ┌─────▼──────┐
│  Knowledge   │ │  Metadata  │ │ PostgreSQL  │ │   Redis    │
│    Base      │ │  Service   │ │   Port:5432 │ │ Port:6379  │
│ Port:8004    │ │ Port:8005  │ └─────────────┘ └────────────┘
└──────────────┘ └─────────────┘
```

## 核心服务

### 1. MCP Gateway (端口: 8000)
- **职责**: MCP工具的统一网关
- **功能**:
  - 工具注册和发现
  - 工具执行路由
  - 参数验证
  - 执行监控和审计

### 2. Workflow Engine (端口: 8001)
- **职责**: 工作流编排和执行
- **功能**:
  - 工作流定义管理
  - 工作流执行引擎
  - 节点执行管理
  - 状态持久化

### 3. Auth Service (端口: 8002)
- **职责**: 认证和授权
- **功能**:
  - SSO单点登录
  - JWT token管理
  - 用户权限管理
  - 会话管理

### 4. Knowledge Base (端口: 8004)
- **职责**: 知识库管理
- **功能**:
  - 文档上传和解析
  - 向量索引构建
  - 语义搜索
  - 知识图谱管理

### 5. Metadata Service (端口: 8005)
- **职责**: 元数据管理和数据血缘追踪
- **功能**:
  - 数据资产、AI模型、业务实体、工作流元数据管理
  - 数据血缘追踪和管理
  - 元数据自动采集
  - 数据质量指标管理和监控
  - 元数据搜索和发现

### 6. Web UI (端口: 3000)
- **职责**: 前端用户界面
- **技术**: Next.js + TypeScript + TailwindCSS
- **功能**:
  - 工作流设计器
  - 聊天界面
  - 管理后台
  - 数据库管理
  - 自动化调试决策面板

### 7. 自动化调试系统 (auto_debug)
- **职责**: 智能错误分析和自动修复
- **位置**: `src/auto_debug/`
- **核心模块**:
  - 平台错误分析器：智能识别错误模式和根因
  - 修复策略管理：管理修复策略库和自动选择
  - 调试协调器：协调整个调试过程
  - 测试验证器：验证修复效果
  - 部署管理器：智能部署和回滚
  - 平台监控器：监控集成和告警处理
- **功能**:
  - 错误检测和分析
  - 自动修复策略执行
  - 人工决策支持
  - 修复效果验证
  - 部署管理
  - 监控和告警

## 数据存储

### PostgreSQL
- 用户和权限数据
- 工作流定义和执行历史
- 知识库元数据
- 元数据服务数据（数据资产、AI模型、业务实体、工作流元数据、数据血缘）
- 系统配置和审计日志

### Redis
- 用户会话缓存
- Token缓存
- 工作流执行状态缓存
- 速率限制计数

### 向量数据库
- 文档向量索引
- 语义搜索支持

## 共享组件

### Shared Libraries
- 统一日志记录
- 错误处理
- HTTP客户端
- 数据模型定义

## 通信方式

- **服务间通信**: RESTful API
- **前端通信**: HTTP/HTTPS
- **实时通信**: WebSocket（可选）

## 部署架构

- **开发环境**: Docker Compose
- **生产环境**: Kubernetes（推荐）
- **容器化**: 每个服务独立容器
- **服务发现**: 通过环境变量配置

## 安全架构

- **认证**: JWT Token
- **授权**: RBAC（基于角色的访问控制）
- **API安全**: HTTPS、CORS、速率限制
- **数据安全**: 加密存储、敏感数据脱敏
