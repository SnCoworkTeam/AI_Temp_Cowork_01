# 设计模式

本文档记录项目中使用的设计模式和最佳实践。

## 目录

- [Repository模式](./repository-pattern.md) - 数据访问层抽象
- [Service层模式](./service-layer-pattern.md) - 业务逻辑封装
- [Middleware模式](./middleware-pattern.md) - 横切关注点处理

## 设计原则

1. **单一职责原则**: 每个类/函数只负责一个功能
2. **开闭原则**: 对扩展开放，对修改关闭
3. **依赖倒置原则**: 依赖抽象而非具体实现
4. **接口隔离原则**: 使用多个专门的接口

## 最佳实践

- 使用依赖注入管理依赖
- 使用工厂模式创建对象
- 使用策略模式处理算法变体
- 使用观察者模式处理事件
