## 🔧 如何应用统一配置

### 方案1: 直接引用（推荐）

#### 前端

1. **修改 `.eslintrc.json`**:
```json
{
  "extends": [
    "../config-standards/packages/eslint-config",
    "next/core-web-vitals"
  ],
  "rules": {
    // 项目特定规则覆盖
  }
}
```

2. **创建 `.prettierrc.js`**:
```javascript
module.exports = require('../config-standards/packages/prettier-config');
```

3. **修改 `tsconfig.json`**:
```json
{
  "extends": "../config-standards/packages/typescript-config/tsconfig.base.json",
  "compilerOptions": {
    // 项目特定配置
  }
}
```

#### 后端

1. **使用统一配置**:
```bash
# 方式1: 复制配置
cp config-standards/packages/python-config/pyproject.toml project_management/pyproject.toml

# 方式2: 使用符号链接（Windows需要管理员权限）
# mklink project_management\pyproject.toml config-standards\packages\python-config\pyproject.toml
```

2. **修改项目特定配置**:
在 `pyproject.toml` 中添加项目特定的 `known_first_party` 等配置

### 方案2: 发布为npm包（适用于多项目）

1. **发布配置包**:
```bash
cd config-standards/packages/eslint-config
npm publish --access public
```

2. **在各项目中安装**:
```bash
cd web-ui
npm install --save-dev @enterprise-ai/eslint-config
```

3. **引用配置**:
```json
{
  "extends": ["@enterprise-ai/eslint-config"]
}
```
