**日期**: 2025-12-07

---

## 发现的问题

服务器上未找到 `docker-compose` 命令，可能使用以下方式之一：

1. **Docker Compose V2** - 使用 `docker compose`（作为Docker子命令）
2. **直接使用Docker** - 服务可能直接通过 `docker run` 启动
3. **Systemd服务** - 服务可能通过systemd管理
4. **其他编排工具** - 可能使用Kubernetes或其他工具

---

## 服务重启方法

### 方法1: 使用Docker Compose V2
```bash
cd /opt/enterprise-ai-platform
docker compose restart metadata-service api-gateway
docker compose ps
```

### 方法2: 直接使用Docker
```bash
# 查找容器
docker ps -a | grep -E 'metadata|api-gateway'

# 重启容器
docker restart <container_name>

# 或通过名称模式重启
docker ps --filter 'name=metadata-service' --format '{{.Names}}' | xargs docker restart
docker ps --filter 'name=api-gateway' --format '{{.Names}}' | xargs docker restart
```

### 方法3: 使用Systemd
```bash
# 检查服务
systemctl status enterprise-ai-platform
systemctl status metadata-service
systemctl status api-gateway

# 重启服务
sudo systemctl restart enterprise-ai-platform
sudo systemctl restart metadata-service
sudo systemctl restart api-gateway
```

### 方法4: 重新启动容器
```bash
# 停止并启动
docker stop metadata-service api-gateway
docker start metadata-service api-gateway

# 或使用docker-compose.yml重新创建
cd /opt/enterprise-ai-platform
docker compose down metadata-service api-gateway
docker compose up -d metadata-service api-gateway
```

## 检查服务状态

### 检查Docker容器
```bash
# 查看所有容器
docker ps -a

# 查看特定服务
docker ps | grep -E 'metadata|api-gateway'

# 查看容器日志
docker logs metadata-service --tail=50
docker logs api-gateway --tail=50
```

### 检查服务健康
```bash
# 检查API端点
curl http://localhost:8000/health
curl http://localhost:8000/api/health

# 检查端口监听
netstat -tlnp | grep -E '8000|8001'
ss -tlnp | grep -E '8000|8001'
```
