## 2. 数据存储策略

### 2.1 PostgreSQL存储（实体元数据）

**存储内容**:
- 组织单元、业务角色
- 业务流程、业务能力、业务服务
- 应用系统、应用服务、API接口
- 数据实体、数据模型、数据流
- 技术类型、技术实例、技术组件

**特点**:
- 结构化数据
- 支持ACID事务
- 支持复杂SQL查询
- 存储实体属性

### 2.2 Neo4j存储（关系数据）

**存储内容**:
- 组织层级关系
- 业务流程关系
- 应用系统依赖关系
- 技术实例使用关系
- 跨层架构关系

**特点**:
- 图结构数据
- 支持图遍历
- 支持路径查询
- 支持影响分析

### 2.3 数据关联

**关联方式**:
- PostgreSQL中的每个实体都有`neo4j_node_id`字段
- 通过UUID和neo4j_node_id实现双向关联


**检查Neo4j**:
```cypher
MATCH (n) RETURN count(n) AS total_nodes;
MATCH ()-[r]->() RETURN count(r) AS total_relationships;
MATCH (n:OrganizationUnit) RETURN count(n) AS org_count;
MATCH (n:BusinessProcess) RETURN count(n) AS process_count;
MATCH (n:ApplicationSystem) RETURN count(n) AS system_count;
```
