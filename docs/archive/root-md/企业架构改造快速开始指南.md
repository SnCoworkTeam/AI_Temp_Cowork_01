## 🚀 快速开始

### 步骤1: 运行数据库迁移

```bash
# 进入数据库目录
cd database

# 运行迁移
python -m alembic upgrade head

# 或者指定版本
python -m alembic upgrade 026
```

### 步骤2: 测试数据库迁移

```bash
# 运行测试脚本
python scripts/test_enterprise_architecture_migration.py
```

### 步骤3: 配置服务器信息

编辑 `scripts/deploy_enterprise_architecture.sh`，设置以下变量：

```bash
# 应用服务器配置
APP_SERVER_HOST="your-app-server.com"
APP_SERVER_USER="root"
APP_SERVER_KEY="./remote.ssh"  # 密钥文件路径

# Neo4j服务器配置（如果分离部署）
NEO4J_SERVER_HOST="your-neo4j-server.com"
NEO4J_SERVER_USER="root"
NEO4J_SERVER_KEY="./remote.ssh"
```

### 步骤4: 部署到服务器

```bash
# 确保密钥文件存在且权限正确
chmod 600 ./remote.ssh

# 运行部署脚本
bash scripts/deploy_enterprise_architecture.sh
```

## 📝 重要提示

1. **备份数据库**: 在生产环境运行迁移前，务必先备份数据库
2. **测试环境**: 建议先在测试环境运行迁移和测试
3. **Neo4j连接**: 确保应用服务器可以连接到Neo4j服务器
4. **环境变量**: 确保配置了正确的数据库和Neo4j连接信息
5. **服务重启**: 部署后需要重启相关服务
