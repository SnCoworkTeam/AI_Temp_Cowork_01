# 功能页面布局设计报告

## 📋 设计目标

从门户页面点击功能卡片进入后，不再直接进入后台管理页面，而是使用新的功能页面布局：
- **左侧菜单栏**：显示该功能模块的所有子功能
- **右侧操作区域**：显示具体的操作页面内容

---

## 🎨 布局设计

### FeatureLayout 组件

创建了通用的功能页面布局组件 `FeatureLayout`，包含以下特性：

#### 1. 左侧菜单栏
- **固定宽度**：256px（lg屏幕），移动端可折叠
- **菜单项**：支持图标、标题、链接
- **多级菜单**：支持子菜单展开/折叠
- **高亮当前页面**：自动高亮当前访问的页面
- **用户信息**：底部显示当前用户信息
- **返回门户**：顶部有返回门户的快捷按钮

#### 2. 右侧内容区域
- **顶部工具栏**：
  - 显示功能模块标题和描述
  - 移动端菜单切换按钮
  - 返回门户按钮（桌面端）
- **主内容区**：
  - 自适应宽度
  - 内边距：p-4 lg:p-6
  - 可滚动

#### 3. 响应式设计
- **桌面端（lg+）**：左侧菜单固定显示
- **移动端**：左侧菜单可折叠，通过遮罩层控制
- **过渡动画**：菜单展开/折叠有平滑过渡效果

## 🔧 技术实现

### FeatureLayout 组件结构

```typescript
interface FeatureLayoutProps {
  children: ReactNode
  title: string                    // 功能模块标题
  description?: string              // 功能模块描述
  menuItems: MenuItem[]            // 菜单项列表
  backToPortal?: boolean           // 是否显示返回门户按钮
}

interface MenuItem {
  name: string                      // 菜单名称
  href: string                      // 链接地址
  icon?: LucideIcon | string       // 图标（可选）
  children?: MenuItem[]             // 子菜单（可选）
}
```

### 布局层次结构

```
FeatureLayout
├── AuthGuard (认证保护)
└── 主容器 (flex布局)
    ├── 左侧菜单栏 (固定宽度)
    │   ├── 菜单头部（标题 + 返回按钮）
    │   ├── 菜单内容（导航项）
    │   └── 用户信息（底部）
    ├── 遮罩层（移动端）
    └── 右侧内容区域 (flex-1)
        ├── 顶部工具栏
        │   ├── 菜单切换按钮（移动端）
        │   ├── 标题和描述
        │   └── 返回门户按钮（桌面端）
        └── 主内容区
            └── {children}
```

## 📱 响应式设计

### 桌面端（lg: 1024px+）
- 左侧菜单：固定显示，宽度256px
- 右侧内容：自适应剩余宽度
- 菜单切换：隐藏切换按钮

### 移动端（< 1024px）
- 左侧菜单：默认隐藏，可点击按钮展开
- 遮罩层：菜单打开时显示，点击关闭菜单
- 菜单切换：显示切换按钮

## 🎯 使用方式

### 1. 创建新功能模块布局

在功能模块目录下创建 `layout.tsx`：

```typescript
'use client'

import { FeatureLayout } from '@/components/Layout/FeatureLayout'
import { Icon1, Icon2 } from 'lucide-react'

const menuItems = [
  {
    name: '功能1',
    href: '/module/feature1',
    icon: Icon1,
  },
  {
    name: '功能2',
    href: '/module/feature2',
    icon: Icon2,
  },
]

export default function ModuleLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <FeatureLayout
      title="功能模块"
      description="功能模块描述"
      menuItems={menuItems}
      backToPortal={true}
    >
      {children}
    </FeatureLayout>
  )
}
```

### 2. 调整页面内容

在功能页面中：
- **移除**：页面内的标题和描述（已在布局中显示）
- **保留**：操作按钮、搜索栏、内容列表等
- **调整**：移除最外层的容器和padding（布局已提供）
