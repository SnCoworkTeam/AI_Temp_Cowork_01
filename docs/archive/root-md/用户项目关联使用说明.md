# 用户项目关联使用说明

## 概述

将Excel文件中的用户账号与项目进行关联，支持批量操作。

## 使用步骤

### 步骤1：创建用户账号

如果用户还未创建，先运行用户创建脚本：

```powershell
.\create_users_from_excel.ps1
```

**功能**：
- 从Excel文件读取用户信息（姓名、邮箱）
- 从邮箱提取用户名（邮箱前缀）
- 批量创建用户账号
- **自动保存用户ID映射到 `user_id_map.json`**

**输出**：
- 创建成功的用户ID会自动保存
- 已存在的用户标记为需要查询

---

### 步骤2：获取已存在用户的ID（可选）

如果有些用户已存在，需要获取他们的用户ID：

```powershell
.\query_users_from_db.ps1
```

**功能**：
- 通过SSH连接服务器
- 从数据库查询用户ID
- 更新 `user_id_map.json` 文件

**要求**：
- 需要SSH访问权限
- 需要数据库连接信息

---

### 步骤3：关联用户到项目

运行关联脚本：

```powershell
.\associate_users_with_projects_final.ps1
```

**功能**：
- 读取 `user_id_map.json` 获取用户ID
- 显示项目列表供选择
- 选择要关联的项目（支持多选或全部）
- 选择用户角色（manager/member/viewer）
- 批量添加用户到项目

**交互流程**：
1. 选择项目（输入编号，多个用逗号分隔，或输入 'all'）
2. 选择角色（1-manager, 2-member, 3-viewer）
3. 自动关联所有用户

## 用户ID映射文件格式

`user_id_map.json` 文件格式：

```json
{
  "guanruibei": {
    "user_id": "uuid-here",
    "name": "管瑞贝",
    "email": "guanruibei@sinochem.com"
  },
  "zhaojun": {
    "user_id": null,
    "name": "赵军",
    "email": "zhaojun@sinochem.com"
  }
}
```

**说明**：
- `user_id` 为 `null` 表示需要查询
- 运行 `query_users_from_db.ps1` 可以填充这些值

## 项目角色说明

### manager（项目经理）
- **权限**：所有权限（创建、查看、更新、删除、管理）
- **适用**：项目负责人

### member（项目成员）
- **权限**：创建、查看、更新（不能删除和管理）
- **适用**：项目参与人员

### viewer（查看者）
- **权限**：只能查看
- **适用**：需要了解项目进展但不参与的人员

## 常见问题

### Q1: 用户创建成功但没有返回用户ID？

**A**: 检查注册API的响应格式。如果API不返回用户ID，需要：
1. 修改注册API返回用户ID
2. 或运行 `query_users_from_db.ps1` 查询用户ID

---

### Q2: 如何批量关联所有用户到所有项目？

**A**: 运行 `associate_users_with_projects_final.ps1`，在选择项目时输入 `all`。

---

### Q3: 如何为不同用户分配不同角色？

**A**: 目前脚本为所有用户分配相同角色。如需不同角色，可以：
1. 多次运行脚本，每次选择不同的用户和角色
2. 修改脚本支持按用户指定角色

---

### Q4: 用户ID映射文件丢失怎么办？

**A**: 运行 `query_users_from_db.ps1` 重新生成映射文件。

## 完整流程示例

```powershell
# 1. 创建用户（如果还未创建）
.\create_users_from_excel.ps1

# 2. 查询已存在用户的ID（如果需要）
.\query_users_from_db.ps1

# 3. 关联用户到项目
.\associate_users_with_projects_final.ps1
# 交互：
# - 选择项目: all
# - 选择角色: 2 (member)
```

---

## 注意事项

1. **用户必须先创建**：关联用户到项目前，用户必须已存在
2. **用户ID必须有效**：确保 `user_id_map.json` 中的用户ID正确
3. **权限要求**：需要管理员权限才能添加项目成员
4. **重复关联**：如果用户已是项目成员，脚本会自动跳过
