## 👥 角色定义

### 默认角色列表 (6个)

1. **超级管理员 (admin)**
   - 拥有所有权限
   - 系统角色，不可删除

2. **普通用户 (user)**
   - 基本查看和执行权限
   - 可以查看项目、使用AI助手、查看知识库等
   - 系统角色

3. **项目经理 (project_manager)**
   - 项目相关所有权限
   - 可以管理项目、任务、里程碑、周报、月报等
   - 自定义角色

4. **开发者 (developer)**
   - 工作流和工具管理权限
   - 可以创建工作流、管理工具、使用AI功能
   - 自定义角色

5. **架构师 (architect)**
   - 企业架构相关所有权限
   - 可以管理组织、业务、应用、数据、技术架构
   - 自定义角色

6. **查看者 (viewer)**
   - 所有资源的只读权限
   - 可以查看所有功能，但不能修改
   - 自定义角色

## 🔧 权限操作类型

每个资源支持以下操作类型：

- **read** - 查看/读取权限
- **create** - 创建权限
- **update** - 更新权限
- **delete** - 删除权限
- **execute** - 执行权限（如执行工作流、工具等）
- **admin** - 管理权限（高级管理操作）

## 📝 使用说明

### 初始化权限和角色

运行以下命令初始化权限和角色数据：

```bash
python init_permissions_roles.py
```

### 权限代码格式

权限代码遵循 `resource:action` 格式，例如：
- `project:read` - 查看项目
- `workflow:execute` - 执行工作流
- `user:admin` - 用户管理权限

### 权限验证

在API路由中使用权限验证：

```python
from .auth import require_permission

@router.get("/projects")
@require_permission("project:read")
async def list_projects():
    ...
```
