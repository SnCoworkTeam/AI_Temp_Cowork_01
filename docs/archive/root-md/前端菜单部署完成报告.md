## 问题排查

如果菜单仍然无法折叠或缺少菜单项：

1. **检查浏览器控制台**：查看是否有 JavaScript 错误
2. **检查服务状态**：
   ```bash
   ssh -i enterprise_ai_platform.pem ubuntu@43.143.139.197
   cd /opt/enterprise-ai-platform
   docker compose ps web-ui
   ```
3. **手动重启服务**：
   ```bash
   docker compose restart web-ui
   ```
4. **检查文件是否存在**：
   ```bash
   ls -la /opt/enterprise-ai-platform/web-ui/src/components/Layout/Sidebar.tsx
   ls -la /opt/enterprise-ai-platform/web-ui/src/app/enterprise-architecture/organization/page.tsx
   ```
