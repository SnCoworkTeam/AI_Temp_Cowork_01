## 可能的问题和解决方案

### 1. Next.js环境变量需要重新构建
**问题**: Next.js的NEXT_PUBLIC_*环境变量在构建时被嵌入到代码中，如果环境变量在运行时改变，需要重新构建。

**解决方案**:
`ash
# 在服务器上执行
cd /opt/enterprise-ai-platform
docker compose restart web-ui
`

### 2. 浏览器缓存问题
**问题**: 浏览器可能缓存了旧的JavaScript代码，导致使用了旧的API地址。

**解决方案**:
- 清除浏览器缓存
- 使用硬刷新（Ctrl+Shift+R 或 Cmd+Shift+R）
- 使用无痕模式访问

### 3. 检查浏览器控制台
**建议**: 打开浏览器开发者工具（F12），查看：
- Console标签：查看是否有API连接错误
- Network标签：查看API请求的实际URL
- 确认请求是否发送到 http://43.143.139.197:8080
