## 注意事项

1. **导入位置**: `from ..prompt_utils import get_system_prompt` 应该放在函数内部或文件顶部
2. **fallback**: 所有修改都应该保留fallback提示词，确保向后兼容
3. **动态参数**: 对于包含动态参数的提示词（如format_agent），使用`format_prompt()`函数
4. **测试**: 修改后需要测试相关功能，确保提示词正确加载
