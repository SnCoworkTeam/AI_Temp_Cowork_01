### 2. 菜单折叠问题分析

#### 问题原因
1. **路径匹配过于宽泛**: 如果当前路径是 `/admin` 或 `/enterprise-architecture`，会匹配父菜单，导致自动展开
2. **自动展开逻辑**: 当路径匹配时，菜单会自动展开，但用户可能没有注意到需要手动折叠

#### 已修复的逻辑
```typescript
const isExpanded = (href: string, item: NavItem) => {
  // 1. 用户手动折叠 → 保持折叠（最高优先级）
  if (collapsedItems.has(href)) {
    return false
  }
  
  // 2. 用户手动展开 → 保持展开
  if (expandedItems.has(href)) {
    return true
  }
  
  // 3. 只有子菜单匹配当前路径时才自动展开父菜单
  // 不再检查父菜单本身是否匹配（避免过度展开）
  
  // 4. 默认折叠
  return false
}
```
