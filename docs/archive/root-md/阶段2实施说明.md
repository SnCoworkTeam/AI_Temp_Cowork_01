## 🔧 技术实现细节

### 1. 流式查询方法

```python
async def query_intent_enhanced_stream(...) -> AsyncIterator[Dict[str, Any]]:
    """流式查询语义引擎"""
    # 分阶段返回进度
    yield {"stage": "preparing", "progress": 5}
    yield {"stage": "vectorizing", "progress": 10}
    yield {"stage": "vectorized", "progress": 30}
    yield {"stage": "searching", "progress": 40}
    # ... 更多阶段
    yield {"stage": "complete", "progress": 100, "result": result}
```

### 2. 实时转发机制

```python
# 在process_hybrid中实时转发语义引擎结果
async for chunk in semantic_adapter.query_intent_enhanced_stream(...):
    yield {
        "stage": "semantic_search",
        "progress": 50 + chunk["progress"] * 0.3,  # 映射到50-80%范围
        "semantic_chunk": chunk
    }
```
