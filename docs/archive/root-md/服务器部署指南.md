# 服务器部署指南

## 修改的文件

以下文件需要上传到服务器：

1. `database/src/models/system_models.py` - 修复了AuditAction枚举值问题
2. `knowledge-base/src/repositories/search_history_repository.py` - 确保使用正确的枚举值
3. `knowledge-base/src/core/embedding_manager.py` - 添加了HuggingFace镜像支持

## 部署步骤

### 1. 上传文件到服务器

```bash
# 使用SCP上传文件
scp -i enterprise_ai_platform.pem database/src/models/system_models.py ubuntu@43.143.139.197:/opt/enterprise-ai-platform/database/src/models/system_models.py

scp -i enterprise_ai_platform.pem knowledge-base/src/repositories/search_history_repository.py ubuntu@43.143.139.197:/opt/enterprise-ai-platform/knowledge-base/src/repositories/search_history_repository.py

scp -i enterprise_ai_platform.pem knowledge-base/src/core/embedding_manager.py ubuntu@43.143.139.197:/opt/enterprise-ai-platform/knowledge-base/src/core/embedding_manager.py
```

### 2. 安装依赖

```bash
# SSH连接到服务器
ssh -i enterprise_ai_platform.pem ubuntu@43.143.139.197

# 在服务器上执行
cd /opt/enterprise-ai-platform
docker exec enterprise-ai-knowledge-base pip install --upgrade sentence-transformers huggingface-hub --no-cache-dir
```

### 3. 重启服务

```bash
# 在服务器上执行
cd /opt/enterprise-ai-platform
docker compose restart knowledge-base
```

### 4. 等待服务启动并检查状态

```bash
# 等待30秒
sleep 30

# 检查服务状态
docker compose ps knowledge-base

# 检查模型加载状态
docker exec enterprise-ai-knowledge-base python -c "import sys; sys.path.insert(0, '/app'); from src.core.embedding_manager import get_embedding_manager; em = get_embedding_manager(); print('Model available:', em.is_available()); print('Has model:', em.model is not None)"

# 查看日志
docker logs enterprise-ai-knowledge-base --tail 50
```

## 一键部署脚本（如果SSH连接正常）

如果SSH连接正常，可以使用以下PowerShell脚本：

```powershell
# 上传文件
$SERVER = "ubuntu@43.143.139.197"
$KEY = "enterprise_ai_platform.pem"
$PROJECT_PATH = "/opt/enterprise-ai-platform"

# 上传文件
scp -i $KEY database/src/models/system_models.py ${SERVER}:${PROJECT_PATH}/database/src/models/system_models.py
scp -i $KEY knowledge-base/src/repositories/search_history_repository.py ${SERVER}:${PROJECT_PATH}/knowledge-base/src/repositories/search_history_repository.py
scp -i $KEY knowledge-base/src/core/embedding_manager.py ${SERVER}:${PROJECT_PATH}/knowledge-base/src/core/embedding_manager.py

# 安装依赖
ssh -i $KEY $SERVER "cd $PROJECT_PATH && docker exec enterprise-ai-knowledge-base pip install --upgrade sentence-transformers huggingface-hub --no-cache-dir"

# 重启服务
ssh -i $KEY $SERVER "cd $PROJECT_PATH && docker compose restart knowledge-base"
```

## 注意事项

1. 确保SSH密钥文件 `enterprise_ai_platform.pem` 存在且有正确的权限
2. 如果连接超时，检查网络连接或服务器状态
3. 安装依赖可能需要几分钟时间
4. 重启服务后需要等待30-60秒让服务完全启动
5. 可以通过查看日志确认服务是否正常启动

## 验证部署

部署完成后，可以通过以下方式验证：

1. 检查服务状态：`docker compose ps knowledge-base`
2. 查看日志：`docker logs enterprise-ai-knowledge-base --tail 100`
3. 测试API：访问知识库服务的健康检查端点
4. 检查模型加载：确认日志中显示 "Embedding model loaded successfully"
