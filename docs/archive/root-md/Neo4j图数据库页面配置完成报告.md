## 页面功能

### 1. 图数据可视化

- **节点展示**: 显示Neo4j中的所有节点
- **关系展示**: 显示节点之间的关系
- **交互操作**: 支持拖拽、缩放、点击查看详情

### 2. 节点搜索

- **按名称搜索**: 支持模糊搜索节点名称
- **按类型过滤**: 可以按节点类型（Label）过滤
- **实时搜索**: 输入关键词实时搜索

### 3. 节点详情

- **点击节点**: 查看节点详细信息
- **属性展示**: 显示节点的所有属性
- **标签信息**: 显示节点的标签（Labels）

### 4. 邻居节点

- **查看邻居**: 点击节点可以查看其邻居节点
- **关系展示**: 显示节点之间的连接关系
- **深度控制**: 可以控制查看的深度

### 5. 统计信息

- **节点数量**: 实时显示图中的节点数量
- **关系数量**: 实时显示图中的关系数量
- **类型统计**: 显示各类型节点的数量

## 后端API支持

### API Gateway路由

**文件**: `api-gateway/src/routes/neo4j_graph.py`

**路由**:
- `GET /api/neo4j/graph` - 获取图数据
- `GET /api/neo4j/nodes` - 查询节点
- `GET /api/neo4j/nodes/{node_id}` - 获取节点详情
- `GET /api/neo4j/nodes/{node_id}/neighbors` - 获取邻居节点
- `GET /api/neo4j/nodes/search` - 搜索节点
- `POST /api/neo4j/cypher` - 执行Cypher查询

### Metadata Service API

**文件**: `metadata-service/src/api/neo4j_api.py`

**功能**: 直接连接Neo4j数据库执行查询

## 使用说明

### 1. 查看图数据

1. 打开"图数据库"页面
2. 页面会自动加载Neo4j中的图数据
3. 可以在可视化界面中查看节点和关系

### 2. 搜索节点

1. 在搜索框中输入节点名称
2. 点击搜索按钮或按Enter键
3. 搜索结果会高亮显示在图中

### 3. 过滤节点类型

1. 在"节点类型"下拉框中选择类型
2. 图会自动过滤显示该类型的节点
3. 选择"全部"显示所有节点

### 4. 查看节点详情

1. 点击图中的任意节点
2. 右侧会显示节点的详细信息
3. 包括属性、标签、邻居节点等

### 5. 查看邻居节点

1. 点击节点后，在详情面板中
2. 点击"查看邻居"按钮
3. 会显示该节点的所有邻居节点和关系

## 注意事项

### 1. 数据加载

- 首次加载可能需要几秒钟
- 如果数据量大，建议使用过滤功能
- 默认加载最多500个节点

### 2. 性能优化

- 大数据量时建议使用节点类型过滤
- 使用搜索功能可以快速定位节点
- 查看邻居节点时注意深度设置

### 3. 连接问题

如果页面无法加载数据，请检查：
- Neo4j服务是否正常运行
- 应用服务器的Neo4j配置是否正确
- API Gateway是否正常
- 网络连接是否正常
