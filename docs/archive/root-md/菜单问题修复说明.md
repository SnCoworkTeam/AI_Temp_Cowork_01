# 菜单问题修复说明

**日期**: 2025-12-07  
**问题**: 
1. 菜单无法折叠
2. admin下看不到组织架构
3. 图数据库展示页面没有

## 🔍 问题分析

### 1. 菜单无法折叠
**原因**: 
- 自动展开逻辑太强，覆盖了手动折叠操作
- 当路径匹配时，总是返回 `true`，导致无法手动折叠

**解决方案**:
- 添加 `collapsedItems` 状态来跟踪用户手动折叠的菜单
- 优先检查用户是否手动折叠，如果是则返回 `false`
- 只有在用户没有手动折叠时，才进行自动展开判断

### 2. Admin下看不到组织架构
**原因**:
- 菜单配置正确，但可能菜单默认是折叠的
- 用户需要点击"企业架构"菜单才能看到子菜单

**解决方案**:
- 确保菜单可以正常展开/折叠
- 当访问组织架构页面时，自动展开企业架构菜单

### 3. 图数据库展示页面没有
**检查结果**:
- ✅ Neo4j页面存在: `web-ui/src/app/admin/database/neo4j/page.tsx`
- ✅ 菜单配置存在: 在"数据库管理" → "图数据库"
- 问题可能是菜单没有展开

**解决方案**:
- 确保"数据库管理"菜单可以展开
- 当访问Neo4j页面时，自动展开"数据库管理"菜单

### 1. 改进菜单折叠逻辑

```typescript
// 添加折叠状态跟踪
const [collapsedItems, setCollapsedItems] = useState<Set<string>>(new Set())

const toggleExpand = (href: string) => {
  // 切换折叠状态
  setCollapsedItems((prev) => {
    const next = new Set(prev)
    if (next.has(href)) {
      next.delete(href)  // 取消折叠
    } else {
      next.add(href)     // 标记为折叠
    }
    return next
  })
}

const isExpanded = (href: string, item: NavItem) => {
  // 如果用户手动折叠了，优先使用折叠状态
  if (collapsedItems.has(href)) {
    return false
  }
  
  // 如果当前路径匹配，自动展开
  if (pathname?.startsWith(href + '/') || pathname === href) {
    return true
  }
  
  // 如果任何子菜单项匹配当前路径，也自动展开
  if (item.children) {
    for (const child of item.children) {
      if (pathname?.startsWith(child.href + '/') || pathname === child.href) {
        return true
      }
      // 递归检查更深层的子菜单
      if (child.children) {
        for (const grandChild of child.children) {
          if (pathname?.startsWith(grandChild.href + '/') || pathname === grandChild.href) {
            return true
          }
        }
      }
    }
  }
  
  // 默认展开状态（如果之前手动展开过）
  return expandedItems.has(href)
}
```
