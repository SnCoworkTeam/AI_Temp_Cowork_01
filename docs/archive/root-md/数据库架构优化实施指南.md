- URL: http://localhost:7474
- 用户名: neo4j
- 密码: neo4j_password (或.env中配置的)

**Windows PowerShell**:


#### 4.3 手动部署步骤

如果自动部署脚本不可用，可以手动执行：

1. **上传文件**
   ```bash
   scp docker-compose.yml user@server:/opt/enterprise-ai-platform/
   scp -r scripts/ user@server:/opt/enterprise-ai-platform/
   scp database/src/core/neo4j_client.py user@server:/opt/enterprise-ai-platform/database/src/core/
   ```

2. **在服务器上执行**
   ```bash
   # SSH到服务器
   ssh user@server
   
   # 进入项目目录
   cd /opt/enterprise-ai-platform
   
   # 启动Neo4j
   docker-compose up -d neo4j
   
   # 等待启动
   sleep 30
   
   # 运行迁移
   docker-compose exec metadata-service python /app/scripts/migrate_data_to_neo4j.py
   docker-compose exec metadata-service python /app/scripts/migrate_vectors_to_qdrant.py --qdrant-url http://qdrant:6333
   
   # 运行测试
   docker-compose exec metadata-service python /app/scripts/test_database_migration.py
   ```

## 🔍 故障排查

### 问题1: Neo4j无法启动

**症状**: 容器启动后立即退出

**排查**:
```bash
# 查看日志
docker-compose logs neo4j

# 检查内存
docker stats neo4j

# 检查端口占用
netstat -tulpn | grep 7474
netstat -tulpn | grep 7687
```

**解决**:
- 检查内存是否足够
- 检查端口是否被占用
- 检查配置文件是否正确

### 问题2: 数据迁移失败

**症状**: 迁移脚本报错

**排查**:
```bash
# 检查PostgreSQL连接
docker-compose exec postgres psql -U ai_user -d ai_platform -c "SELECT 1"

# 检查Neo4j连接
docker-compose exec neo4j cypher-shell -u neo4j -p neo4j_password "RETURN 1"

# 检查Qdrant连接
curl http://localhost:6333/health
```

**解决**:
- 确保所有服务正常运行
- 检查数据库连接配置
- 查看详细错误日志

### 问题3: 数据数量不匹配

**症状**: 测试显示数据数量不匹配

**排查**:
```bash
# 检查PostgreSQL数据
docker-compose exec postgres psql -U ai_user -d ai_platform -c "SELECT COUNT(*) FROM knowledge_graph_nodes"

# 检查Neo4j数据
docker-compose exec neo4j cypher-shell -u neo4j -p neo4j_password "MATCH (n:Entity) RETURN count(n)"
```

**解决**:
- 重新运行迁移脚本
- 检查迁移日志
- 手动验证数据

## 🔄 回滚方案

如果部署出现问题，可以回滚：

### 1. 停止Neo4j服务

```bash
docker-compose stop neo4j
docker-compose rm neo4j
```

### 2. 恢复PostgreSQL数据

```bash
# 从备份恢复
docker-compose exec -T postgres psql -U ai_user ai_platform < backup.sql
```

### 3. 恢复docker-compose.yml

```bash
git checkout docker-compose.yml
```
