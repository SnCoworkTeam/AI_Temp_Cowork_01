# 数据库枚举值错误修复总结

## 问题描述

在测试F5文档上传时，发现以下错误：
```
invalid input value for enum auditaction: "READ"
```

错误发生在查询文档详情时，尝试创建audit log记录。

## 根本原因

SQLAlchemy的`SQLEnum`在处理PostgreSQL原生枚举类型时，默认使用枚举的**名称**（如'READ'）而不是**值**（如'read'）。但数据库中的枚举值是小写的'read'，导致类型不匹配。

## 修复方案

### 1. 修改SQLEnum配置

在`database/src/models/system_models.py`中，修改`AuditLog.action`列的SQLEnum配置：

**修复前：**
```python
action = Column(SQLEnum(AuditAction), nullable=False, index=True, comment="操作类型")
```

**修复后：**
```python
action = Column(SQLEnum(AuditAction, native_enum=False, values_callable=lambda x: [e.value for e in AuditAction]), nullable=False, index=True, comment="操作类型")
```

**关键配置：**
- `native_enum=False`: 不使用PostgreSQL原生枚举，改用字符串存储
- `values_callable=lambda x: [e.value for e in AuditAction]`: 明确指定使用枚举值（小写字符串）而不是名称

### 2. 确保代码使用枚举值

在`knowledge-base/src/repositories/search_history_repository.py`中，确保使用`.value`获取枚举值：

```python
audit_action = AuditAction.READ.value  # 返回 'read'（小写字符串）
```

## 验证结果

修复后测试：
- ✅ 文档详情查询成功（Status: 200）
- ✅ Audit log创建成功，不再报错
- ✅ 文档处理可以正常进行
