## 故障排除

   ```bash

   ```

2. **检查环境变量**
   ```bash
   cat .env | grep -E "DB_|NEO4J_"
   ```

3. **检查端口占用**
   ```bash
   netstat -tlnp | grep -E "8000|8001"
   ```

4. **重新构建（如果需要）**
   ```bash
   docker-compose build metadata-service
   docker-compose up -d metadata-service
   ```
