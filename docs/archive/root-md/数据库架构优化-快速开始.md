## 📋 分步执行

### 步骤1: 启动Neo4j (2分钟)

```bash
# 启动Neo4j容器
docker-compose up -d neo4j

# 等待服务启动（约30秒）
timeout /t 30  # Windows
# sleep 30     # Linux/Mac

# 检查服务状态
docker-compose ps neo4j

# 查看日志
docker-compose logs neo4j
```

**验证**: 访问 http://localhost:7474，应该能看到Neo4j Browser登录页面

---

### 步骤2: 安装依赖 (1分钟)

```bash
# 安装Neo4j Python驱动
pip install neo4j==5.14.0 qdrant-client
```

---

### 步骤3: 运行数据迁移 (5-30分钟，取决于数据量)

```bash
# 迁移知识图谱数据到Neo4j
python scripts/migrate_data_to_neo4j.py

# 迁移向量数据到Qdrant
python scripts/migrate_vectors_to_qdrant.py --qdrant-url http://localhost:6333
```

**注意**: 
- 如果数据量大，迁移可能需要较长时间
- 迁移过程中会显示进度信息
- 如有错误，会显示详细错误信息

---

### 步骤4: 运行测试 (1分钟)

```bash
# 运行迁移测试
python scripts/test_database_migration.py
```

**预期输出**:
- ✅ Neo4j连接测试通过
- ✅ Qdrant连接测试通过
- ✅ 数据数量匹配
- ✅ 查询功能正常

## 🔧 故障排查

### Neo4j无法启动

**问题**: 容器启动后立即退出

**解决**:
```bash
# 查看详细日志
docker-compose logs neo4j

# 检查内存
docker stats neo4j

# 检查端口占用
netstat -ano | findstr :7474  # Windows
netstat -tulpn | grep 7474    # Linux
```

### 迁移脚本报错

**问题**: `ModuleNotFoundError: No module named 'neo4j'`

**解决**:
```bash
# 确保已安装依赖
pip install neo4j==5.14.0

# 或在容器内安装
docker-compose exec metadata-service pip install neo4j==5.14.0
```

### 连接失败

**问题**: `Failed to connect to Neo4j`

**解决**:
```bash
# 检查Neo4j是否运行
docker-compose ps neo4j

# 检查环境变量
echo $NEO4J_PASSWORD  # Linux/Mac
echo %NEO4J_PASSWORD% # Windows

# 测试连接
docker-compose exec neo4j cypher-shell -u neo4j -p neo4j_password "RETURN 1"
```

## 🚀 部署到服务器

### 方式1: 使用部署脚本（推荐）

**Linux/Mac**:
```bash
export SERVER_HOST=your-server-ip
export SERVER_USER=root
./scripts/deploy_to_server.sh
```

**Windows PowerShell**:
```powershell
.\scripts\deploy_to_server.ps1 -ServerHost your-server-ip -ServerUser root
```

### 方式2: 手动部署

1. **上传文件到服务器**
   ```bash
   scp docker-compose.yml user@server:/opt/enterprise-ai-platform/
   scp -r scripts/ user@server:/opt/enterprise-ai-platform/
   ```

2. **在服务器上执行**
   ```bash
   ssh user@server
   cd /opt/enterprise-ai-platform
   docker-compose up -d neo4j
   # 等待启动后运行迁移脚本
   ```
