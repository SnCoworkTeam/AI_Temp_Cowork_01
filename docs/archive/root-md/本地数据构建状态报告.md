## 📋 数据同步方案

### 方案1: 等待Neo4j稳定后同步（推荐）
```bash
# 1. 等待Neo4j完全启动
docker compose ps neo4j  # 确认状态为"Up"

# 2. 执行同步脚本
python scripts/migrate_enterprise_architecture_to_neo4j.py
```

### 方案2: 直接同步到服务器Neo4j
由于本地Neo4j不稳定，可以直接将PostgreSQL数据同步到服务器的Neo4j：

```bash
# 1. 确保服务器metadata-service运行
# 2. 调用同步API
curl -X POST http://43.143.139.197:8080/api/enterprise-architecture/sync/all
```

### 方案3: 导出PostgreSQL数据到服务器
```bash
# 1. 导出数据
docker compose exec postgres pg_dump -U ai_user ai_platform > backup.sql

# 2. 上传到服务器
scp backup.sql ubuntu@43.143.139.197:/tmp/

# 3. 在服务器导入
ssh ubuntu@43.143.139.197 "cd /opt/enterprise-ai-platform && docker compose exec -T postgres psql -U ai_user ai_platform < /tmp/backup.sql"

# 4. 同步到Neo4j
curl -X POST http://43.143.139.197:8080/api/enterprise-architecture/sync/all
```
