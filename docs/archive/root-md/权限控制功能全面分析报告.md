## 二、权限体系架构分析

### 2.1 权限模型设计

**核心权限模型**（`auth-service/src/models/permission_models.py`）：

```python
class ResourceType(str, Enum):
    """资源类型"""
    USER = "user"
    WORKFLOW = "workflow"
    TOOL = "tool"
    ADMIN = "admin"
    SYSTEM = "system"

class PermissionType(str, Enum):
    """权限类型"""
    READ = "read"
    WRITE = "write"
    DELETE = "delete"
    EXECUTE = "execute"
    ADMIN = "admin"
```

**权限结构**：
- `resource_type`: 资源类型（用户、工作流、工具、管理、系统）
- `permission_type`: 操作类型（读、写、删除、执行、管理）
- `code`: 权限代码（格式：`resource:action`，如 `workflow:execute`）

#### ✅ 2. 项目级数据权限（已实现）

**位置**：`project-management/src/middleware/project_permissions.py`

**功能**：
- 项目成员角色：`MANAGER`（项目经理）、`MEMBER`（成员）、`VIEWER`（查看者）
- 权限操作：`CREATE`、`READ`、`UPDATE`、`DELETE`、`MANAGE`
- 自动过滤：用户只能看到自己有权限的项目

**权限规则**：
- **项目经理（MANAGER）**：所有权限
- **项目成员（MEMBER）**：创建、查看、更新（不能删除和管理）
- **查看者（VIEWER）**：只能查看

**使用示例**：
```python
@router.get("/projects/{project_id}")
async def get_project(
    project_id: str,
    current_user: dict = Depends(require_project_permission(ProjectPermission.READ))
):
    # 只有项目成员可以查看
    pass
```

**覆盖范围**：
- ✅ 项目列表（自动过滤）
- ✅ 项目详情（需要READ权限）
- ✅ 项目更新（需要UPDATE权限）
- ✅ 项目删除（需要DELETE权限）
- ✅ 项目成员管理（需要MANAGE权限）

## 四、权限控制改进建议

### 4.1 菜单权限控制（P1优先级）

**实施步骤**：

1. **扩展菜单配置**：
```typescript
interface NavItem {
  name: string
  href: string
  icon: LucideIcon
  requiredPermission?: string  // 新增：需要的权限代码
  children?: NavItem[]
}
```

2. **添加权限检查Hook**：
```typescript
// hooks/useMenuPermissions.ts
export function useMenuPermissions() {
  const { user } = useAuth()
  const [userPermissions, setUserPermissions] = useState<string[]>([])
  
  useEffect(() => {
    // 从API获取用户权限
    fetchUserPermissions().then(setUserPermissions)
  }, [user])
  
  const hasPermission = (permissionCode?: string) => {
    if (!permissionCode) return true
    return userPermissions.includes(permissionCode)
  }
  
  return { hasPermission, userPermissions }
}
```

3. **过滤菜单项**：
```typescript
const filterMenuByPermissions = (items: NavItem[], hasPermission: (code?: string) => boolean): NavItem[] => {
  return items
    .filter(item => hasPermission(item.requiredPermission))
    .map(item => ({
      ...item,
      children: item.children ? filterMenuByPermissions(item.children, hasPermission) : undefined
    }))
}
```

### 4.2 字段级数据权限（P2优先级）

**实施步骤**：

1. **创建字段权限配置**：
```python
# database/src/models/permission_models.py
class FieldPermission(BaseModel):
    __tablename__ = "field_permissions"
    
    id: UUID
    resource_type: str  # 如 "project"
    field_name: str      # 如 "budget"
    permission_code: str  # 如 "project:view_budget"
    mask_value: bool     # 是否脱敏
    default_value: Any   # 无权限时的默认值
```

2. **添加字段权限检查中间件**：
```python
def check_field_permission(
    resource_type: str,
    field_name: str,
    user_permissions: List[str]
) -> bool:
    # 检查用户是否有该字段的访问权限
    permission_code = f"{resource_type}:view_{field_name}"
    return permission_code in user_permissions
```

3. **在API响应中过滤字段**：
```python
def filter_fields_by_permission(
    data: dict,
    resource_type: str,
    user_permissions: List[str]
) -> dict:
    filtered = {}
    for field, value in data.items():
        if check_field_permission(resource_type, field, user_permissions):
            filtered[field] = value
        else:
            filtered[field] = None  # 或脱敏值
    return filtered
```
