## 修改模式

### 标准修改模式

**修改前**:
```python
response = await self.llm.chat([
    {"role": "system", "content": "你是一个XXX专家，擅长..."},
    {"role": "user", "content": prompt}
])
```

**修改后**:
```python
# 从提示词模板获取系统提示词
from ..prompt_utils import get_system_prompt
system_prompt = get_system_prompt(
    "template_name",  # 模板名称，对应YAML中的key
    fallback="你是一个XXX专家，擅长..."  # 后备提示词（可选）
)

response = await self.llm.chat([
    {"role": "system", "content": system_prompt},
    {"role": "user", "content": prompt}
])
```

### 支持动态参数的模板

**修改前**:
```python
{"role": "system", "content": f"你是一个格式优化专家，擅长将内容格式化为{target_format}格式。"}
```

**修改后**:
```python
from ..prompt_utils import format_prompt
system_prompt = format_prompt("format_agent_execute", target_format=target_format)

{"role": "system", "content": system_prompt}
```

## 使用示例

### 示例1: 基本使用
```python
from ..prompt_utils import get_system_prompt

# 获取系统提示词
system_prompt = get_system_prompt("metadata_agent")

# 使用提示词
response = await self.llm.chat([
    {"role": "system", "content": system_prompt},
    {"role": "user", "content": user_prompt}
])
```

### 示例2: 带后备提示词
```python
from ..prompt_utils import get_system_prompt

# 如果模板不存在，使用后备提示词
system_prompt = get_system_prompt(
    "metadata_agent",
    fallback="你是一个元数据专家，擅长分析任务的元数据需求。"
)
```

### 示例3: 动态参数
```python
from ..prompt_utils import format_prompt

# 格式化提示词，替换动态占位符
system_prompt = format_prompt(
    "format_agent_execute",
    target_format="markdown"
)
```

## 注意事项

1. **向后兼容**: 所有修改都保留了fallback提示词，确保即使模板不存在也能正常工作
2. **性能**: `get_template_by_name()` 会直接从YAML文件读取，性能可接受
3. **缓存**: TemplateManager在初始化时加载所有模板，后续访问很快
4. **动态重载**: 可以通过 `template_manager.reload_templates()` 重新加载模板
