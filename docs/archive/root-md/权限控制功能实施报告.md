#### 1.1 数据模型

**创建ProjectMember模型**（`database/src/models/project_models.py`）：
```python
class ProjectMemberRole(str, Enum):
    MANAGER = "manager"      # 项目经理（所有权限）
    MEMBER = "member"        # 项目成员（创建、编辑、查看）
    VIEWER = "viewer"        # 查看者（只能查看）

class ProjectMember(BaseModel):
    """项目成员模型（项目级别权限）"""
    __tablename__ = "pm_project_members"
    
    id: UUID
    project_id: UUID  # 外键：pm_projects.id
    user_id: UUID     # 外键：users.id
    role: ProjectMemberRole  # 成员角色
    joined_at: Date   # 加入日期
    
    # 唯一约束：同一用户在同一项目中只能有一个角色
    __table_args__ = (
        UniqueConstraint('project_id', 'user_id', name='uq_project_member'),
    )
```

**数据库迁移脚本**（`030_add_project_members_table.py`）：
- 创建`pm_project_members`表
- 创建索引（project_id, user_id, role）

#### 1.2 权限检查中间件

**创建权限检查服务**（`project-management/src/middleware/project_permissions.py`）：

**核心函数**：
1. `check_project_permission(project_id, user_id, permission, db)` - 检查权限
2. `require_project_permission(permission)` - 权限要求装饰器工厂
3. `require_project_manager(project_id, db, current_user)` - 项目经理权限
4. `get_user_projects(user_id, db, role)` - 获取用户有权限的项目列表

**权限操作**：
- `CREATE` - 创建
- `READ` - 查看
- `UPDATE` - 更新
- `DELETE` - 删除
- `MANAGE` - 管理（所有操作）

**权限规则**：
- **项目经理（MANAGER）**：所有权限
- **项目成员（MEMBER）**：创建、查看、更新（不能删除和管理）
- **查看者（VIEWER）**：只能查看

## 二、权限控制流程

### 2.1 权限检查流程

```
请求 → 认证检查（require_auth）
         ↓
      获取用户ID
         ↓
      权限检查（require_project_permission）
         ↓
      查询项目成员表
         ↓
      检查角色权限
         ↓
      允许/拒绝
```

### 2.2 权限判断逻辑

```python
def check_project_permission(project_id, user_id, permission, db):
    # 1. 检查是否是项目创建者/管理员
    if project.manager_id == user_id:
        return True
    
    # 2. 检查项目成员权限
    member = query_project_member(project_id, user_id)
    if not member:
        return False
    
    # 3. 根据角色判断权限
    if member.role == MANAGER:
        return True  # 所有权限
    elif member.role == MEMBER:
        return permission in [CREATE, READ, UPDATE]  # 不能删除
    elif member.role == VIEWER:
        return permission == READ  # 只能查看
```
