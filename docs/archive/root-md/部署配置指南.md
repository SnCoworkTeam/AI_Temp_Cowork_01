## 🚀 执行部署

### 方式1: 使用部署脚本（推荐）

```bash
# 1. 确保脚本有执行权限（Linux/Mac）
chmod +x scripts/deploy_enterprise_architecture.sh

# 2. 运行部署脚本
bash scripts/deploy_enterprise_architecture.sh
```

### 方式2: 手动部署

如果部署脚本无法使用，可以手动执行以下步骤：

#### 步骤1: 备份数据库

```bash
ssh -i ./remote.ssh user@your-app-server << 'EOF'
    mkdir -p /opt/backups/$(date +%Y%m%d_%H%M%S)
    pg_dump -U postgres enterprise_ai > /opt/backups/$(date +%Y%m%d_%H%M%S)/database_backup.sql
    echo "数据库备份完成"
EOF
```

#### 步骤2: 上传代码

```bash
rsync -avz --progress \
    -e "ssh -i ./remote.ssh" \
    --exclude 'node_modules' \
    --exclude '__pycache__' \
    --exclude '*.pyc' \
    --exclude '.git' \
    ./ user@your-app-server:/opt/enterprise-ai-platform/
```

#### 步骤3: 运行数据库迁移

```bash
ssh -i ./remote.ssh user@your-app-server << 'EOF'
    cd /opt/enterprise-ai-platform/database
    source venv/bin/activate || true
    python -m alembic upgrade 026
    echo "数据库迁移完成"
EOF
```

#### 步骤4: 验证迁移

```bash
ssh -i ./remote.ssh user@your-app-server << 'EOF'
    cd /opt/enterprise-ai-platform
    python scripts/test_enterprise_architecture_migration.py
EOF
```

#### 步骤5: 重启服务

```bash
ssh -i ./remote.ssh user@your-app-server << 'EOF'
    cd /opt/enterprise-ai-platform
    docker-compose restart metadata-service api-gateway || systemctl restart enterprise-ai-platform
    echo "服务重启完成"
EOF
```

## 🔍 故障排除

### 问题1: SSH连接失败

**可能原因**:
- 服务器地址错误
- 用户名错误
- 密钥文件权限错误
- 防火墙阻止连接

**解决方案**:
```bash
# 检查密钥权限
chmod 600 ./remote.ssh

# 测试连接（显示详细信息）
ssh -v -i ./remote.ssh user@your-server
```

### 问题2: 数据库迁移失败

**可能原因**:
- 数据库连接失败
- 迁移脚本错误
- 表已存在

**解决方案**:
```bash
# 检查数据库连接
ssh -i ./remote.ssh user@your-server "psql -U postgres -d enterprise_ai -c 'SELECT 1'"

# 检查当前迁移版本
ssh -i ./remote.ssh user@your-server "cd /opt/enterprise-ai-platform/database && python -m alembic current"

# 如果需要，可以回滚
ssh -i ./remote.ssh user@your-server "cd /opt/enterprise-ai-platform/database && python -m alembic downgrade -1"
```

### 问题3: 服务启动失败

**可能原因**:
- 环境变量未配置
- 端口冲突
- 依赖服务未启动

**解决方案**:
```bash
# 检查服务日志
ssh -i ./remote.ssh user@your-server "docker-compose logs metadata-service"

# 检查环境变量
ssh -i ./remote.ssh user@your-server "cd /opt/enterprise-ai-platform && cat .env"
```
