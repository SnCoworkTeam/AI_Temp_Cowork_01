## ⚠️ 已知问题

### 问题1：AgentManager中的类型检查

**描述**: `isinstance(agent, BaseAgent)` 可能无法正确识别所有统一接口的智能体

**影响**: 低，有fallback机制

**解决方案**: 使用 `hasattr(agent, 'plan_and_execute')` 作为补充检查

### 问题2：旧智能体的适配

**描述**: 部分旧智能体（如WorkflowAgent）尚未重构，需要通过适配器使用

**影响**: 低，适配器已实现

**解决方案**: 继续统一其他智能体，或使用AgentAdapter
