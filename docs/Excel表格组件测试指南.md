# Excel风格项目计划表格组件测试指南

## 一、测试环境

- **服务器地址**: http://43.143.139.197:3000
- **测试页面**: 项目详情页 → "项目计划" 标签页
- **测试项目**: 任意已有项目（建议使用有项目计划的）

## 二、功能测试清单

### ✅ 基础功能测试

#### 1. 表格显示
- [ ] 表格是否正确显示（包含所有列：名称、负责人、时间范围、进度、状态、优先级、预估工时）
- [ ] 树形结构是否正确显示（阶段节点和任务节点的层级关系）
- [ ] 阶段节点是否显示文件夹图标（蓝色）
- [ ] 任务节点是否显示文件图标（灰色）
- [ ] 层级缩进是否正确（每级20px）

#### 2. 展开/折叠功能
- [ ] 点击展开/折叠图标是否能正确展开/折叠子节点
- [ ] "全部展开"/"全部折叠"按钮是否正常工作
- [ ] 默认是否展开所有阶段节点

#### 3. 内联编辑功能
- [ ] **名称列**：双击任务名称是否能进入编辑模式
- [ ] **负责人列**：双击是否能打开选择器（TODO：需要实现用户列表）
- [ ] **时间范围列**：双击是否能打开日期选择器
- [ ] **进度列**：双击任务进度是否能输入数字（0-100）
- [ ] **状态列**：双击是否能打开状态选择器
- [ ] **优先级列**：双击是否能打开优先级选择器
- [ ] **预估工时列**：双击是否能输入数字

#### 4. 键盘快捷键
- [ ] **Tab键**：是否能切换到下一个单元格
- [ ] **Enter键**：是否能进入编辑模式或确认编辑
- [ ] **F2键**：是否能进入编辑模式
- [ ] **Delete键**：是否能删除任务（需要确认）

#### 5. 列操作
- [ ] **列排序**：点击列标题是否能排序
- [ ] **列宽调整**：拖拽列边界是否能调整列宽
- [ ] **列冻结**：名称列是否固定在左侧（frozen）

### ✅ 高级功能测试

#### 6. 行选择
- [ ] 点击行是否能选中
- [ ] 是否能多选行（Ctrl+Click 或 Shift+Click）
- [ ] 选中行后是否显示"批量删除"按钮
- [ ] 批量删除是否能正常工作

#### 7. 操作按钮
- [ ] 阶段节点是否显示"添加任务"按钮（+图标）
- [ ] 点击"添加任务"是否能跳转到任务创建页面
- [ ] 任务节点是否显示"删除"按钮（垃圾桶图标）
- [ ] 点击"删除"是否能删除任务

#### 8. 数据更新
- [ ] 编辑单元格后，数据是否自动保存到后端
- [ ] 刷新页面后，修改是否保留
- [ ] 阶段进度是否自动计算（基于子任务的平均进度）

#### 9. 复制粘贴
- [ ] 是否能复制单元格内容（Ctrl+C）
- [ ] 是否能粘贴到其他单元格（Ctrl+V）
- [ ] 复制粘贴是否保持数据格式

### ✅ 样式和UI测试

#### 10. 视觉效果
- [ ] 表格样式是否美观（与现有UI风格一致）
- [ ] 鼠标悬停时行是否高亮
- [ ] 选中行是否有明显的背景色
- [ ] 只读节点（阶段）是否有锁定图标

#### 11. 响应式
- [ ] 表格是否能适应不同屏幕尺寸
- [ ] 列宽调整是否流畅
- [ ] 滚动是否流畅（虚拟滚动）

### ✅ 错误处理测试

#### 12. 异常情况
- [ ] 空数据时是否显示友好提示
- [ ] 网络错误时是否有错误提示
- [ ] 编辑失败时是否有错误提示
- [ ] 删除失败时是否有错误提示

## 三、已知问题和待优化项

### 待实现功能
1. **用户列表**：负责人列的选择器需要从后端获取用户列表
2. **拖拽排序**：目前未实现拖拽排序功能（原计划使用@dnd-kit，但react-data-grid不支持）
3. **批量编辑**：目前只支持批量删除，不支持批量编辑

### 已知限制
1. **react-data-grid版本**：使用6.0.0版本（兼容React 18），部分新功能可能不可用
2. **树形结构**：react-data-grid不原生支持树形结构，需要手动实现展开/折叠逻辑
