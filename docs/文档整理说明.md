# 项目文档整理说明

## 整理完成时间
2025-11-11

## 整理目标
将项目根目录下散落的文档文件统一整理到 `docs/` 目录下，按功能分类存放。

## 目录结构

```
docs/
├── troubleshooting/          # 故障排查文档
│   ├── README.md            # 故障排查文档说明
│   ├── 修复*.txt            # 各种问题修复步骤
│   ├── 排查*.txt            # 问题排查指南
│   ├── 检查*.txt            # 系统检查命令
│   ├── 验证*.txt            # 修复验证步骤
│   └── *.md                 # 问题分析文档
│
├── deployment/               # 部署相关文档
│   ├── commands/            # 部署命令文档（服务器端执行）
│   │   ├── README.md        # 部署命令说明
│   │   ├── 启动*.txt        # 服务启动命令
│   │   ├── 快速*.txt        # 快速启动脚本
│   │   ├── 修复*.txt        # 修复命令（上传后执行）
│   │   └── 服务器*.txt      # 服务器端命令
│   │
│   ├── scripts/             # 部署脚本（本地执行）
│   │   ├── README.md        # 部署脚本说明
│   │   ├── 上传*.ps1        # PowerShell上传脚本
│   │   └── *.ps1            # 其他PowerShell脚本
│   │
│   ├── *.md                 # 部署相关Markdown文档
│   └── README.md            # 部署文档说明
│
├── quick-start/             # 快速开始指南
│   └── (预留目录)
│
└── README.md                # 文档目录总说明
```

## 文件分类规则

### troubleshooting/ - 故障排查文档
包含所有问题修复和排查相关的文档：
- 修复步骤文档（`修复*.txt`）
- 问题排查指南（`排查*.txt`）
- 系统检查命令（`检查*.txt`）
- 修复验证步骤（`验证*.txt`）
- 问题分析文档（`问题*.md`）
- 其他故障排查相关文档

### deployment/commands/ - 部署命令文档
包含服务器端执行的命令文档：
- 服务启动命令（`启动*.txt`）
- 快速启动脚本（`快速*.txt`）
- 修复命令（`修复*.txt` - 上传文件后的执行步骤）
- 服务器端命令（`服务器*.txt`）
- 其他部署相关命令文档

### deployment/scripts/ - 部署脚本
包含本地执行的脚本文件：
- PowerShell上传脚本（`上传*.ps1`）
- 自动化部署脚本
- 文件上传脚本
- 其他本地执行的脚本

### deployment/ - 部署文档
包含部署相关的 Markdown 文档：
- 部署指南（`DEPLOYMENT-*.md`）
- 部署状态（`DEPLOYMENT-STATUS.md`）
- GitHub上传指南（`GITHUB_*.md`）
- 平台介绍（`PLATFORM_INTRODUCTION.md`）
- 其他部署相关文档

## 保留在根目录的文件

以下文件保留在项目根目录，因为它们是项目核心文档：
- `README.md` - 项目主文档
- `CHANGELOG.md` - 变更日志
- `CODE_REVIEW_REPORT.md` - 代码审查报告
- `PROJECT_CHECK_REPORT.md` - 项目检查报告
- `check-env.ps1` - 环境检查脚本（常用工具）
- `check-services.ps1` - 服务检查脚本（常用工具）
- `update-env.ps1` - 环境更新脚本（常用工具）

## 使用说明

1. **查找故障排查文档**：查看 `docs/troubleshooting/` 目录
2. **查找部署命令**：查看 `docs/deployment/commands/` 目录
3. **查找部署脚本**：查看 `docs/deployment/scripts/` 目录
4. **查找快速启动指南**：查看 `docs/quick-start/` 目录
