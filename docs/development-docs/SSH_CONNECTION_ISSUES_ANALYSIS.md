# SSH连接卡住问题分析

## 问题现象

- **症状**: 多次SSH连接后，连接会卡住不动
- **触发条件**: 连续执行多个SSH命令后
- **影响**: 测试脚本无法继续执行

## 根本原因分析

### 1. ControlMaster连接文件损坏
- Windows上ControlMaster支持不稳定
- 连接文件(`~/.ssh/control-*`)可能损坏但未被清理
- 后续连接尝试复用损坏的连接，导致卡住

### 2. 连接资源泄漏
- SSH进程没有正确关闭
- 后台连接进程累积
- 系统资源耗尽

### 3. 网络层问题
- TCP连接处于半开状态
- 服务器端连接未正确关闭
- 防火墙或网络设备超时设置

### 4. PowerShell Job管理问题
- Job没有正确清理
- 多个Job同时执行导致冲突

## 解决方案

### 方案1: 每次执行前清理（当前采用）
- ✅ 执行前强制清理ControlMaster连接文件
- ✅ 清理僵尸SSH进程
- ✅ 使用Job和超时机制
- ✅ 不使用ControlMaster（避免Windows兼容性问题）

### 方案2: 连接健康检查
- 定期检查连接健康
- 检测到问题自动清理
- 自动重建连接

### 方案3: 连接池管理
- 维护活跃连接列表
- 自动清理过期连接
- 限制最大连接数

## 当前实现

使用 `ssh-exec-reliable.ps1`:
- 每次执行前清理旧连接
- 使用Job + 超时机制
- 不使用ControlMaster
- 自动清理僵尸进程

## 最佳实践

1. **每次执行前清理**: 避免复用损坏的连接
2. **使用超时**: 防止无限等待
3. **避免ControlMaster**: Windows上不稳定
4. **定期清理**: 防止资源泄漏
5. **错误重试**: 自动处理临时故障
