# 服务器操作智能体部署指南

## 📋 概述

服务器操作智能体是一个基于LLM的智能体，能够理解用户需求并将其转化为安全的服务器命令序列并执行。该智能体集成了SSHCommandExecutor工具，可以直接在远程服务器上执行操作。

## 🏗️ 架构

```
用户请求 → 智能体对话框 → 服务器操作智能体 → LLM生成计划 → SSH执行器 → 远程服务器
```

## 📦 组件

1. **ServerOperationAgent** (`agent-service/src/core/agents/server_operation_agent.py`)
   - 核心智能体逻辑
   - 集成LLM生成执行计划
   - 调用SSH执行器执行命令

2. **API路由** (`agent-service/src/routes/server_operation.py`)
   - `/server-operation/execute` - 执行服务器操作
   - `/server-operation/plan` - 仅生成计划
   - `/server-operation/health` - 健康检查

3. **SSH执行器** (`tools/ssh_executor.py`)
   - SSH连接管理
   - 命令执行
   - 文件传输

## 🚀 部署步骤

### 1. 准备SSH密钥

确保服务器上有SSH密钥文件：

```bash
# 在服务器上
ls -la /opt/enterprise-ai-platform/enterprise_ai_platform.pem
chmod 600 /opt/enterprise-ai-platform/enterprise_ai_platform.pem
```

### 2. 配置环境变量

在 `docker-compose.yml` 或 `.env` 文件中添加：

```bash
# SSH配置
SSH_HOST=43.143.139.197
SSH_USERNAME=ubuntu
SSH_PRIVATE_KEY_PATH=/opt/enterprise-ai-platform/enterprise_ai_platform.pem
SSH_BASE_WORKDIR=/opt/enterprise-ai-platform
SSH_PORT=22
SSH_CONNECTION_TIMEOUT=30
```

### 3. 安装依赖

确保 `agent-service/requirements.txt` 包含：

```
paramiko>=2.12.0
```

### 4. 复制工具文件

确保 `tools` 目录被复制到容器中：

```dockerfile
# 在 Dockerfile 中添加
COPY ../tools /app/tools
```

或者使用卷挂载：

```yaml
# 在 docker-compose.yml 中
volumes:
  - ../tools:/app/tools:ro
```

### 5. 构建和启动服务

```bash
# 构建镜像
cd agent-service
docker build -t server-operation-agent .

# 或使用 docker-compose
docker-compose -f docker-compose.server-operation.yml up -d
```

### 6. 验证部署

```bash
# 健康检查
curl http://localhost:8002/server-operation/health

# 测试执行
curl -X POST http://localhost:8002/server-operation/execute \
  -H "Content-Type: application/json" \
  -d '{
    "user_request": "查看docker服务状态",
    "auto_execute": true
  }'
```

## 💻 使用方式

### 方式1: 通过API调用

```python
import requests

response = requests.post(
    "http://43.143.139.197:8002/server-operation/execute",
    json={
        "user_request": "重启web-ui服务",
        "project_id": "test-project",
        "auto_execute": True
    }
)

result = response.json()
print(result)
```

### 方式2: 通过智能体对话框

在AIOS平台的智能体对话框中输入：

```
查看docker服务状态
```

或

```
部署项目到服务器，拉取main分支代码并重启web-ui服务
```

智能体会：
1. 理解需求
2. 生成执行计划
3. 执行命令
4. 返回结果

### 方式3: 仅生成计划（不执行）

```python
response = requests.post(
    "http://43.143.139.197:8002/server-operation/plan",
    json={
        "user_request": "部署项目",
        "auto_execute": False
    }
)

plan = response.json()
print(plan["plan"])  # 查看生成的计划
```

## 📝 使用示例

### 示例1: 查看服务状态

**用户输入**: "查看所有docker服务的状态"

**智能体生成计划**:
```json
{
  "plan_name": "查看Docker服务状态",
  "description": "检查所有Docker容器的运行状态",
  "execution_mode": "sequence",
  "commands": [
    "docker compose ps",
    "docker compose ps --format json"
  ],
  "expected_outcomes": [
    "显示所有服务的状态信息",
    "返回JSON格式的服务状态"
  ]
}
```

**执行结果**: 返回所有服务的状态信息

    HostName 43.143.139.197
    User ubuntu

    IdentityFile /opt/enterprise-ai-platform/enterprise_ai_platform.pem

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `SSH_HOST` | 服务器地址 | `43.143.139.197` |
| `SSH_USERNAME` | SSH用户名 | `ubuntu` |
| `SSH_PRIVATE_KEY_PATH` | 私钥路径 | `/opt/enterprise-ai-platform/enterprise_ai_platform.pem` |

| `SSH_CONNECTION_TIMEOUT` | 连接超时 | `30` |

## 🔍 故障排查

### 问题1: SSH连接失败

**检查项**:
1. SSH密钥文件是否存在且权限正确
2. 服务器地址和端口是否正确
3. 网络连接是否正常
4. SSH服务是否运行

**解决方案**:
```bash
# 检查密钥权限
chmod 600 /opt/enterprise-ai-platform/enterprise_ai_platform.pem

# 测试SSH连接
ssh -i /opt/enterprise-ai-platform/enterprise_ai_platform.pem ubuntu@43.143.139.197
```

### 问题2: 工具导入失败

**检查项**:
1. `tools` 目录是否在Python路径中
2. `paramiko` 是否已安装

**解决方案**:
```bash
# 安装依赖
pip install paramiko>=2.12.0

# 检查Python路径
python -c "import sys; print(sys.path)"
```

### 问题3: LLM生成计划失败

**检查项**:
1. LLM服务是否正常运行
2. API密钥是否正确配置
3. 网络连接是否正常

**解决方案**:
```bash
# 检查LLM服务
curl http://llm-service:8000/health

# 检查环境变量
echo $DEEPSEEK_API_KEY
```

## 📊 API文档

### POST /server-operation/execute

执行服务器操作

**请求体**:
```json
{
  "user_request": "查看服务状态",
  "project_id": "optional-project-id",
  "context": {},
  "auto_execute": true
}
```

**响应**:
```json
{
  "success": true,
  "plan": {
    "plan_name": "查看服务状态",
    "commands": ["docker compose ps"],
    ...
  },
  "execution_result": {
    "success": true,
    "commands_executed": 1,
    "commands_succeeded": 1,
    "results": [...],
    "summary": "执行了 1 条命令，成功 1 条"
  },
  "message": "操作完成"
}
```

### POST /server-operation/plan

仅生成执行计划，不执行

**请求体**: 同 `/execute`

**响应**:
```json
{
  "success": true,
  "plan": {
    "plan_name": "...",
    "commands": [...],
    ...
  },
  "message": "执行计划生成成功"
}
```
