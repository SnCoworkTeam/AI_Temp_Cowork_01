# 解决表格显示问题指南

## 问题现象
页面仍然显示提示："表格功能暂时不可用（react-data-grid 6.x 兼容性问题），已切换到列表视图"

## 原因分析
代码已经修复，但可能因为以下原因导致页面仍显示旧内容：
1. **浏览器缓存**：浏览器缓存了旧的 JavaScript 文件
2. **开发服务器未重启**：Next.js 开发服务器需要重启以加载新的依赖
3. **热更新未生效**：Next.js 的热更新可能没有检测到依赖变化

## 解决步骤

### 步骤 1：重启开发服务器

**停止当前服务器**（按 `Ctrl+C`），然后重新启动：

```bash
cd web-ui
npm run dev
```

### 步骤 2：清除浏览器缓存

**方法 1：硬刷新**
- Windows/Linux: `Ctrl + Shift + R` 或 `Ctrl + F5`
- Mac: `Cmd + Shift + R`

**方法 2：清除缓存**
1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

**方法 3：使用无痕模式**
- 打开浏览器的无痕/隐私模式
- 访问页面测试

### 步骤 3：验证修复

检查以下内容确认修复成功：

1. **检查控制台**：
   - 打开浏览器开发者工具（F12）
   - 查看 Console 标签
   - 不应该有 `DataGrid is not defined` 或类似的错误

2. **检查网络请求**：
   - 打开 Network 标签
   - 刷新页面
   - 确认加载的是最新的 JavaScript 文件

3. **检查页面显示**：
   - 应该看到 Excel 风格的表格，而不是列表视图
   - 不应该看到黄色提示框

### 步骤 4：如果问题仍然存在

#### 4.1 清除 Next.js 缓存

```bash
cd web-ui
rm -rf .next
npm run dev
```

Windows PowerShell:
```powershell
cd web-ui
Remove-Item -Recurse -Force .next
npm run dev
```

#### 4.2 重新安装依赖

```bash
cd web-ui
rm -rf node_modules
rm package-lock.json
npm install
npm run dev
```

#### 4.3 检查代码是否正确

确认 `PlanExcelTable.tsx` 文件包含：

```tsx
import DataGrid, { ... } from 'react-data-grid';
import 'react-data-grid/lib/styles.css';
```

并且返回的 JSX 中使用的是 `<DataGrid ... />` 而不是列表视图。

## 如果仍然有问题

1. **检查版本**：
   ```bash
   cd web-ui
   npm list react-data-grid
   ```
   应该显示 `react-data-grid@7.0.0-beta.59`

2. **检查导入**：
   打开 `web-ui/src/components/ProjectPlans/PlanExcelTable.tsx`
   确认第 4 行是：
   ```tsx
   import DataGrid, { ... } from 'react-data-grid';
   ```

3. **查看完整错误信息**：
   - 打开浏览器开发者工具
   - 查看 Console 和 Network 标签
   - 截图错误信息
