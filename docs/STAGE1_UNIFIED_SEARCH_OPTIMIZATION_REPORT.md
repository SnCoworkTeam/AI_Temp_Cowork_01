## 🎯 技术实现

### 缓存策略

1. **缓存键生成**
   - 基于查询文本、类型、限制、过滤条件
   - MD5哈希确保唯一性
   - 查询文本标准化（小写、去空格）

2. **缓存层级**
   - L1（内存）：热点查询，最快
   - L2（Redis）：跨服务共享，容量大

3. **缓存失效**
   - TTL机制（5分钟）
   - 手动清除接口

### 并行调用策略

1. **任务准备**
   - 根据types准备搜索任务
   - 每个任务独立超时

2. **并行执行**
   - 使用`asyncio.gather`并行执行
   - `return_exceptions=True`确保部分失败不影响整体

3. **结果处理**
   - 独立处理每个任务的结果
   - 错误隔离
