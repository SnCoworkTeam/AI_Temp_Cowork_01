**关键代码**:
```python
class BaseAgent(ABC):
    @abstractmethod
    async def plan(self, task: str, context: Optional[Dict] = None) -> Union[ExecutionPlan, AsyncIterator[str]]:
        """规划任务"""
        pass

    @abstractmethod
    async def execute(self, plan: ExecutionPlan, context: Optional[Dict] = None) -> ExecutionResult:
        """执行计划"""
        pass
```

## 📊 架构改进

### 改进前
```
ServerOperationAgent (独立类)
  ├─ generate_plan()
  ├─ execute_plan()
  └─ process_request()

其他智能体 (各自独立)
  ├─ AnalysisAgent
  ├─ WorkflowAgent
  └─ ...
```

### 改进后
```
BaseAgent (统一基类)
  ├─ plan()
  ├─ execute()
  ├─ reflect()
  └─ plan_and_execute()

ServerOperationAgent (继承BaseAgent)
  ├─ plan() ✅
  ├─ execute() ✅
  ├─ generate_plan() (向后兼容)
  └─ execute_plan() (向后兼容)

ReActEngine
  └─ react_loop()

ToolRegistry
  └─ 统一工具管理
```

## 🎯 核心改进点

### 1. 接口统一
- **之前**: 每个智能体有自己的方法签名
- **现在**: 所有智能体实现相同的 `plan()` 和 `execute()` 接口

### 2. 数据格式统一
- **之前**: 每个智能体返回不同的数据格式
- **现在**: 统一使用 `ExecutionPlan` 和 `ExecutionResult`

### 3. 状态管理
- **之前**: 没有统一的状态跟踪
- **现在**: 使用 `AgentState` 枚举跟踪状态

### 4. 工具管理
- **之前**: 工具调用分散在各个智能体中
- **现在**: 统一的 `ToolRegistry` 管理所有工具

### 5. ReAct模式
- **之前**: 没有思考-行动-观察循环
- **现在**: `ReActEngine` 提供完整的ReAct实现

## 📝 使用示例

### 使用统一接口

