# 自动生成文档

本目录包含自动生成的文档，**请勿手动编辑**。

## 文档类型

- **code-docs/**: 从代码注释自动生成的代码文档
- **dependency-graphs/**: 模块依赖关系图
- **api-reference/**: 从OpenAPI规范生成的API参考

## 生成文档

运行以下命令生成所有文档：

```bash
python scripts/docs/generate-all.py
```

## 更新文档

文档会在以下情况自动更新：
- CI/CD流水线中
- 代码提交前（通过pre-commit钩子）
- 手动运行生成脚本

## 注意事项

- 这些文件是自动生成的，手动修改会被覆盖
- 文档版本与代码版本同步
- 如需修改文档，请修改源代码注释或配置
