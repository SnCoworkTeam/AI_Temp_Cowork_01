## 📝 演示脚本

### 演示脚本1: 知识图谱查询（完整版）

```bash
#!/bin/bash

echo "=== 知识图谱演示 ==="
echo ""

echo "1. 知识图谱统计"
echo "----------------"
curl -s http://localhost:8005/api/knowledge-graph/stats | jq '.statistics'

echo ""
echo "2. 查询实体列表（前10个）"
echo "----------------"
curl -s http://localhost:8005/api/knowledge-graph/nodes?node_type=concept&limit=10 | jq '.[:5] | .[] | {id, label, node_type}'

echo ""
echo "3. 查询关系（前10个）"
echo "----------------"
curl -s http://localhost:8005/api/knowledge-graph/edges?limit=10 | jq '.[:5] | .[] | {source, target, relationship_type}'

echo ""
echo "4. 查询特定实体的关系"
echo "----------------"
# 获取第一个实体ID
FIRST_NODE_ID=$(curl -s http://localhost:8005/api/knowledge-graph/nodes?node_type=concept&limit=1 | jq -r '.[0].id')
if [ "$FIRST_NODE_ID" != "null" ] && [ -n "$FIRST_NODE_ID" ]; then
    curl -s "http://localhost:8005/api/knowledge-graph/nodes/$FIRST_NODE_ID/relationships" | jq '.relationships[:5]'
fi

echo ""
echo "=== 演示完成 ==="
```
