#### 3. 计划树形结构接口 ✅

**接口**: `GET /api/v1/projects/{project_id}/plans/{plan_id}/tree`

**响应模型**:
```python
class PlanTreeResponse(BaseModel):
    plan_id: str
    plan_name: str
    tree: List[PlanTreeNode]

class PlanTreeNode(BaseModel):
    id: str
    type: str  # 'phase' or 'task'
    name: str
    category_id: Optional[str]
    category_code: Optional[str]
    sequence: Optional[int]
    is_readonly: bool  # 阶段节点为True
    phase_id: Optional[str]
    status: Optional[str]
    progress_percent: Optional[float]
    children: List['PlanTreeNode']
```

**核心功能**:
- ✅ 获取项目的所有阶段（按sequence排序）
- ✅ 获取计划的所有任务
- ✅ 构建树形结构（阶段为父节点，任务为子节点）
- ✅ 阶段节点标记为只读（`is_readonly=True`）
- ✅ 任务节点可编辑（`is_readonly=False`）

## 技术要点

### 1. 模板结构设计

模板的`template_structure`字段存储JSON格式：
```json
{
  "phases": [
    {
      "category_id": "uuid",
      "category_code": "01",
      "category_name": "01-准备/可研",
      "sequence": 1,
      "tasks": []
    }
  ]
}
```

### 2. 阶段数据来源

- 阶段数据来源于基础数据分类（`category_type = 'project_phase'`）
- 创建阶段时自动从基础数据同步名称、编码、顺序
- 阶段节点在树形结构中标记为只读

### 3. 树形结构构建

- 阶段按`sequence`排序
- 任务按`phase_id`分组到对应阶段下
- 阶段节点`is_readonly=True`，任务节点`is_readonly=False`
