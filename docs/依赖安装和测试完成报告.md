## 📝 使用说明

### 日常开发

1. **代码编写**: VS Code会自动格式化和检查
2. **提交代码**: Git钩子会自动运行检查
3. **手动检查**: 运行 `npm run lint` (前端) 或 `ruff check` (后端)

### 提交前检查

当执行 `git commit` 时，会自动：
1. 运行Prettier格式化代码
2. 运行ESLint修复错误
3. 运行ESLint检查（如有错误会阻止提交）

### 手动格式化

```bash
# 前端
cd web-ui
npx prettier --write "src/**/*.{ts,tsx}"
npm run lint -- --fix

# 后端
cd project_management
black src/
isort src/
ruff check --fix src/
```
