# 依赖版本冲突修复说明

## 问题描述

在构建 mcp-gateway 服务时遇到依赖版本冲突错误：
```
ERROR: Could not find a version that satisfies the requirement pydantic-core==2.14.1 (from pydantic)
```

## 问题原因

`pydantic==2.5.0` 需要 `pydantic-core==2.14.1`，但该版本在 PyPI 上不可用或与当前环境不兼容。

## 解决方案

将所有 `requirements.txt` 文件中的固定版本改为范围版本，让 pip 自动解决依赖冲突：

### 修改前
```txt
pydantic==2.5.0
pydantic-settings==2.1.0
```

### 修改后
```txt
pydantic>=2.5.0,<3.0.0
pydantic-settings>=2.1.0,<3.0.0
```

## 已修复的文件

1. ✅ `shared_libs/requirements.txt`
2. ✅ `mcp-gateway/requirements.txt`
3. ✅ `workflow-engine/requirements.txt`
4. ✅ `auth-service/requirements.txt`
5. ✅ `knowledge-base/requirements.txt`
6. ✅ `metadata-service/requirements.txt`
7. ✅ `database/requirements.txt`

## 修改内容

所有文件中的以下依赖已从固定版本改为范围版本：
- `pydantic`: `==2.5.0` → `>=2.5.0,<3.0.0`
- `pydantic-settings`: `==2.1.0` → `>=2.1.0,<3.0.0`
- `fastapi`: `==0.104.1` → `>=0.104.1,<1.0.0`
- `uvicorn[standard]`: `==0.24.0` → `>=0.24.0,<1.0.0`
- `httpx`: `==0.25.2` → `>=0.25.2,<1.0.0`
- `redis`: `==5.0.1` → `>=5.0.1,<6.0.0`
- `python-dotenv`: `==1.0.0` → `>=1.0.0,<2.0.0`
- `psutil`: `==5.9.6` → `>=5.9.6,<6.0.0`

## 优势

1. **自动依赖解析**: pip 可以自动选择兼容的版本
2. **避免版本冲突**: 范围版本允许 pip 解决依赖冲突
3. **保持兼容性**: 使用范围版本确保不会升级到不兼容的主版本
