# 故障排查文档

本目录包含所有故障排查和问题修复相关的文档。

## 文档分类

### 修复文档
- `修复*.txt` - 各种问题的修复步骤和解决方案

### 排查文档
- `排查*.txt` - 问题排查指南和诊断步骤

### 检查文档
- `检查*.txt` - 系统检查命令和验证步骤

### 验证文档
- `验证*.txt` - 修复验证和测试步骤

### 问题分析文档
- `问题*.md` - 问题分析和解决方案文档
- `Docker网络问题解决方案.md` - Docker网络问题解决方案
- `依赖版本修复说明.md` - 依赖版本修复说明

## 使用说明

1. 遇到问题时，先查看相关的问题分析文档
2. 按照排查文档进行问题诊断
3. 根据修复文档执行修复步骤
4. 使用验证文档确认修复成功
