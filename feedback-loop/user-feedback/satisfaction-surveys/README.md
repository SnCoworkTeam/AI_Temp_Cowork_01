# 满意度调查

## 概述

满意度调查用于收集用户对产品的整体满意度和意见。

## 调查类型

### 1. NPS (Net Promoter Score)
净推荐值，衡量用户推荐意愿。

#### NPS问题
"您有多大可能向朋友或同事推荐我们的产品？"
- 0-10分评分

#### NPS计算
- **推荐者 (9-10分)**: 推荐产品的用户
- **中立者 (7-8分)**: 中立态度的用户
- **贬损者 (0-6分)**: 不推荐产品的用户

NPS = (推荐者% - 贬损者%) × 100

### 2. CSAT (Customer Satisfaction)
客户满意度，衡量用户对特定功能的满意度。

#### CSAT问题
"您对[功能]的满意度如何？"
- 非常满意
- 满意
- 一般
- 不满意
- 非常不满意

#### CSAT计算
CSAT = (满意用户数 / 总用户数) × 100

### 3. CES (Customer Effort Score)
客户努力度，衡量用户完成任务的难易程度。

#### CES问题
"完成[任务]对您来说有多容易？"
- 1-7分评分

#### CES计算
CES = 平均评分

## 调查设计

### 调查频率
- **NPS**: 每季度一次
- **CSAT**: 功能使用后
- **CES**: 任务完成后

### 调查渠道
- 产品内调查
- 邮件调查
- 电话调查
- 现场调查

### 调查问题
- 核心问题（必答）
- 开放性问题（可选）
- 背景问题（可选）

## 调查分析

### 数据分析
- 评分统计
- 趋势分析
- 细分分析

### 反馈分析
- 关键词提取
- 主题分类
- 情感分析

### 改进识别
- 识别改进机会
- 优先级排序
- 改进计划

## 调查模板

### NPS调查模板
```markdown
# NPS调查

1. 您有多大可能向朋友或同事推荐我们的产品？
   [0-10分]

2. 为什么给出这个分数？
   [开放性问题]

3. 您对我们的产品有什么建议？
   [开放性问题]
```

### CSAT调查模板
```markdown
# CSAT调查

1. 您对[功能]的满意度如何？
   [非常满意/满意/一般/不满意/非常不满意]

2. 您最喜欢[功能]的哪些方面？
   [开放性问题]

3. 您希望[功能]如何改进？
   [开放性问题]
```
