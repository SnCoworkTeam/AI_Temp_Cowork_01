# 变更请求

## 概述

本目录包含所有变更请求记录。

## 变更请求流程

1. 使用模板创建变更请求
2. 填写变更描述和影响分析
3. 提交审查和批准
4. 实施变更
5. 验证和关闭

## 变更请求编号

格式: `CHANGE-XXXX`

- 从0001开始
- 按顺序递增
- 永不重复

## 变更请求状态

- **待审查**: 刚创建，等待审查
- **审查中**: 正在审查
- **已批准**: 审查通过，可以实施
- **已拒绝**: 审查拒绝，需要修改或取消
- **实施中**: 正在实施变更
- **已完成**: 变更完成并验证
- **已取消**: 变更被取消

## 创建变更请求

```bash
# 使用模板创建
cp release-management/change-control/change-requests/template.md \
   release-management/change-control/change-requests/CHANGE-0001.md

# 编辑变更请求
# 填写所有相关部分
```
