# 测试覆盖率80%提升计划（命令执行+超时保护）

## 目标
所有服务（auth-service, knowledge-base, metadata-service, workflow-engine, mcp-gateway, database）的测试覆盖率达到80%。

## 执行方式
- **不使用PowerShell脚本**，直接执行命令
- **所有命令设置10秒超时**，超时后自动重试
- **Windows命令使用分号`;`分隔，不使用`&&`**
- 在Cursor中通过终端工具执行命令（但要注意Cursor终端可能卡住，如果卡住需要在原生终端执行）
- 使用SSH（remote.ssh配置）上传文件到服务器
- 在服务器Docker容器中执行测试
- 自动修复测试错误
- 按服务逐个处理，循环执行直到完成

## 服务列表（按优先级）
1. auth-service
2. knowledge-base
3. metadata-service
4. workflow-engine
5. mcp-gateway
6. database

## 命令执行规范

### 超时和重试机制
- **所有SSH命令**：使用 `-o ConnectTimeout=10` 设置连接超时
- **所有远程命令**：使用 `timeout 10` 或 `timeout 120`（测试命令用120秒）
- **本地命令**：如果超过10秒无响应，按 `Ctrl+C` 中断后重试
- **重试策略**：超时后等待2秒，然后重新执行，最多重试3次

### 命令分隔符
- **Windows PowerShell/CMD**：使用分号 `;` 分隔多个命令
- **Linux/SSH远程命令**：使用分号 `;` 分隔多个命令
- **禁止使用**：`&&`（Windows不支持）

## 主要步骤（每个服务）

### 1. 检查当前覆盖率
```bash
# 设置10秒连接超时，120秒执行超时
ssh -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server "cd /opt/enterprise-ai-platform; timeout 120 bash scripts/test-coverage/check-coverage-server.sh"
```

**如果超时**：等待2秒后重试，最多3次

### 2. 生成测试文件
```bash
# 本地执行，如果超过10秒无响应，按Ctrl+C中断后重试
py scripts/test-coverage/improve-coverage.py --service <service-name>
```

### 3. 提交并上传到服务器
```bash
# 使用分号分隔命令
git add <service-name>/tests/unit/test_*.py; git commit -m "test: 添加<service-name>测试文件"; git push origin main

# SSH命令设置超时
ssh -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server "cd /opt/enterprise-ai-platform; timeout 10 git pull origin main"
```

**如果超时**：等待2秒后重试，最多3次

### 4. 在服务器Docker中执行测试
```bash
# 设置10秒连接超时，120秒执行超时（测试需要更长时间）
ssh -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server "cd /opt/enterprise-ai-platform; timeout 120 bash scripts/test-coverage/run-tests-in-docker.sh"
```

**如果超时**：等待2秒后重试，最多3次

### 5. 下载测试结果
```bash
# SCP命令也设置超时
scp -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server:/tmp/.test-results.json .test-results.json
```

**如果超时**：等待2秒后重试，最多3次

### 6. 自动修复测试错误
```bash
# 本地执行
py scripts/test-coverage/auto-fix-tests.py --test-results .test-results.json
```

### 7. 提交修复后的文件
```bash
# 使用分号分隔
git add .; git commit -m "fix: 修复<service-name>测试错误"; git push origin main

# 服务器拉取
ssh -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server "cd /opt/enterprise-ai-platform; timeout 10 git pull origin main"
```

### 8. 验证覆盖率
```bash
# 检查覆盖率
ssh -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server "cd /opt/enterprise-ai-platform; timeout 120 bash scripts/test-coverage/check-coverage-server.sh"

# 下载覆盖率结果
scp -F remote.ssh -o ConnectTimeout=10 enterprise-ai-server:/tmp/.coverage-status.json .coverage-status.json

# 检查是否达到80%
py -c "import json; data=json.load(open('.coverage-status.json')); coverage=data['services']['<service-name>']['coverage']; print(f'Coverage: {coverage}%'); exit(0 if coverage >= 80 else 1)"
```

### 9. 循环执行
如果覆盖率 < 80%，重复步骤2-8，直到达到80%覆盖率。

## 超时处理流程

### 如果命令超时：
1. 按 `Ctrl+C` 中断当前命令
2. 等待2秒
3. 重新执行命令
4. 如果连续3次超时，跳过该步骤，记录错误，继续下一步

### 如果Cursor终端卡住：
1. 不要继续在Cursor中执行
2. 打开原生Windows PowerShell或CMD
3. 按照相同的命令清单执行
4. 所有命令都设置了超时，不会无限等待

## 注意事项
- **所有命令使用分号`;`分隔，不使用`&&`**
- **所有SSH命令都设置 `-o ConnectTimeout=10`**
- **所有远程命令都使用 `timeout` 命令**
- **如果命令超过10秒无响应，中断后重试**
- **如果Cursor终端卡住，切换到原生终端执行**
- **每次执行前确保在正确的目录** (`E:\enterprise-ai-platform`)
