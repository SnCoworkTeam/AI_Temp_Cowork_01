### Q2: 怎么结合LLM？

**答案**：✅ **三层融合机制**

#### 机制1：并行处理（不阻塞）
```python
# LLM思考和元数据检索并行进行
metadata_task = asyncio.create_task(retrieve_metadata())
thinking_task = asyncio.create_task(llm_deep_think())

metadata, thinking = await asyncio.gather(metadata_task, thinking_task)
```

#### 机制2：验证和增强（不限制）
```python
# 元数据验证和增强LLM思考结果
validated_thinking = validate_and_enhance(
    thinking_result,  # LLM思考结果（主导）
    metadata          # 元数据（增强）
)
```

#### 机制3：融合决策（智能结合）
```python
# 融合LLM思考和元数据
final_plan = fuse_thinking_and_metadata(
    validated_thinking,  # 验证后的思考结果
    metadata,           # 元数据
    user_input
)
```

## 二、元数据在LLM思考中的具体作用

### 2.1 作用1：提供业务上下文（思考前）

**时机**：LLM思考时（作为参考，不强制）

**作用**：
```python
# LLM思考时的提示词
prompt = f"""
用户请求: "{user_input}"

可用业务上下文（参考，不限制）:
- 可用工具: {metadata['tools']}
- 业务实体: {metadata['business_entities']}
- SAP服务: {metadata['sap_services']}

请基于以上上下文（但不被限制），深度思考用户需求...
"""
```

**关键**：
- ✅ 提供上下文，帮助理解
- ✅ 不限制LLM的思考方向
- ✅ 如果元数据不可用，LLM自主思考

### 2.2 作用2：验证和增强（思考后）

**时机**：LLM思考完成后

**作用**：
```python
# 验证和增强LLM思考结果
for step in thinking_result['steps']:
    # 验证工具是否存在
    if step['method'] == 'tool':
        if tool_exists(step['tool_name'], metadata['tools']):
            # 增强工具元数据
            step['tool_metadata'] = get_tool_metadata(step['tool_name'])
        else:
            # 工具不存在，但不强制替换，让执行层处理
            step['tool_validation'] = {'exists': False}
    
    # 增强SAP相关步骤
    if 'sap' in step['action']:
        # 从业务实体获取表名
        table_name = extract_table_name(metadata['business_entities'])
        if table_name:
            step['input']['table'] = table_name
```

**关键**：
- ✅ 验证思考结果的准确性
- ✅ 补充缺失的技术信息
- ✅ 不改变LLM的核心决策

### 2.3 作用3：优化执行计划（融合时）

**时机**：最终决策阶段

**作用**：
```python

if thinking_result['confidence'] > 0.8:
    # 高置信度，直接使用，但用元数据优化
    final_plan = enhance_with_metadata(thinking_result, metadata)

    # 低置信度，使用元数据重新思考

```

**关键**：
- ✅ 优化执行效率
- ✅ 添加错误处理策略
- ✅ 提供性能优化建议
