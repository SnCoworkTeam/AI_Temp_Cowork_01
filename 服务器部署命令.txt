========================================
服务器部署命令（手动执行）
========================================

由于SSH连接超时，请手动在服务器上执行以下命令：

1. 上传文件（在本地Windows PowerShell中执行）：
----------------------------------------
scp -i enterprise_ai_platform.pem database/src/models/system_models.py ubuntu@43.143.139.197:/opt/enterprise-ai-platform/database/src/models/system_models.py

scp -i enterprise_ai_platform.pem knowledge-base/src/repositories/search_history_repository.py ubuntu@43.143.139.197:/opt/enterprise-ai-platform/knowledge-base/src/repositories/search_history_repository.py

scp -i enterprise_ai_platform.pem knowledge-base/src/core/embedding_manager.py ubuntu@43.143.139.197:/opt/enterprise-ai-platform/knowledge-base/src/core/embedding_manager.py

2. SSH连接到服务器并安装依赖：
----------------------------------------
ssh -i enterprise_ai_platform.pem ubuntu@43.143.139.197

# 在服务器上执行：
cd /opt/enterprise-ai-platform
docker exec enterprise-ai-knowledge-base pip install --upgrade sentence-transformers huggingface-hub --no-cache-dir

3. 重启服务：
----------------------------------------
docker compose restart knowledge-base

4. 等待并检查状态：
----------------------------------------
# 等待30秒
sleep 30

# 检查服务状态
docker compose ps knowledge-base

# 检查模型加载
docker exec enterprise-ai-knowledge-base python -c "import sys; sys.path.insert(0, '/app'); from src.core.embedding_manager import get_embedding_manager; em = get_embedding_manager(); print('Model available:', em.is_available()); print('Has model:', em.model is not None)"

# 查看日志
docker logs enterprise-ai-knowledge-base --tail 50
