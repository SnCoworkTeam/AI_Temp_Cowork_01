# 统一意图识别、流式处理、动态流程科学整合方案

## 🎯 核心问题

如何科学整合三个核心能力：
1. **统一意图识别**：理解用户想做什么
2. **流式处理能力**：实时反馈处理过程
3. **动态流程执行**：根据任务动态设计执行路径

**关键**：不是简单堆砌，而是科学的架构整合。

## 📊 主流AI平台实现分析

### 1. Cursor的实现方式

**架构特点**：
```
用户输入
    ↓
[统一入口：Composer]
    ├─→ 意图理解（流式返回）
    │   ├─→ 代码理解
    │   ├─→ 任务分析
    │   └─→ 工具发现
    │
    ├─→ 动态规划（流式返回）
    │   ├─→ 任务分解
    │   ├─→ 执行计划
    │   └─→ 依赖分析
    │
    └─→ 执行（流式返回）
        ├─→ 工具调用（实时反馈）
        ├─→ 代码生成（流式输出）
        └─→ 结果验证（实时反馈）
```

**核心设计**：
- ✅ **端到端流式**：从意图识别到执行，全程流式返回
- ✅ **动态规划**：根据意图动态设计执行计划
- ✅ **统一入口**：Composer作为统一入口，整合所有能力
- ✅ **渐进式反馈**：每个阶段都实时返回中间结果

### 2. Claude的实现方式

**架构特点**：
```
用户输入
    ↓
[Claude API统一处理]
    ├─→ 意图理解（内置，流式）
    │   └─→ 单次LLM调用完成意图理解+执行决策

    ├─→ 工具调用（动态，流式）
    │   ├─→ 自动发现工具
    │   ├─→ 自动组合工具
    │   └─→ 流式返回工具结果
    │
    └─→ 结果生成（流式）
        └─→ 实时生成回复内容
```

**核心设计**：
- ✅ **单模型端到端**：一次LLM调用完成意图理解+执行决策
- ✅ **内置流式**：所有处理都支持流式返回
- ✅ **动态工具调用**：根据意图动态选择和调用工具
- ✅ **统一接口**：所有能力通过统一API暴露

## 🔍 主流平台的核心设计模式

### 模式1：端到端流式架构（Cursor/Claude）

**特点**：
- 从意图识别到执行，全程流式返回
- 每个阶段都实时反馈
- 统一的流式接口

**优势**：
- ✅ 用户体验好（实时反馈）
- ✅ 架构简洁（统一接口）
- ✅ 易于扩展（新能力可以无缝集成）

### 模式2：统一模型架构（Claude/ChatGPT）

**特点**：
- 意图识别和执行决策通过同一个模型完成
- 通过系统提示词和函数调用机制实现
- 减少多次调用，提高效率

**优势**：
- ✅ 效率高（单次调用）
- ✅ 一致性好（同一模型）
- ✅ 成本低（减少API调用）

### 模式3：动态规划架构（Cursor）

**特点**：
- 意图识别后，动态规划执行路径
- 根据任务复杂度选择执行策略
- 支持动态调整执行计划

**优势**：
- ✅ 灵活性高（适应各种场景）
- ✅ 效率优化（根据任务选择最优路径）
- ✅ 可扩展性强（易于添加新能力）

## 📋 当前平台方案分析

### 当前架构

```
用户输入
    ↓
[前端选择]
    ├─→ 路径A：动态工作流（DynamicExecutionEngine）
    │   ├─→ 动态设计智能体网络（流式）
    │   └─→ 执行智能体网络（流式）
    │
    ├─→ 路径B：统一意图识别（UnifiedIntentService）
    │   ├─→ LLM意图分析（批处理）
    │   ├─→ 语义引擎查询（批处理）
    │   └─→ 融合策略（批处理）
    │
    └─→ 路径C：流式编排（OrchestrationEngine）
        ├─→ 意图分析（流式）
        ├─→ 路由决策（流式）
        └─→ 执行（流式）
```

### 问题分析

#### 问题1：三套系统独立，缺乏整合

**现状**：
- `UnifiedIntentService`：批处理，固定流程
- `DynamicExecutionEngine`：流式，动态流程
- `OrchestrationEngine`：流式，固定路由

**问题**：
- ❌ 功能重叠（都有意图识别）
- ❌ 接口不统一（不同的调用方式）
- ❌ 无法组合使用（独立运行）

#### 问题2：统一意图识别服务缺乏流式和动态能力

**现状**：
- 固定三步流程（LLM → 语义引擎 → 融合）
- 批处理模式（必须等待全部完成）
- 无法根据任务动态调整流程

**问题**：
- ❌ 用户体验差（无实时反馈）
- ❌ 灵活性差（无法适应复杂场景）
- ❌ 效率低（简单任务也用复杂流程）

#### 问题3：动态流程缺乏统一意图识别能力

**现状**：
- 动态设计智能体网络
- 但意图识别较简单（没有语义引擎和融合策略）

**问题**：
- ❌ 意图识别能力弱（没有企业语义引擎）
- ❌ 无法利用企业知识图谱
- ❌ 执行建议不完整

## 🔧 具体实现方案

### 方案1：统一服务层（推荐）⭐

**设计**：创建一个统一的服务层，整合三个能力

```python
class UnifiedIntentExecutionService:
    """统一意图识别与执行服务 - 整合意图识别、流式处理、动态流程"""
    
    def __init__(self):
        # 意图识别组件
        self.intent_service = UnifiedIntentService()
        
        # 动态流程组件
        self.dynamic_engine = DynamicExecutionEngine()
        
        # 流式处理组件（内置）
        self.stream_handler = StreamHandler()
    
    async def process_stream(
        self,
        user_input: str,
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[Dict[str, Any]]:
        """
        统一处理入口（流式）
        
        整合：
        1. 统一意图识别（流式）
        2. 动态执行规划（流式）
        3. 动态流程执行（流式）
        """
        
        # 阶段1：意图理解（流式）
        async for chunk in self._understand_intent_stream(user_input, context):
            yield chunk
        
        # 从流式结果中提取意图
        intent_result = await self._collect_intent_result()
        
        # 阶段2：执行规划（动态，流式）
        async for chunk in self._plan_execution_stream(intent_result, context):
            yield chunk
        
        # 从流式结果中提取执行计划
        execution_plan = await self._collect_execution_plan()
        
        # 阶段3：执行（动态，流式）
        async for chunk in self._execute_stream(execution_plan, context):
            yield chunk
    
    async def _understand_intent_stream(
        self,
        user_input: str,
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[Dict[str, Any]]:
        """流式意图理解"""
        
        # 1. LLM意图分析（流式返回）
        yield {
            "stage": "intent_analysis",
            "status": "analyzing",
            "progress": 10,
            "message": "正在分析用户意图..."
        }
        
        llm_task = self.intent_service._analyze_intent_with_llm(user_input, context)
        sentiment_task = self.intent_service._analyze_sentiment(user_input, context)
        
        # 并行执行，流式返回
        llm_result, sentiment_analysis = await asyncio.gather(
            llm_task, sentiment_task, return_exceptions=True
        )
        
        yield {
            "stage": "intent_analysis",
            "status": "llm_complete",
            "progress": 30,
            "result": llm_result,
            "sentiment": sentiment_analysis
        }
        
        # 2. 语义引擎查询（流式返回）
        if llm_result.get("needs_semantic_search", True):
            yield {
                "stage": "semantic_search",
                "status": "searching",
                "progress": 40,
                "message": "正在查询企业语义引擎..."
            }
            
            semantic_results = await self.intent_service.semantic_adapter.query_intent_enhanced(
                user_input=user_input,
                llm_result=llm_result,
                context=context,
                top_k=10,
                min_score=0.5
            )
            
            yield {
                "stage": "semantic_search",
                "status": "complete",
                "progress": 60,
                "result": semantic_results
            }
        else:
            semantic_results = None
        
        # 3. 融合策略（流式返回）
        yield {
            "stage": "fusion",
            "status": "fusing",
            "progress": 70,
            "message": "正在融合分析结果..."
        }
        
        fused_result = self.intent_service._dynamic_fusion_strategy_with_sentiment(
            llm_result,
            semantic_results,
            sentiment_analysis
        )
        
        yield {
            "stage": "fusion",
            "status": "complete",
            "progress": 80,
            "result": fused_result
        }
        
        # 4. 构建意图结果
        intent_result = self._build_intent_result(
            llm_result,
            semantic_results,
            fused_result,
            sentiment_analysis
        )
        
        yield {
            "stage": "intent_complete",
            "status": "complete",
            "progress": 100,
            "result": intent_result
        }
    
    async def _plan_execution_stream(
        self,
        intent_result: UnifiedIntentResult,
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[Dict[str, Any]]:
        """动态执行规划（流式）"""
        
        # 1. 任务复杂度分析（流式返回）
        yield {
            "stage": "complexity_analysis",
            "status": "analyzing",
            "progress": 10,
            "message": "正在分析任务复杂度..."
        }
        
        complexity = await self._analyze_complexity(intent_result, context)
        
        yield {
            "stage": "complexity_analysis",
            "status": "complete",
            "progress": 30,
            "complexity": complexity
        }
        
        # 2. 执行模式选择（动态）
        execution_mode = self._select_execution_mode(complexity, intent_result)
        
        yield {
            "stage": "mode_selection",
            "status": "complete",
            "progress": 50,
            "mode": execution_mode
        }
        
        # 3. 执行计划生成（流式返回）
        yield {
            "stage": "planning",
            "status": "planning",
            "progress": 60,
            "message": "正在生成执行计划..."
        }
        
        if execution_mode == "direct":
            # 简单任务：直接执行计划
            execution_plan = await self._create_direct_plan(intent_result, context)
        elif execution_mode == "template":
            # 中等任务：模板执行计划
            execution_plan = await self._create_template_plan(intent_result, context)
        else:
            # 复杂任务：动态设计执行计划
            async for chunk in self.dynamic_engine.workflow_designer.design_for_request(
                intent_result.user_input,
                context,
                stream=True
            ):
                yield {
                    "stage": "planning",
                    "status": "designing",
                    "progress": 60 + chunk.get("progress", 0) * 0.3,
                    "design_chunk": chunk
                }
            
            execution_plan = await self._collect_design_result()
        
        yield {
            "stage": "planning",
            "status": "complete",
            "progress": 100,
            "plan": execution_plan
        }
    
    async def _execute_stream(
        self,
        execution_plan: Dict[str, Any],
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[Dict[str, Any]]:
        """动态执行（流式）"""
        
        execution_mode = execution_plan.get("mode", "direct")
        
        if execution_mode == "direct":
            # 直接执行
            async for chunk in self._execute_direct_stream(execution_plan, context):
                yield chunk
        elif execution_mode == "template":
            # 模板执行
            async for chunk in self._execute_template_stream(execution_plan, context):
                yield chunk
        else:
            # 动态执行
            async for chunk in self.dynamic_engine.execute_dynamic_workflow(
                execution_plan["user_input"],
                context,
                stream=True
            ):
                yield chunk
```

```python
class UnifiedOrchestrationService:
    """统一编排服务 - 整合三个能力"""
    
    def __init__(self):
        # 意图识别层
        self.intent_layer = IntentRecognitionLayer()
        
        # 规划层

        # 执行层
        self.execution_layer = ExecutionLayer()
    
    async def orchestrate_stream(
        self,
```

### 方案3：管道式整合架构（推荐用于复杂场景）

**设计**：使用管道模式，每个阶段都是可组合的处理器

```python
class ProcessingPipeline:
    """处理管道 - 可组合的处理阶段"""
    
    def __init__(self):
        self.stages = []
    
    def add_stage(self, stage: ProcessingStage):
        """添加处理阶段"""
        self.stages.append(stage)
    
    async def process_stream(
        self,
        user_input: str,
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[Dict[str, Any]]:
        """流式处理管道"""
        
        current_data = {
            "user_input": user_input,
            "context": context or {},
            "results": {}
        }
        
        for stage in self.stages:
            async for chunk in stage.process_stream(current_data):
                yield chunk
                # 更新当前数据
                if chunk.get("result"):
                    current_data["results"][stage.name] = chunk["result"]
                    current_data.update(chunk.get("data", {}))


# 使用示例
pipeline = ProcessingPipeline()

# 阶段1：意图理解
pipeline.add_stage(IntentRecognitionStage(
    intent_service=UnifiedIntentService(),
    enable_sentiment=True,
    enable_semantic=True
))

# 阶段2：执行规划
pipeline.add_stage(ExecutionPlanningStage(
    dynamic_engine=DynamicExecutionEngine(),
    enable_learning=True
))

# 阶段3：执行
pipeline.add_stage(ExecutionStage(
    dynamic_engine=DynamicExecutionEngine(),
    enable_streaming=True
))
```

## 🎯 推荐方案：统一服务层 + 动态适配

### 核心设计理念

**不是简单堆砌，而是科学整合**：

1. **统一入口**：所有请求通过统一服务处理
2. **流式优先**：所有处理都支持流式返回
3. **动态适配**：根据任务复杂度动态选择流程
4. **能力组合**：整合各系统的优势能力
5. **渐进式反馈**：每个阶段都实时返回中间结果

### 核心设计

```python
class UnifiedIntentExecutionService:
    """
    统一意图识别与执行服务
    
    整合：
    1. 统一意图识别（流式 + 动态）
    2. 动态执行规划（流式 + 动态）
    3. 动态流程执行（流式 + 动态）
    """
    
    async def process_stream(
        self,
        user_input: str,
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[UnifiedStreamChunk]:
        """
        统一处理入口（流式）
        
        流程：
        1. 意图理解（流式，整合LLM + 情感 + 语义引擎）
        2. 执行规划（动态，根据复杂度选择模式）
        3. 执行（动态，根据规划执行）
        """
        
        # 阶段1：意图理解（流式）
        intent_result = None
        async for chunk in self._understand_intent_stream(user_input, context):
            yield chunk
            if chunk.stage == "intent_complete":
                intent_result = chunk.result
        
        # 阶段2：执行规划（动态，流式）
        execution_plan = None
        async for chunk in self._plan_execution_stream(intent_result, context):
            yield chunk
            if chunk.stage == "planning_complete":
                execution_plan = chunk.plan
        
        # 阶段3：执行（动态，流式）
        async for chunk in self._execute_stream(execution_plan, context):
            yield chunk
```

### 关键特性

1. **统一入口**：所有请求通过 `process_stream` 处理
2. **流式优先**：所有阶段都支持流式返回
3. **动态适配**：根据任务复杂度动态选择执行模式
4. **能力整合**：整合三个系统的优势能力

```python
class UnifiedIntentMVP:
    """务实版MVP：混合模式（伪流式 + 批处理）"""
    
    def __init__(self):
        # 复用现有组件，不重构
        self.conversation_agent = ConversationAgent()
        self.orchestration_engine = OrchestrationEngine()
        self.intent_service = UnifiedIntentService()
    
    async def process_hybrid(
        self,
        user_input: str,
        context: Optional[Dict[str, Any]] = None
    ) -> AsyncIterator[Dict[str, Any]]:
        """
        混合模式：前端伪流式 + 后端批处理
        降低技术风险，快速验证价值
        """
        try:
            # 1. 立即返回"接收成功"响应
            yield {
                "stage": "received",
                "status": "success",
                "progress": 5,
                "message": "请求已接收，正在处理..."
            }
            
            # 2. 后端并行处理（保持现有批处理逻辑）
            yield {
                "stage": "processing",
                "status": "analyzing",
                "progress": 20,
                "message": "正在分析用户意图..."
            }
            
            # 使用现有组件，并行执行
            intent_task = self.conversation_agent.understand_conversation(
                user_input,
                context.get('history', []),
                context
            )
            
            # 语义引擎查询（可选，不阻塞）
            semantic_task = None
            if self.intent_service.semantic_adapter:
                try:
                    semantic_task = asyncio.create_task(
                        self._query_semantic_engine_safe(user_input, context)
                    )
                except:
                    pass  # 失败不影响主流程
            
            # 等待意图分析完成
            intent_analysis = await intent_task
            
            yield {
                "stage": "intent_complete",
                "status": "complete",
                "progress": 50,
                "result": {
                    "task_type": intent_analysis.task_type.value,
                    "confidence": intent_analysis.confidence
                }
            }
            
            # 3. 执行阶段（使用现有编排引擎）
            yield {
                "stage": "execution",
                "status": "executing",
                "progress": 60,
                "message": "正在执行任务..."
            }
            
            # 使用现有编排引擎（批处理模式）
            result = await self.orchestration_engine.orchestrate_request(
                user_input,
                context
            )
            
            # 4. 整合语义引擎结果（如果可用）
            if semantic_task and semantic_task.done():
                try:
                    semantic_results = await semantic_task
                    result["semantic_enhancement"] = semantic_results
                except:
                    pass  # 语义引擎失败不影响主结果
            
            # 5. 返回最终结果
            yield {
                "stage": "complete",
                "status": "success",
                "progress": 100,
                "result": result
            }
        
        except Exception as e:
            logger.error(f"处理失败: {e}", exc_info=True)
            yield {
                "stage": "error",
                "status": "error",
                "error": str(e),
                "message": "处理过程中发生错误，已记录日志"
            }
    
    async def _query_semantic_engine_safe(
        self,
        user_input: str,
        context: Optional[Dict[str, Any]]
    ) -> Optional[Dict[str, Any]]:
        """安全查询语义引擎（带超时和错误处理）"""
        try:
            # 设置超时，避免阻塞
            result = await asyncio.wait_for(
                self.intent_service.semantic_adapter.query_intent_enhanced(
                    user_input=user_input,
                    llm_result={},  # 简化版，不依赖LLM结果
                    context=context,
                    top_k=5,
                    min_score=0.5
                ),
                timeout=3.0  # 3秒超时
            )
            return result
        except (asyncio.TimeoutError, Exception) as e:
            logger.warning(f"语义引擎查询失败: {e}")
            return None
```

```python
class PerformanceOptimizer:
    """性能优化器（务实版）"""
    
    def __init__(self):
        # 使用Redis缓存，而不是复杂的内存管理
        self.redis = redis.Redis()

        return None

        """缓存结果"""
        await self.redis.setex(
            cache_key,
            self.cache_ttl,
            json.dumps(result)
        )
    
    async def optimize_parallel_execution(
        self,
        tasks: List[Coroutine],
        timeout: float = 5.0
    ):
        """优化并行执行（带超时）"""
        try:
            return await asyncio.wait_for(
                asyncio.gather(*tasks, return_exceptions=True),
                timeout=timeout
            )
        except asyncio.TimeoutError:
            # 超时返回已完成的结果
            return [None] * len(tasks)
```

```python
# 简化版状态管理（降低复杂度）
class StreamStateManager:
    """简化版状态管理器"""
    
    def __init__(self):
        self.states = {}  # 内存存储（可扩展到Redis）
        self.max_states = 1000  # 限制状态数量
    
    async def save_checkpoint(self, session_id: str, stage: str, data: Any):
        """保存检查点（简化版）"""
        if session_id not in self.states:
            self.states[session_id] = {}
        
        self.states[session_id][stage] = {
            "data": data,
            "timestamp": datetime.now()
        }
        
        # 限制状态数量（防止内存泄漏）
        if len(self.states) > self.max_states:
            self._cleanup_old_states()
    
    async def get_last_checkpoint(self, session_id: str) -> Optional[Dict[str, Any]]:
        """获取最后一个检查点"""
        if session_id not in self.states:
            return None
        
        stages = ["started", "intent_complete", "planning_complete", "execution_complete"]
        for stage in reversed(stages):
            if stage in self.states[session_id]:
                return {
                    "stage": stage,
                    "data": self.states[session_id][stage]["data"]
                }
        return None
    
    def _cleanup_old_states(self):
        """清理旧状态（简化版）"""
        # 保留最近100个会话的状态
        if len(self.states) > 100:
            sorted_sessions = sorted(
                self.states.items(),
                key=lambda x: max(s.get("timestamp", datetime.min) for s in x[1].values()),
                reverse=True
            )
            self.states = dict(sorted_sessions[:100])
```

```python
class PerformanceOptimizer:
    """性能优化器"""
    
    def __init__(self):
        self.cache = {}  # 结果缓存
        self.rate_limiter = RateLimiter()  # 限流器
    
    async def optimize_parallel_execution(
        self,
        tasks: List[Coroutine],
        timeout: float = 5.0
    ) -> List[Any]:
        """优化并行执行（带超时）"""
        try:
            results = await asyncio.wait_for(
                asyncio.gather(*tasks, return_exceptions=True),
                timeout=timeout
            )
            return results
        except asyncio.TimeoutError:
            # 超时处理：返回已完成的结果
            return [None] * len(tasks)
    
    async def optimize_streaming(
        self,
        stream: AsyncIterator[Dict[str, Any]],
        batch_size: int = 10
    ) -> AsyncIterator[Dict[str, Any]]:
        """优化流式处理（批处理）"""
        batch = []
        async for chunk in stream:
            batch.append(chunk)
            if len(batch) >= batch_size:
                yield {"type": "batch", "chunks": batch}
                batch = []
        
        if batch:
            yield {"type": "batch", "chunks": batch}
```

## 🔍 企业语义引擎的深度整合方案

### 当前整合情况分析

**现状**：
- ✅ 在意图理解阶段已整合：`semantic_adapter.query_intent_enhanced()`
- ⚠️ 在执行规划阶段未充分利用
- ⚠️ 在执行阶段未提供上下文增强
- ⚠️ 语义引擎的推荐能力未使用

**问题**：
- 语义引擎只在意图识别阶段使用
- 执行规划时没有利用语义引擎的活动推荐
- 执行过程中没有利用语义引擎的能力映射

### 企业语义引擎的完整能力

**核心能力**：
1. **意图查询**：`query_intent()` - 根据用户输入查询相关业务活动
2. **活动搜索**：`search_activities()` - 基于向量搜索业务活动
3. **活动推荐**：`recommend_activities()` - 推荐相关业务活动
4. **能力映射**：通过 `ActivityCapabilityMapping` 获取活动对应的能力

### 科学整合方案

```python
async def _understand_intent_stream(...):
```

```python
async def _plan_execution_stream(
    self,
    intent_result: UnifiedIntentResult,
    context: Optional[Dict[str, Any]] = None
) -> AsyncIterator[StreamChunk]:
    """动态执行规划（流式 + 语义引擎增强）"""
    
    # 1. 复杂度分析（流式）
    yield StreamChunk(stage="complexity_analysis", progress=10)
    complexity = await self._analyze_complexity(intent_result, context)
    yield StreamChunk(stage="complexity_analysis", progress=20, complexity=complexity)
    
    # 2. 语义引擎增强规划（新增）
    if intent_result.suggested_activities:
        yield StreamChunk(
            stage="semantic_planning",
            progress=25,
            message="正在使用企业语义引擎增强执行规划..."
        )
        
        # 2.1 获取活动对应的能力
        activity_capabilities = await self._get_capabilities_for_activities(
            intent_result.suggested_activities
        )
        yield StreamChunk(
            stage="semantic_planning",
            progress=35,
            capabilities=activity_capabilities
        )
        
        # 2.2 推荐相关活动（如果任务复杂）
        if complexity == "complex":
            yield StreamChunk(
                stage="activity_recommendation",
                progress=40,
                message="任务复杂，正在推荐相关活动..."
            )
            
            # 为每个主要活动推荐相关活动
            all_recommendations = []
            for activity in intent_result.suggested_activities[:3]:  # 只处理前3个
                recommendations = await self._recommend_related_activities(
                    activity_id=activity["id"],
                    top_k=3
                )
                all_recommendations.extend(recommendations)
            
            yield StreamChunk(
                stage="activity_recommendation",
                progress=50,
                recommendations=all_recommendations
            )
        
        # 2.3 构建能力映射
        capability_mapping = await self._build_capability_mapping(
            intent_result.suggested_activities,
            activity_capabilities,
            all_recommendations if complexity == "complex" else []
        )
        yield StreamChunk(
            stage="semantic_planning",
            progress=60,
            capability_mapping=capability_mapping
        )
    
    # 3. 执行模式选择（动态，使用语义引擎结果）
    execution_mode = self._select_execution_mode(
        complexity,
        intent_result,
        capability_mapping if intent_result.suggested_activities else None
    )
    yield StreamChunk(stage="mode_selection", progress=70, mode=execution_mode)
    
    # 4. 执行计划生成（流式，使用语义引擎结果）
    yield StreamChunk(stage="planning", progress=75)
    
    if execution_mode == "dynamic":
        # 动态设计时，使用语义引擎的能力映射
        async for design_chunk in self.dynamic_engine.workflow_designer.design_for_request(
            intent_result.user_input,
            context,
            stream=True,
            semantic_context={  # 新增：语义引擎上下文
                "suggested_activities": intent_result.suggested_activities,
                "capability_mapping": capability_mapping,
                "recommendations": all_recommendations if complexity == "complex" else []
            }
        ):
            yield StreamChunk(stage="planning", design_chunk=design_chunk)
    
    yield StreamChunk(stage="planning_complete", progress=100)
```

```python
async def _execute_stream(
    self,
    execution_plan: Dict[str, Any],
    context: Optional[Dict[str, Any]] = None
) -> AsyncIterator[StreamChunk]:
    """动态执行（流式 + 语义引擎上下文增强）"""
    
    # 在执行过程中，使用语义引擎提供上下文增强
    semantic_context = execution_plan.get("semantic_context", {})
    
    if execution_plan.get("mode") == "dynamic":
        # 动态执行时，为每个智能体提供语义引擎上下文
        async for chunk in self.dynamic_engine.execute_dynamic_workflow(
            execution_plan["user_input"],
            {
                **context,
                "semantic_context": semantic_context,  # 新增：语义引擎上下文
                "suggested_activities": semantic_context.get("suggested_activities", []),
                "capability_mapping": semantic_context.get("capability_mapping", {})
            },
            stream=True
        ):
            # 在执行过程中，可以实时查询语义引擎获取更多上下文
            if chunk.get("stage") == "agent_executing":
                agent_id = chunk.get("agent_id")
                if agent_id:
                    # 为智能体提供语义引擎上下文
                    enhanced_context = await self._enhance_agent_context(
                        agent_id=agent_id,
                        semantic_context=semantic_context,
                        current_step=chunk.get("step")
                    )
                    chunk["semantic_context"] = enhanced_context
            
            yield chunk
```

```python
async def _recommend_related_activities(
    self,
    activity_id: str,
    top_k: int = 5
) -> List[Dict[str, Any]]:
    """推荐相关活动"""
    try:
        loop = asyncio.get_event_loop()
        recommendation = await loop.run_in_executor(
            None,
            self.intent_service.semantic_engine.recommend_activities,
            activity_id,
            top_k,
            0.6  # min_similarity
        )
        
        # 转换为字典格式
        return [
            {
                "id": act.id,
                "name": act.name,
                "description": act.description,
                "similarity_score": score,
                "recommendation_reason": recommendation.recommendation_reason
            }
            for act, score in zip(
                recommendation.recommended_activities,
                recommendation.similarity_scores
            )
        ]
    except Exception as e:
        logger.warning(f"推荐相关活动失败: {e}")
        return []

async def _get_capabilities_for_activities(
    self,
    activities: List[Dict[str, Any]]
) -> Dict[str, List[Dict[str, Any]]]:
    """获取活动对应的能力"""
    try:
        capability_mapping = {}
        
        for activity in activities:
            activity_id = activity["id"]
            capabilities = await self.intent_service.get_capabilities_for_activity(activity_id)
            capability_mapping[activity_id] = capabilities
        
        return capability_mapping
    except Exception as e:
        logger.warning(f"获取活动能力失败: {e}")
        return {}

async def _build_capability_mapping(
    self,
    suggested_activities: List[Dict[str, Any]],
    activity_capabilities: Dict[str, List[Dict[str, Any]]],
    recommendations: List[Dict[str, Any]]
) -> Dict[str, Any]:
    """构建能力映射"""
    return {
        "suggested_activities": suggested_activities,
        "activity_capabilities": activity_capabilities,
        "recommendations": recommendations,
        "total_capabilities": sum(len(caps) for caps in activity_capabilities.values())
    }

async def _enhance_agent_context(
    self,
    agent_id: str,
    semantic_context: Dict[str, Any],
    current_step: Optional[str] = None
) -> Dict[str, Any]:

    enhanced = {
        "suggested_activities": semantic_context.get("suggested_activities", []),
        "capability_mapping": semantic_context.get("capability_mapping", {}),
        "recommendations": semantic_context.get("recommendations", [])
    }
    
    # 根据当前步骤，提供更相关的上下文
    if current_step:
        # 可以进一步查询语义引擎，获取与当前步骤相关的活动
        pass
    
    return enhanced
```
