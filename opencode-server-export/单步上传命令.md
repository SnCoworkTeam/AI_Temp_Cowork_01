# OpenCode 本地 Web — 单步上传命令

本机先执行 **build-and-pack-local-web** 脚本，得到 **opencode-upload** 文件夹。下面说明：每个文件在服务器上的目标目录，以及逐条可执行的上传命令。

**约定：**

- 本机上传包路径：`仓库根目录/opencode-upload/`（脚本生成）
- 服务器代码根目录：`/opt/enterprise-ai-platform`（按你实际路径替换 `SERVER_ROOT`）
- 服务器上 OpenCode 部署目录：`SERVER_ROOT/opencode-server-export/`

下文中的 `SERVER_ROOT`、`内网用户`、`内网服务器IP`、`堡垒机用户`、`堡垒机IP` 请替换为实际值。

---

## 一、服务器上目标目录（先创建）

在**内网服务器**上执行（若目录已存在可跳过）：

```bash
mkdir -p /opt/enterprise-ai-platform/opencode-server-export
```

若你的代码根目录不是 `/opt/enterprise-ai-platform`，请把上面路径改成你的 `SERVER_ROOT/opencode-server-export`。

---

## 二、每个文件对应服务器路径

| 本机文件（在 opencode-upload 下） | 服务器目标路径 |
|----------------------------------|----------------|
| enterprise-ai-opencode-local-web.tar | `SERVER_ROOT/opencode-server-export/enterprise-ai-opencode-local-web.tar` |
| docker-compose.opencode.local-web.yml | `SERVER_ROOT/opencode-server-export/docker-compose.opencode.local-web.yml` |
| .env.example | `SERVER_ROOT/opencode-server-export/.env.example` |
| .env（若有） | `SERVER_ROOT/opencode-server-export/.env` |

---

## 三、单步上传命令（逐条执行）

在**本机**、进入**仓库根目录**执行（将 `SERVER_ROOT`、`内网用户`、`内网服务器IP` 换成实际值）。

### 方式 A：经堡垒机跳转（ProxyJump）— 一条命令传一个文件

```bash
# 1. 上传镜像 tar
scp -o ProxyJump=堡垒机用户@堡垒机IP opencode-upload/enterprise-ai-opencode-local-web.tar 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/

# 2. 上传 compose
scp -o ProxyJump=堡垒机用户@堡垒机IP opencode-upload/docker-compose.opencode.local-web.yml 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/

# 3. 上传 .env.example
scp -o ProxyJump=堡垒机用户@堡垒机IP opencode-upload/.env.example 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/

# 4. 若有 .env 一并上传
scp -o ProxyJump=堡垒机用户@堡垒机IP opencode-upload/.env 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/
```

**示例**（SERVER_ROOT=/opt/enterprise-ai-platform，堡垒机 jump@192.168.1.1，内网 deploy@10.0.0.5）：

```bash
scp -o ProxyJump=jump@192.168.1.1 opencode-upload/enterprise-ai-opencode-local-web.tar deploy@10.0.0.5:/opt/enterprise-ai-platform/opencode-server-export/

scp -o ProxyJump=jump@192.168.1.1 opencode-upload/docker-compose.opencode.local-web.yml deploy@10.0.0.5:/opt/enterprise-ai-platform/opencode-server-export/

scp -o ProxyJump=jump@192.168.1.1 opencode-upload/.env.example deploy@10.0.0.5:/opt/enterprise-ai-platform/opencode-server-export/
```

---

### 方式 B：整包上传（一次传整个 opencode-upload）

本机执行（会覆盖服务器上该目录下同名文件）：

```bash
scp -o ProxyJump=堡垒机用户@堡垒机IP -r opencode-upload/* 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/
```

**示例**：

```bash
scp -o ProxyJump=jump@192.168.1.1 -r opencode-upload/* deploy@10.0.0.5:/opt/enterprise-ai-platform/opencode-server-export/
```

---

### 方式 C：无 ProxyJump，先传到堡垒机再传到内网

```bash
# 本机 → 堡垒机
scp opencode-upload/enterprise-ai-opencode-local-web.tar 堡垒机用户@堡垒机IP:/tmp/
scp opencode-upload/docker-compose.opencode.local-web.yml 堡垒机用户@堡垒机IP:/tmp/
scp opencode-upload/.env.example 堡垒机用户@堡垒机IP:/tmp/

# 登录堡垒机后执行：堡垒机 → 内网服务器
# ssh 堡垒机用户@堡垒机IP
scp /tmp/enterprise-ai-opencode-local-web.tar 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/
scp /tmp/docker-compose.opencode.local-web.yml 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/
scp /tmp/.env.example 内网用户@内网服务器IP:SERVER_ROOT/opencode-server-export/
```

---

## 四、上传后在服务器上的操作

SSH 登录内网服务器后：

```bash
cd SERVER_ROOT/opencode-server-export

# 若无 .env，从示例复制并编辑
cp .env.example .env
# 编辑 .env：OPENCODE_WORKSPACE、EXTERNAL_NETWORK_NAME、OPENCODE_SERVER_PASSWORD 等

# 加载镜像并启动
docker load -i enterprise-ai-opencode-local-web.tar
docker compose -f docker-compose.opencode.local-web.yml --env-file .env up -d
```

---

## 五、操作步骤汇总

| 步骤 | 在哪里执行 | 命令 |
|------|------------|------|
| 1. 本机构建并打上传包 | 本机，仓库根目录 | `.\opencode-server-export\build-and-pack-local-web.ps1`（Windows）或 `./opencode-server-export/build-and-pack-local-web.sh`（Linux/Mac） |
| 2. 服务器创建目录 | 内网服务器 | `mkdir -p /opt/enterprise-ai-platform/opencode-server-export` |
| 3. 上传文件 | 本机 | 按上面「方式 A/B/C」任选，把 opencode-upload 下文件传到服务器 `.../opencode-server-export/` |
| 4. 配置并启动 | 内网服务器 | `cd .../opencode-server-export` → `cp .env.example .env` 并编辑 → `docker load -i ...` → `docker compose -f docker-compose.opencode.local-web.yml --env-file .env up -d` |
